Library Examples.BayerGrothIns

The Bayer–Groth shuffle argument at the Swiss Post 3072-bit group

This file instantiates the Bayer–Groth shuffle argument (Bayer and Groth, EUROCRYPT 2012), in the variant used by the mix-net of the Swiss Post e-voting system (Crypto/BayerGroth.v, Backend/BayerGrothVerifier.v), at the group of the Swiss Post crypto-primitives test vectors: the 3072-bit safe prime p = 2q + 1 of crypto-primitives/src/test/resources/mixnet/verify-*.json (the ‘3072-bits’ group of the crypto-primitives specification, section 3.1), with generator g = 2. The scalar field is Z_q and the group is the order-q subgroup of Z_p^*.
Everything here is fully certified: q is prime by the ECPP certificate of primeQSP.v (generated by PARI/GP's primecert and converted by bench/ecpp2coq.py), and p is then prime by Pocklington's criterion since p - 1 = 2q; p = 2q + 1 and the order of g are checked by computation.
The file is extracted to OCaml by src/Extraction/BayerGrothlib. The driver Executable/Bgverifier parses the JSON test vectors, computes the RecursiveHash challenges and passes them in through the oracles record, and runs shuffle_verify_fs_ins; the provers are exported too, so the driver can also produce and check honest arguments. The parser and the hash computations are trusted. The same file, with only the group replaced, is the template from which BayerGrothE2EIns.v, BayerGrothIvxvIns.v and BayerGrothIvxvGoIns.v are generated.

The argument

The claim is that of any proof of a shuffle: the output ciphertexts C'ᵢ are the input ciphertexts Cᵢ, re-encrypted and permuted by a secret π,

C'ᵢ = Enc(1; ρᵢ) · C_π(i).
The ingredients are Pedersen commitments to vectors of Z_q, com(a; r) = h^r · ∏ gᵢ^aᵢ, and multi-recipient ElGamal ciphertexts (g^r, pk₁^r·m₁, …, pk_ℓ^r·m_ℓ) with ℓ message components. The N = m·n ciphertexts are arranged as an m × n matrix.
  • The prover commits to the permutation, c_A = com(π(1), …, π(N)).
  • The verifier sends x; the prover commits to the permuted powers c_B = com(x^π(1), …, x^π(N)).
  • The verifier sends y and z. A product argument shows ∏ᵢ (y·aᵢ + bᵢ - z) = ∏ᵢ (y·i + x^i - z) for the committed a, b: as polynomials in z both sides must coincide, so the committed pairs (aᵢ, bᵢ) are a rearrangement of the pairs (i, x^i).
  • A multi-exponentiation argument shows ∏ᵢ Cᵢ^(x^i) = Enc(1; ρ) · ∏ᵢ C'ᵢ^(x^π(i)), which holds for an honest shuffle with ρ = -Σᵢ ρᵢ·x^π(i) and, x being random, for no other relation between the C and C'.
Underneath are five sub-arguments (Swiss Post specification 1.6.0, section 9): single value product (∏ aᵢ = b for a committed vector), zero (Σ aᵢ ⋆ b_(i-1) = 0 for committed matrices), Hadamard (a committed vector is the entrywise product of committed columns), product (∏ a_(i,j) = b for a committed matrix) and multi-exponentiation.
Crypto/BayerGroth.v defines the interactive verifiers and proves their completeness; Crypto/BayerGrothSound.v proves k-special soundness of every sub-argument and composes them (shuffle_soundness); Crypto/BayerGrothZK.v gives honest-verifier zero-knowledge simulators for single-message ElGamal. Backend/BayerGrothVerifier.v is the Fiat–Shamir layer: an oracles record supplies each challenge as a function of the transcript so far, and shuffle_fs_soundness / shuffle_fs_completeness hold for every oracle. This file only instantiates those definitions; the one theorem stated here is completeness at this group.

The generator g = 2 (as an integer).
  Definition gval : Z := 2.

q is prime, by the ECPP certificate primeQSP.prime_q_sp.
  Theorem prime_q : prime q.
  Proof. exact primeQSP.prime_q_sp. Qed.

p = 2q + 1, checked by computation.
  Theorem cofactor : p = 2 × q + 1.
  Proof. vm_cast_no_check (eq_refl p). Qed.

2^q mod p = 1, so g = 2 is a quadratic residue and lies in the subgroup of order q. The modular power is evaluated with the BigN implementation of BigNPow, which is proved equal to Zpow_mod.
  Theorem g_order : Zpow_mod gval q p = 1.
  Proof.
    unfold q; rewrite BigNPow.bpow_mod_spec by (vm_compute; discriminate).
    vm_cast_no_check (eq_refl 1).
  Qed.

p is prime, by Pocklington's criterion (PocklingtonCorollary1) with the fully factored part q of p - 1 = 2q: since q > √p, it suffices that the witness 2 satisfies 2^(p-1) ≡ 1 and gcd(2^((p-1)/q) - 1, p) = gcd(3, p) = 1.
  Theorem prime_p : prime p.
  Proof.
    assert (hq0 : 0 < q) by (vm_cast_no_check (eq_refl Lt)).
    assert (hp0 : p ≠ 0) by (unfold p; discriminate).
    assert (e : p - 1 = q × 2) by (rewrite cofactor; ring).
    apply (PocklingtonCorollary1 p q 2).
    - vm_cast_no_check (eq_refl Lt).
    - lia.
    - exact e.
    - vm_cast_no_check (eq_refl Lt).
    - intros π hπ hdiv.
      pose proof (prime_ge_2 π hπ) as hπ2.
      destruct (prime_divisors q prime_q π hdiv) as [eπ | [eπ | [eπ | eπ]]]; try lia.
      subst π. ∃ 2. split; [lia |]. split.
      +
        rewrite e, Z.pow_mul_r by lia. rewrite Zpower_mod by lia.
        rewrite <-(Zpow_mod_correct 2 q p hp0).
        pose proof g_order as hg; unfold gval in hg; rewrite hg.
        vm_cast_no_check (eq_refl 1).
      +
        replace ((p - 1) / q) with 2 by (rewrite e, Z.mul_comm, Z.div_mul; lia).
        vm_cast_no_check (eq_refl 1).
  Qed.

Conversions and types for the driver

The OCaml driver works with integers. of_Z reduces an integer modulo q into Z_q; to_Z and elem_to_Z return the integer representative of a scalar or group element. Group elements are built by the driver, which checks membership (0 < v < p and v^q = 1) first.
  Definition of_Z (z : Z) : F.
  Proof. refine (Zpfield.mk_zp (Z.modulo z q) _). apply Z.mod_mod. vm_compute; discriminate. Defined.
  Definition to_Z (x : F) : Z := Zpfield.v x.
  Definition elem_to_Z (x : G) : Z := Schnorr.v x.

Completeness at this group

shuffle_fs_completeness_ins: for every oracle record whose challenge functions o_xh and o_yh never return zero, if Cs' really is a re-encryption of Cs under the permutation perm with randomness ρs (that is, C'ᵢ = Enc(1; ρᵢ)·C_perm(i)), 1 ≤ m, 2 ≤ n, n equals the number of commitment generators, and all the random inputs have the lengths the prover expects, then the honest prover's argument passes the verifier. It is shuffle_fs_completeness of Backend/BayerGrothVerifier.v at bg_vspace.
  Theorem shuffle_fs_completeness_ins : ∀ (l : nat) (O : oracles l) (h : G) (gs : list G) (g : G)
    (pk : Vector.t G l) (m n : nat) (Cs Cs' : list (ciphertext l)) (perm : list nat) (ρs : list F) (r s : list F)
    (sp : F) (smid : list F) (a0z bmz : list F) (r0z smz : F) (t1 t2 : list F)
    (d : list F) (rd : F) (dmid : list F) (s0 sx : F) (a0 : list F) (r0 : F) (bs ss τs : list F),
    (1 ≤ m)%nat → (2 ≤ n)%nat → length Cs = (m × n)%nat → length Cs' = (m × n)%nat →
    Permutation.Permutation perm (seq 0 (m × n)) → length ρs = (m × n)%nat →
    (∀ i, (i < m × n)%nat →
