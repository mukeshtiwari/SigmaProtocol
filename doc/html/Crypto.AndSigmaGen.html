Library Crypto.AndSigmaGen

AND composition of Schnorr proofs with independent bases

This file generalises AndSigma by allowing a different base for each conjunct. The relation is

      R((g₁, …, gₙ), (h₁, …, hₙ); (x₁, …, xₙ)) :⇔ ∀ i, gᵢ ^ xᵢ = hᵢ.
    
With randomness us and a single shared challenge c, the prover sends (g₁ ^ u₁, …, gₙ ^ uₙ) and responds with (uᵢ + c · xᵢ)ᵢ; the verifier generalised_and_accepting_conversations checks gᵢ ^ rᵢ = aᵢ · hᵢ ^ c for every i. Transcripts have type @sigma_proto F G n 1 n. The announcement, response and simulator announcement are exposed as separate functions (construct_and_conversations_schnorr_commitment, construct_and_conversations_schnorr_response, construct_and_conversations_simulator_commitment) so that composite protocols can reuse the pieces.
Results._ Verifier characterisation (accept iff all conjuncts accept; reject iff some conjunct rejects); completeness of prover and simulator; special soundness in two forms, generalise_and_sigma_soundness (existence of a witness vector) and generalise_and_sigma_soundness_neq (the witness vector is the explicit ys = ((r₁ᵢ - r₂ᵢ) · (c₁ - c₂)⁻¹)ᵢ); and special HVZK in the weak acceptance-bit form and as equality of distributions up to permutation (generalised_and_special_honest_verifier_zkp_perm, generalised_and_special_honest_verifier_zkp_enum).
Used by NeqSigma (inequality-of-discrete-logs proofs), which relies on the explicit extractor of generalise_and_sigma_soundness_neq and on construct_and_commitment_shift; also extracted on its own (see src/Extraction/dune). Reference: Cramer, Damgård and Schoenmakers, CRYPTO 1994, for AND composition.

Announcement vector (gᵢ ^ uᵢ)ᵢ for bases gs and randomness us.
        Definition construct_and_conversations_schnorr_commitment
          {n : nat} (gs : Vector.t G n ) (us : Vector.t F n) : Vector.t G n :=
          zip_with (fun g y ⇒ g^y) gs us.

Response vector (uᵢ + c · xᵢ)ᵢ for witnesses xs, randomness us and challenge c.
        Definition construct_and_conversations_schnorr_response
          {n : nat} (xs us : Vector.t F n) (c : F) : Vector.t F n.
        Proof.
          set (usxs := zip_with (fun u x ⇒ (u, x)) us xs).
          set (res := Vector.map (fun '(u, x) ⇒ u + c × x) usxs).
          exact res.
        Defined.

Honest prover: announcement from construct_and_conversations_schnorr_commitment, one-element challenge vector c :: nil, responses from construct_and_conversations_schnorr_response.
        Definition construct_and_conversations_schnorr {n : nat}
          (xs : Vector.t F n) (gs : Vector.t G n)
          (us : Vector.t F n) (c : F) : @sigma_proto F G n 1 n.
        Proof.
          set (comm := construct_and_conversations_schnorr_commitment
            gs us).
          set (res := construct_and_conversations_schnorr_response xs us c).
          exact (comm; [c]; res).
        Defined.

Simulated announcement vector (gᵢ ^ uᵢ · hᵢ ^ (-c))ᵢ.
        Definition construct_and_conversations_simulator_commitment {n : nat}
          (gs : Vector.t G n) (hs : Vector.t G n) (us : Vector.t F n)
          (c : F) : Vector.t G n.
        Proof.
          set (ushs := zip_with (fun u h ⇒ (u, h)) us hs).
          set (gsushs := zip_with (fun g uh ⇒ (g, uh)) gs ushs).
          set (comm := Vector.map (fun '(g, (u, h)) ⇒ gop (g^u) (h^(opp c))) gsushs).
          exact comm.
        Defined.

Simulator: simulated announcement, one-element challenge vector c :: nil and responses us. Uses no witness.
        Definition construct_and_conversations_simulator {n : nat}
          (gs : Vector.t G n) (hs : Vector.t G n) (us : Vector.t F n)
          (c : F) : @sigma_proto F G n 1 n.
        Proof.
          set (comm := construct_and_conversations_simulator_commitment
            gs hs us c).
          refine(comm; [c]; us).
        Defined.

Verifier: by recursion on n, checks gᵢ ^ rᵢ = aᵢ · hᵢ ^ c on the head conjunct with accepting_conversation and recurses on the tails with the same one-element challenge vector c. Accepts when n = 0.
        Definition generalised_and_accepting_conversations :
          ∀ {n : nat}, Vector.t G n → Vector.t G n →
          @sigma_proto F G n 1 n → bool.
        Proof.
          refine(fix Fn n {struct n} :=
            match n with
            | 0 ⇒ fun _ _ p ⇒ true
            | S n' ⇒ fun gs hs p ⇒
              match p with
              | (a; c ; r) ⇒ _
              end
            end).
          destruct (vector_inv_S a) as (ah & atl & _).
          destruct (vector_inv_S c) as (ch & ctl & _).
          destruct (vector_inv_S r) as (rh & rtl & _).
          destruct (vector_inv_S gs) as (g & gtl & _).
          destruct (vector_inv_S hs) as (h & htl & _).
          exact ((@accepting_conversation F G gop gpow Gdec g h ([ah]; [ch]; [rh])) &&
            (Fn _ gtl htl (atl; c; rtl))).
        Defined.

Real transcript distribution for a fixed challenge c: n independent uniform draws from lf, then the honest prover.
        Definition generalised_and_schnorr_distribution
          {n : nat} (lf : list F) (Hlfn : lf ≠ List.nil)
          (xs : Vector.t F n) (gs : Vector.t G n)
          (c : F) : dist (@sigma_proto F G n 1 n) :=
          us <- repeat_dist_ntimes_vector
            (uniform_with_replacement lf Hlfn) n ;;
          Ret (construct_and_conversations_schnorr xs gs us c).

Simulated transcript distribution for a fixed challenge c: n independent uniform draws from lf, then the simulator.
        Definition generalised_and_simulator_distribution
          {n : nat} (lf : list F) (Hlfn : lf ≠ List.nil)
          (gs : Vector.t G n) (hs : Vector.t G n)
          (c : F) : dist (@sigma_proto F G n 1 n) :=
          us <- repeat_dist_ntimes_vector
            (uniform_with_replacement lf Hlfn) n ;;
          Ret (construct_and_conversations_simulator gs hs us c).

    End Def.

If the verifier accepts (a; c; r), every conjunct (a_f; c; r_f) is an accepting Schnorr transcript for (gs_f, hs_f).
        Lemma generalised_and_accepting_conversations_correctness_forward :
          ∀ (n : nat) (gs hs : Vector.t G n) (s : @sigma_proto F G n 1 n),
          generalised_and_accepting_conversations gs hs s = true →
          (∀ (f : Fin.t n),
            match s with
            | (a; c; r) ⇒
              @accepting_conversation F G gop gpow Gdec (nth gs f) (nth hs f)
                ([(nth a f)]; c; [(nth r f)]) = true
            end).
        Proof.
          unfold accepting_conversation.
          induction n as [|n IHn];
          simpl.
          +
            intros × Ha f.
            refine (match f with end).
          +
            intros × Ha f.
            refine
            (match s as s'
            return s = s' → _ with
            |(a; c; r) ⇒ fun Hc ⇒ _
            end eq_refl).
            rewrite Hc in Ha.
            destruct (vector_inv_S a) as (ha & ta & Hd).
            destruct (vector_inv_S c) as (hc & tc & He).
            destruct (vector_inv_S r) as (hr & tr & Hf).
            destruct (vector_inv_S gs) as (gsa & gstl & Hgg).
            destruct (vector_inv_S hs) as (hsa & hstl & Hj).
            eapply andb_true_iff in Ha.
            destruct Ha as [Hal Har].
            destruct (fin_inv_S _ f) as [hf | (hf & Hg)].
            ++
              subst; cbn;
              exact Hal.
            ++
              rewrite Hf, Hd, Hj, He,
              Hg, Hgg; cbn.
              specialize (IHn _ _ _ Har hf);
              cbn in IHn.
              rewrite He in IHn;
              cbn in IHn; exact IHn.
        Qed.

If the verifier rejects, some conjunct is a rejecting Schnorr transcript.
        Lemma generalised_and_accepting_conversations_correctness_forward_reject :
          ∀ (n : nat) (gs hs : Vector.t G n) (s : @sigma_proto F G n 1 n),
          generalised_and_accepting_conversations gs hs s = false →
          (∃ (f : Fin.t n),
            match s with
            | (a; c; r) ⇒
              @accepting_conversation F G gop gpow Gdec (nth gs f) (nth hs f)
                ([(nth a f)]; c; [(nth r f)]) = false
            end).
        Proof.
          induction n as [|n ihn].
          +
            intros × ha.
            cbn in ha.
            congruence.
          +
            intros × Ha.
            refine
            (match s as s'
            return s = s' → _ with
            |(a; c; r) ⇒ fun Hb ⇒ _
            end eq_refl).
            rewrite Hb in Ha.
            destruct (vector_inv_S a) as (ha & ta & Hd).
            destruct (vector_inv_S c) as (hc & tc & He).
            destruct (vector_inv_S r) as (hr & tr & Hf).
            destruct (vector_inv_S gs) as (gsa & gstl & Hgg).
            destruct (vector_inv_S hs) as (hsa & hstl & Hj).
            subst.
            cbn in Ha.
            eapply andb_false_iff in Ha.
            destruct Ha as [Ha | Ha].
            ++
              ∃ Fin.F1.
              exact Ha.
            ++
              destruct (ihn _ _ (ta; hc :: tc; tr) Ha) as (f & ihnn).
              ∃ (Fin.FS f).
              cbn.
              exact ihnn.
        Qed.

          ∀ (n : nat) (gs hs : Vector.t G n) (s : @sigma_proto F G n 1 n),

            destruct (vector_inv_S hs) as (hsa & hstl & Hj).

            ++
              cbn in Ha |- ×.
              rewrite Ha; reflexivity.

Componentwise completeness: if gsᵢ ^ xsᵢ = hsᵢ for all i, the f-th conjunct of the honest transcript is an accepting Schnorr transcript, for every f. Proved by induction on n.
        Theorem construct_and_conversations_schnorr_completeness_generic :
          ∀ (n : nat) (f : Fin.t n) (gs hs : Vector.t G n)
          (us : Vector.t F n) (xs : Vector.t F n) (c : F),
          (∀ (f : Fin.t n), (Vector.nth gs f)^(Vector.nth xs f) = Vector.nth hs f) →
          @accepting_conversation F G gop gpow Gdec gs[@f] hs[@f]
            ([(zip_with (λ (g : G) (y : F), g ^ y) gs us)[@f]]; [c];
            [(map (λ '(u, x), u + c × x)
            (zip_with (λ u x : F, (u, x)) us xs))[@f]]) = true.
        Proof.
          induction n as [|n ihn].
          +
            intros × R. refine match f with end.
          +
            intros × R.
            destruct (vector_inv_S hs) as (hh & hst & ha).
            destruct (vector_inv_S gs) as (gh & gst & hgg).
            destruct (vector_inv_S us) as (uh & ust & hb).
            destruct (vector_inv_S xs) as (xh & xst & hc).
            subst.
            destruct (fin_inv_S _ f) as [f' | (f' & ha)].
            ++
              specialize (R Fin.F1); cbn in R.
              subst; cbn.
              eapply dec_true.
              assert (Hg : (gh ^ xh) ^ c = (gh ^ (xh × c))).
              rewrite smul_pow_up.
              reflexivity.
              rewrite Hg; clear Hg.
              assert (Hxc : xh × c = c × xh) by field.
              rewrite Hxc; clear Hxc.
              rewrite <- (@vector_space_smul_distributive_fadd F (@eq F)
                zero one add mul sub div
                opp inv G (@eq G) gid ginv gop gpow);
              subst; [exact eq_refl
              | assumption].
            ++
              subst; cbn.
              eapply dec_true.
              specialize (ihn f' gst hst ust xst c).
              cbn in ihn. rewrite dec_true in ihn.
              eapply ihn.
              intro f.
              specialize (R (Fin.FS f)); cbn in R.
              exact R.
        Qed.

Componentwise simulator completeness: the f-th conjunct of a simulated transcript is always accepting.
        Theorem construct_and_conversations_simulator_completeness_generic :
          ∀ (n : nat) (f : Fin.t n) (gs hs : Vector.t G n)
          (us : Vector.t F n) (c : F),
          @accepting_conversation F G gop gpow Gdec gs[@f] hs[@f]
          ([(map (λ '(g, (u, h)), gop (g ^ u) (h ^ opp c))
          (zip_with (λ (g : G) (uh : F × G), (g, uh)) gs
          (zip_with (λ (u : F) (h : G), (u, h)) us hs)))[@f]];
          [c]; [us[@f]]) = true.
        Proof.
           induction n as [|n ihn].
          +
            intros ×. refine match f with end.
          +
            intros ×.
            destruct (vector_inv_S hs) as (hh & hst & ha).
            destruct (vector_inv_S gs) as (gh & gst & hgg).
            destruct (vector_inv_S us) as (uh & ust & hb).
            subst.
            destruct (fin_inv_S _ f) as [f' | (f' & ha)].
            ++
              subst; cbn.
              eapply dec_true.
              rewrite <-associative.
              rewrite <-(@vector_space_smul_distributive_fadd F (@eq F)
                zero one add mul sub div
                opp inv G (@eq G) gid ginv gop gpow).
              rewrite field_zero_iff_left,
              vector_space_field_zero,
              monoid_is_right_identity.
              reflexivity.
              typeclasses eauto.
            ++
              subst; cbn in ihn |- ×.
              eapply ihn.
        Qed.

Completeness._ The honest transcript is accepted for every randomness us and challenge c.
        Lemma construct_and_conversations_schnorr_completeness :
          ∀ (us : Vector.t F n) (c : F),
          generalised_and_accepting_conversations gs hs
            (construct_and_conversations_schnorr xs gs us c) = true.
        Proof.
          intros ×.
          eapply generalised_and_accepting_conversations_correctness.
          unfold construct_and_conversations_schnorr.
          intro f. unfold construct_and_conversations_schnorr_commitment,
          construct_and_conversations_schnorr_response.
          eapply construct_and_conversations_schnorr_completeness_generic.
          exact R.
        Qed.

        Lemma construct_and_conversations_simulator_completeness :

        Lemma generalise_and_sigma_soundness :
          ∀ (a : Vector.t G n) (c₁ : Vector.t F 1)
          (r₁ : Vector.t F n) (c₂ : Vector.t F 1) (r₂ : Vector.t F n),
          generalised_and_accepting_conversations gs hs (a; c₁; r₁) = true →
          generalised_and_accepting_conversations gs hs (a; c₂; r₂) = true →
          c₁ ≠ c₂ →
          ∃ ys : Vector.t F n, (∀ (f : Fin.t n),
            (nth gs f)^(nth ys f) = (nth hs f)).
        Proof using -(xs R).
          clear xs R.
          induction n as [|n' IHn].
          +
            intros × Ha Hb Hc.
            ∃ [];
            intros f; inversion f.
          +
            intros × Ha Hb Hc.

            destruct (vector_inv_S c₁) as (ch₁ & ctl₁ & He).

            destruct (vector_inv_S r₂) as (rh₂ & rtl₂ & Hi).
            destruct (vector_inv_S gs) as (gsh & gstl & Hgg).
            destruct (vector_inv_S hs) as (hsh & hstl & Hk).
            specialize (IHn gstl hstl atl c₁ rtl₁ c₂ rtl₂).
            rewrite Hd, Hf, He, Hk, Hgg in Ha;

            cbn in Hb.

            destruct Hb as [Hbl Hbr].

            rewrite <-Hg in Hbr.

              construct_and_conversations_simulator,
              construct_and_conversations_schnorr_commitment,
              construct_and_conversations_schnorr_response,
              construct_and_conversations_simulator_commitment in ×.
            cbn in ×.
            inversion ih as [[ha hr]].
            f_equal.
            × f_equal;
              [apply schnorr_commitment_shift; symmetry; exact (Rm Fin.F1) | exact ha].
            × f_equal; exact hr.
        Qed.

Special HVZK, distribution equality._ If for every x the translation u ↦ u + c · x permutes lf as a multiset, then the real and simulated distributions for the section statement are permutations of each other. Proof: construct_and_shift, repeat_uniform_perm and bind_ret_perm.
        Theorem generalised_and_special_honest_verifier_zkp_perm :
          ∀ (lf : list F) (Hlfn : lf ≠ List.nil) (c : F),
          (∀ x : F, Permutation (List.map (fun u ⇒ u + c × x) lf) lf) →
          Permutation
            (@generalised_and_schnorr_distribution n lf Hlfn xs gs c)
            (@generalised_and_simulator_distribution n lf Hlfn gs hs c).
        Proof.
          intros × hp.
          change (Permutation
            (Bind (repeat_dist_ntimes_vector (uniform_with_replacement lf Hlfn) n)
              (fun us ⇒ Ret (construct_and_conversations_schnorr xs gs us c)))
            (Bind (repeat_dist_ntimes_vector (uniform_with_replacement lf Hlfn) n)
              (fun us ⇒ Ret (construct_and_conversations_simulator gs hs us c)))).
          eapply bind_ret_perm with
            (phi := vec_apply (Vector.map (fun x u ⇒ u + c × x) xs)).
          + apply repeat_uniform_perm; intros i.
            rewrite (nth_map _ _ i i eq_refl).
            apply hp.
          + intros us p _.
            apply construct_and_shift; exact R.
        Qed.

Special HVZK for an enumerated field._ If lf lists every element of F exactly once, the real and simulated transcript distributions are equal up to permutation.
        Theorem generalised_and_special_honest_verifier_zkp_enum :
          ∀ (lf : list F) (Hlfn : lf ≠ List.nil) (c : F),
          List.NoDup lf → (∀ y : F, List.In y lf) →
          Permutation
            (@generalised_and_schnorr_distribution n lf Hlfn xs gs c)
            (@generalised_and_simulator_distribution n lf Hlfn gs hs c).
        Proof.
          intros × hnd hall.
          eapply generalised_and_special_honest_verifier_zkp_perm.
          intro x.
          eapply enumerates_perm_map with (psi := fun u ⇒ u - c × x);
          [exact hnd | exact hall | intros u; field | intros u; field].
        Qed.
