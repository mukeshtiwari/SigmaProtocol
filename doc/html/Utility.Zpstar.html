Library Utility.Zpstar

The groups Z_p^*, the field Z_p and Schnorr groups

This file provides the concrete algebraic structures over which most protocols of the development are instantiated (see the ×Ins.v files in Examples, for example ElgamalIns.v, ChaumPedersenIns.v or BayerGrothIns.v). It contains four modules, each parameterised over primes given as section Context variables:
  • Zpgroup: the multiplicative group Z_p^* = {1, …, p-1} for a prime p, with multiplication modulo p and inverse a ↦ a^(p-2) mod p; the main result is the instance zpstar_comm of commutative_group (from Algebra/Hierarchy.v).
  • Zpfield: the prime field Z_p, with elements represented as integers v satisfying v mod p = v; the main result is the instance zp_field of field.
  • Schnorr: the Schnorr group, that is, the subgroup of order q of Z_p^* for primes p = k·q + 1, described as the set of v with 0 < v < p and v^q ≡ 1 (mod p); the main result is schnorr_comm.
  • Vspace: exponentiation g ↦ g^x makes the Schnorr group a vector space over Z_q in the sense of Algebra/Hierarchy.v (written additively, it is a Z_q-module); the instance is pow_vspace. This is the form in which a prime-order group enters the generic Sigma protocol and ElGamal developments: scalars are Zpfield.Zp q and group elements are Schnorr.Schnorr_group p q.
Elements are dependent records that pair an integer with a proof of its range condition. Because the conditions are decidable equalities on Z or comparison, their proofs are unique (by Eqdep_dec), so two elements are equal as soon as their integer components are equal (construct_zpstar, construct_zp, construct_schnorr_group). Operations are defined with refine and closed with Defined, so that they compute after extraction; side conditions are discharged with abstract, which keeps the proof terms out of the computational code. Equality deciders such as dec_zpstar are also closed with Defined because the extracted verifiers use them to compare group elements.
Inverses are computed with Fermat's little theorem: for 0 < a < p, a · a^(p-2) = a^(p-1) ≡ 1 (mod p) (Fermat.fermat_little_ZZ), and Fermat.fermat_bound shows a^(p-2) mod p is again in {1, …, p-1}. The exponentiation itself is the executable square-and-multiply Functions.Npow_mod on N, related to Zpow_mod by Functions.zmod_nmod. Several arithmetic facts (multiplication_bound, Hp_2_p, mod_more_gen_bound, mod_exists_pos) come from the prime-modulus section at the end of Util.v.

The multiplicative group Z_p^*

Module Zpgroup.

The section is parameterised by a prime p.
  Section ZpstarGroup.
    Context
      {p : Z}
      {Hp : prime p}.

An element of Z_p^*: an integer v with a proof that 0 < v < p.
    Record Zpstar :=
      mk_zpstar {v : Z; Hv : 0 < v < p}.

Proof irrelevance for < on Z: since x < y unfolds to the equation Z.compare x y = Lt on a type with decidable equality, any two proofs are equal.
    Lemma dec_lt_general :
      ∀ x y (Hx Hy: (x < y)), Hx = Hy.
    Proof.
      intros; apply Eqdep_dec.eq_proofs_unicity;
      intros u v; destruct u; destruct v; auto;
      try (right; intro Hpp; inversion Hpp).
    Qed.

Any two proofs of 0 < x < p are equal.
    Lemma uniqueness_zpstar_proof :
      ∀ x (Hx Hy : (0 < x < p)), Hx = Hy.
    Proof.
      intros ? [Hxl Hxr] [Hyl Hyr];
      f_equal; apply dec_lt_general.
    Qed.

Decidable equality of Z_p^* elements, by comparing the integers. Closed with Defined so that it reduces and extracts.
    Lemma dec_zpstar : ∀ x y : Zpstar, {x = y} + {x ≠ y}.
    Proof.
      intros [x Hx] [y Hy].
      destruct (Z.eq_dec x y) as [Hl | Hr].
      left. subst. f_equal.
      apply uniqueness_zpstar_proof.
      right. intro H; inversion H;
      contradiction.
    Defined.

Two elements with equal integer components are equal, whatever their range proofs.
    Lemma construct_zpstar :
      ∀ x y
      (Hx : 0 < x < p)
      (Hy : 0 < y < p),
      x = y →
      mk_zpstar x Hx = mk_zpstar y Hy.
    Proof.
      intros; subst; f_equal.
      apply uniqueness_zpstar_proof.
    Qed.

The identity element 1.
    Definition one : Zpstar.
      refine (mk_zpstar 1 _).
      pose proof (prime_ge_2 _ Hp).
      abstract nia.
    Defined.

Group multiplication: (a, b) ↦ a · b mod p. The result is nonzero because p is prime (multiplication_bound in Util.v).
    Definition mul_zpstar (u v : Zpstar) : Zpstar.
      refine(
        match u, v with
        | mk_zpstar au Hu, mk_zpstar av Hv ⇒
          mk_zpstar
            (Z.modulo (au × av) p)
            (@multiplication_bound p Hp _ _ Hu Hv)
        end).
    Defined.

Fermat's little theorem for the executable exponentiation: a^(p-1) mod p = 1 for 0 < a < p, computed with Npow_mod.
    Lemma fermat_theorem :
      ∀ au,
      0 < au < p →
      Z.of_N (Npow_mod (Z.to_N au) (Z.to_N (p - 1)) (Z.to_N p)) = 1.
    Proof.
      intros ? Hau.
      rewrite zmod_nmod,
      !Z2N.id.
      rewrite fermat_little_ZZ;
      try nia; try assumption.
      all:try nia.
      rewrite !Z2N.id.
      exact Hp.
      nia.
    Qed.

The Fermat inverse a^(p-2) mod p, computed with Npow_mod, lies in {1, …, p-1} when 0 < a < p.
    Lemma mod_bound : ∀ au,
      0 < au < p →
      0 < Z.of_N (Npow_mod (Z.to_N au) (Z.to_N (p - 2)) (Z.to_N p)) < p.
    Proof.
      intros ? Ha.
      rewrite zmod_nmod,
      !Z2N.id.
      apply fermat_bound.
      exact Hp.
      all:try nia.
      rewrite Z2N.id.
      exact Hp.
      nia.
    Qed.

Group inverse: a ↦ a^(p-2) mod p, computed by square-and-multiply on N. That it is an inverse is zpstar_left_inv.
    Definition inv_zpstar (u : Zpstar) : Zpstar.
      refine(
        match u with
        | mk_zpstar au Hu ⇒ mk_zpstar
            (Z.of_N (Npow_mod (Z.to_N au) (Z.to_N (p - 2)) (Z.to_N p)))
            (mod_bound _ Hu)
        end).
    Defined.

Multiplication modulo p is associative.
    Lemma zpstar_mul_associative :
      ∀ x y z : Zpstar,
      mul_zpstar x (mul_zpstar y z) =
      mul_zpstar (mul_zpstar x y) z.
    Proof.
      pose proof @H_0_p p Hp.
      intros ? ? ?;
      destruct x as [x Hx];
      destruct y as [y Hy];
      destruct z as [z Hz];
      simpl in × |- ×.
      eapply construct_zpstar.
      rewrite Z.mul_mod_idemp_l.
      rewrite Z.mul_mod_idemp_r.
      rewrite Z.mul_assoc.
      reflexivity.
      all:nia.
    Qed.

1 · x = x.
    Lemma one_is_left_identity :
      ∀ x, mul_zpstar one x = x.
    Proof.
      intro x.
      unfold mul_zpstar, one.
      destruct x as [x Hx].
      refine(construct_zpstar _ _ _ _ _).
      rewrite Z.mul_1_l.
      apply mod_not_zero_one.
      exact Hx.
    Qed.

x · 1 = x.
    Lemma one_is_right_identity :
      ∀ x, mul_zpstar x one = x.
    Proof.
      intro x.
      unfold mul_zpstar, one.
      destruct x as [x Hx].
      refine(construct_zpstar _ _ _ _ _).
      rewrite Z.mul_1_r.
      apply mod_not_zero_one.
      exact Hx.
    Qed.

Multiplication modulo p is commutative.
    Lemma zpstar_mul_commutative :
      ∀ x y : Zpstar,
      mul_zpstar x y = mul_zpstar y x.
    Proof.
      destruct x as [x Hx];
      destruct y as [y Hy]; simpl.
      refine(construct_zpstar _ _ _ _ _).
      rewrite Z.mul_comm.
      reflexivity.
    Qed.

mul_zpstar respects Leibniz equality (a trivial Proper instance required by the algebraic hierarchy).
    Global Instance zpstar_mul_proper :
      Proper (eq ==> eq ==> eq) mul_zpstar.
    Proof.
      intros x y Hxy z u Hzu.
      destruct x as [x Hx]; destruct y as [y Hy];
      destruct z as [z Hz]; destruct u as [u Hu]; simpl in × |- ×.
      refine(construct_zpstar _ _ _ _ _).
      inversion Hxy; inversion Hzu; subst; reflexivity.
    Defined.

Left inverse law: a^(p-2) · a ≡ 1 (mod p). After converting Npow_mod to Zpow_mod, the product is a^(p-1) mod p, which is 1 by fermat_little_ZZ.
    Lemma zpstar_left_inv :
      ∀ x, mul_zpstar (inv_zpstar x) x = one.
    Proof.
      intros ?.
      unfold mul_zpstar, inv_zpstar, one.
      destruct x as (v & Hv).
      apply construct_zpstar.
      rewrite Z.mul_comm.
      rewrite zmod_nmod, Zpow_mod_correct.
      rewrite !Z2N.id.
      rewrite Zmult_mod_idemp_r.
      pose proof @Hp_2_p p Hp.
      assert (Hpp : p - 1 = 1 + (p - 2)).
      nia.
      assert (Ht : v × v ^ (p - 2) = v ^ (p - 1)).
      rewrite Hpp.
      rewrite Z.pow_add_r.
      all:try nia.
      rewrite Ht.
      rewrite <- Zpow_mod_correct.
      apply fermat_little_ZZ.
      exact Hp.
      exact Hv.
      nia.
      rewrite Z2N.id.
      exact Hp.
      nia.
    Qed.

Right inverse law: a · a^(p-2) ≡ 1 (mod p), by the same argument.
    Lemma zpstar_right_inv :
      ∀ x, mul_zpstar x (inv_zpstar x) = one.
    Proof.
      intros ?.
      unfold mul_zpstar, inv_zpstar, one.
      destruct x as (v & Hv).
      apply construct_zpstar.
      rewrite zmod_nmod, Zpow_mod_correct.
      rewrite !Z2N.id.
      rewrite Zmult_mod_idemp_r.
      pose proof @Hp_2_p p Hp.
      assert (Hpp : p - 1 = 1 + (p - 2)).
      nia.
      assert (Ht : v × v ^ (p - 2) = v ^ (p - 1)).
      rewrite Hpp.
      rewrite Z.pow_add_r.
      all:try nia.
      rewrite Ht.
      rewrite <- Zpow_mod_correct.
      apply fermat_little_ZZ.
      exact Hp.
      exact Hv.
      nia.
      rewrite Z2N.id.
      exact Hp.
      nia.
    Qed.

Z_p^* with mul_zpstar, one and inv_zpstar is a commutative group (with Leibniz equality).
    Global Instance zpstar_comm : @commutative_group
      Zpstar (@eq Zpstar) mul_zpstar one inv_zpstar.
    Proof.
      repeat econstructor.
      + unfold is_associative;
        intros ? ? ?.
        apply zpstar_mul_associative.
      + intro x. apply one_is_left_identity.
      + intro x. apply one_is_right_identity.
      + apply zpstar_mul_proper.
      + intros x y Hxy. rewrite Hxy. reflexivity.
      + intros x y z Hxy Hyz. rewrite Hxy. exact Hyz.
      + intro x. apply zpstar_left_inv.
      + intro x. apply zpstar_right_inv.
      + intros x y Hxy. rewrite Hxy. reflexivity.
      + intros x y. apply zpstar_mul_commutative.
    Qed.

  End ZpstarGroup.
End Zpgroup.

The prime field Z_p

Module Zpfield.

The section is parameterised by a prime p.
  Section ZpField.

    Context
      {p : Z}
      {Hp : prime p}.

An element of Z_p: an integer v in canonical form, witnessed by v mod p = v (equivalently 0 ≤ v < p, see mod_more_gen_bound). The canonical-form condition is an equation on Z, so its proofs are unique (zple_gen).
    Record Zp :=
      mk_zp {v : Z; Hv : Z.modulo v p = v}.

The additive identity 0.
    Definition zero : Zp.
      refine (mk_zp 0 (Z.mod_0_l _ _)).
      pose proof prime_ge_2 _ Hp as Ht.
      abstract nia.
    Defined.

The multiplicative identity 1 (canonical because p ≥ 2).
    Definition one : Zp.
      refine(mk_zp 1 (Z.mod_1_l _ _ )).
      pose proof prime_ge_2 _ Hp as Ht.
      abstract nia.
    Defined.

Addition modulo p.
    Definition zp_add (x y : Zp) : Zp.
      refine (match x, y with
        | mk_zp ax _, mk_zp ay _ ⇒ mk_zp (Z.modulo (ax + ay) p) _
      end).
      rewrite Zmod_mod.
      exact eq_refl.
    Defined.

Subtraction modulo p (Z.modulo always returns a value in {0, …, p-1} for p > 0).
    Definition zp_sub (x y : Zp) : Zp.
      refine (match x, y with
      | mk_zp ax _, mk_zp ay _ ⇒ mk_zp (Z.modulo (ax - ay) p) _
      end).
      rewrite Zmod_mod.
      exact eq_refl.
    Defined.

Additive inverse, defined as 0 - x mod p.
    Definition zp_opp (x : Zp) : Zp :=
      zp_sub zero x.

Multiplication modulo p.
    Definition zp_mul (x y : Zp) : Zp.
      refine (match x, y with
        | mk_zp ax _, mk_zp ay _ ⇒ mk_zp (Z.modulo (ax × ay) p) _
      end).
      rewrite Zmod_mod.
      exact eq_refl.
    Defined.

Multiplicative inverse x ↦ x^(p-2) mod p, computed with Npow_mod. It is an inverse for x ≠ 0 (zp_mul_left_inv); on 0 it returns 0^(p-2) mod p, which is 0 for p > 2 and 1 for p = 2.
    Definition zp_inv (x : Zp) : Zp.
      refine (match x with
        | mk_zp ax Hu ⇒ mk_zp
          (Z.modulo
            (Z.of_N (Npow_mod (Z.to_N ax) (Z.to_N (p - 2)) (Z.to_N p)))
            p) _
      end).
      rewrite Zmod_mod.
      exact eq_refl.
    Defined.

Division x / y = x · y⁻¹.
    Definition zp_div (x y : Zp) : Zp :=
      zp_mul x (zp_inv y).

Any two proofs of v mod p = v are equal (uniqueness of identity proofs on Z).
    Lemma zple_gen :
      ∀ v
      (H₁ H₂ : Z.modulo v p = v),
      H₁ = H₂.
    Proof.
      intros v ? ?.
      apply UIP_dec,
      Z.eq_dec.
    Qed.

Two field elements with equal integer components are equal.
    Lemma construct_zp :
      ∀ x y
      (Hx : Z.modulo x p = x)
      (Hy : Z.modulo y p = y),
      x = y →
      mk_zp x Hx = mk_zp y Hy.
    Proof.
      intros; subst; f_equal.
      apply zple_gen.
    Qed.

Decidable equality on Z_p, closed with Defined so that it computes.
    Lemma zp_dec: ∀ x y : Zp, {x = y} + {x ≠ y}.
    Proof.
      intros x y. destruct x as [x Hx]; destruct y as [y Hy]; simpl.
      destruct (Z.eq_dec x y) as [Hl | Hr]. left.
      refine(construct_zp _ _ _ _ Hl).
      right. intro H; inversion H; contradiction.
    Defined.

zp_opp x = zp_sub zero x (true by definition).
    Lemma zp_opp_sub :
      ∀ x, zp_opp x = zp_sub zero x.
    Proof.
      intros [x Hx]; unfold zero, zp_opp, zp_sub; simpl.
      refine(construct_zp _ _ _ _ _); reflexivity.
    Qed.

x · y⁻¹ = x / y (true by definition).
    Lemma zp_mul_inv_div :
    ∀ x y, zp_mul x (zp_inv y) = zp_div x y.
    Proof.
      intros [x Hx] [y Hy]; simpl.
      refine(construct_zp _ _ _ _ _).
      reflexivity.
    Qed.

Field axioms

Each axiom of field from Algebra/Hierarchy.v is proved separately by unfolding the operations and using the arithmetic of mod.
Addition modulo p is associative.
    Lemma zp_add_assoc:
      ∀ x y z : Zp,
      zp_add x (zp_add y z) = zp_add (zp_add x y) z.
    Proof.
      pose (@H_0_p p Hp) as Hpp.
      intros [x Hx] [y Hy] [z Hz]; simpl.
      refine (construct_zp _ _ _ _ _).
      rewrite Z.add_mod_idemp_l.
      rewrite Z.add_mod_idemp_r.
      rewrite Z.add_assoc.
      reflexivity.
      all:nia.
    Qed.

0 + x = x.
    Lemma zp_add_zero_left_identity :
      ∀ x, zp_add zero x = x.
    Proof.
      intros [x Hx]; simpl.
      refine (construct_zp _ _ _ _ _).
      exact Hx.
    Qed.

x + 0 = x.
    Lemma zp_add_zero_right_identity :
      ∀ x, zp_add x zero = x.
    Proof.
      intros [x Hx]; simpl.
      refine (construct_zp _ _ _ _ _).
      rewrite Z.add_0_r.
      exact Hx.
    Qed.

zp_add respects equality.
    Global Instance zp_add_proper : Proper (eq ==> eq ==> eq) zp_add.
    Proof.
      intros x y Hxy u v Huv; subst; reflexivity.
    Qed.

Symmetry and transitivity of Leibniz equality on Zp, packaged as instances for the hierarchy.
    Global Instance eq_sym : @Symmetric Zp eq.
    Proof.
      intros x y Hxy. subst; reflexivity.
    Qed.

    Global Instance eq_trans : @Transitive Zp eq.
    Proof.
      intros x y z Hxy Hyz; subst; reflexivity.
    Qed.

(-x) + x = 0.
    Lemma zp_add_opp_left_inv :
      ∀ x, zp_add (zp_opp x) x = zero.
    Proof.
      intros [x Hx]; simpl.
      refine (construct_zp _ _ _ _ _).
      rewrite Zplus_mod_idemp_l.
      rewrite Z.add_opp_diag_l.
      rewrite Zmod_0_l; reflexivity.
    Qed.

x + (-x) = 0.
    Lemma zp_add_opp_right_inv :
      ∀ x, zp_add x (zp_opp x) = zero.
    Proof.
      intros [x Hx]; simpl.
      refine (construct_zp _ _ _ _ _).
      rewrite Zplus_mod_idemp_r.
      rewrite Z.add_opp_diag_r.
      rewrite Zmod_0_l; reflexivity.
    Qed.

zp_opp respects equality.
    Global Instance zp_opp_proper : Proper (eq ==> eq) zp_opp.
    Proof.
      intros x y Hx; subst; reflexivity.
    Qed.

Addition is commutative.
    Lemma zp_add_comm :
      ∀ x y, zp_add x y = zp_add y x.
    Proof.
      intros [x Hx] [y Hy]; simpl;
      refine (construct_zp _ _ _ _ _).
      rewrite Z.add_comm; reflexivity.
    Qed.

Multiplication is associative.
    Lemma zp_mul_assoc :
      ∀ x y z,
      zp_mul x (zp_mul y z) = zp_mul (zp_mul x y) z.
    Proof.
      pose (@H_0_p p Hp) as Hpp.
      intros [x Hx] [y Hy] [z Hz]; simpl;
      refine (construct_zp _ _ _ _ _).
      rewrite Z.mul_mod_idemp_l.
      rewrite Z.mul_mod_idemp_r.
      rewrite Z.mul_assoc. reflexivity.
      all:nia.
    Qed.

1 · x = x.
    Lemma zp_mul_one_left_id :
      ∀ x, zp_mul one x = x.
    Proof.
      intros [x Hx];
      refine (construct_zp _ _ _ _ _).
      rewrite Z.mul_1_l.
      exact Hx.
    Qed.

x · 1 = x.
    Lemma zp_mul_one_right_id :
      ∀ x, zp_mul x one = x.
    Proof.
      intros [x Hx];
      refine (construct_zp _ _ _ _ _).
      rewrite Z.mul_1_r; exact Hx.
    Qed.

zp_mul respects equality.
    Global Instance zp_mul_proper: Proper (eq ==> eq ==> eq) zp_mul.
    Proof.
      intros x y Hxy u v Huv; subst; reflexivity.
    Qed.

Left distributivity: x · (y + z) = x·y + x·z.
    Lemma mul_dist_add_left :
      ∀ x y z,
      zp_mul x (zp_add y z) = zp_add (zp_mul x y) (zp_mul x z).
    Proof.
      pose (@H_0_p p Hp) as Hpp.
      intros [x Hx] [y Hy] [z Hz];
      refine (construct_zp _ _ _ _ _).
      rewrite Z.mul_mod_idemp_r,
        Z.add_mod_idemp_l,
        Z.add_mod_idemp_r,
        Z.mul_add_distr_l;
        try reflexivity;
        try nia.
    Qed.

Right distributivity: (y + z) · x = y·x + z·x.
    Lemma mul_dist_add_right :
      ∀ x y z,
      zp_mul (zp_add y z) x = zp_add (zp_mul y x) (zp_mul z x).
    Proof.
      pose (@H_0_p p Hp) as Hpp.
      intros [x Hx] [y Hy] [z Hz];
      refine (construct_zp _ _ _ _ _).
      rewrite Z.mul_mod_idemp_l,
      Z.add_mod_idemp_r, Z.mul_add_distr_r,
      Zplus_mod_idemp_l;
      try reflexivity; try nia.
    Qed.

Subtraction is addition of the opposite: x - y = x + (-y).
    Lemma zp_sub_add_opp :
      ∀ x y : Zp, zp_sub x y = zp_add x (zp_opp y).
    Proof.
      intros [x Hx] [y Hy]; simpl;
      refine (construct_zp _ _ _ _ _).
      rewrite Zplus_mod_idemp_r, Z.add_opp_r;
      reflexivity.
    Qed.

Schnorr groups

For primes p and q with p = k·q + 1, the Schnorr group is the unique subgroup of order q of Z_p^*. It equals the set of k-th powers modulo p, because (w^k)^q = w^(p-1) ≡ 1; here it is described directly by the condition v^q ≡ 1 (mod p). This is the prime-order group used for discrete-log based protocols (Schnorr, Chaum–Pedersen, ElGamal, and so on).

The Schnorr group as a vector space over Z_q

Scalars are elements of the field Zpfield.Zp q and vectors are elements of Schnorr.Schnorr_group p q; scalar multiplication is exponentiation pow g x = g^x mod p.       apply Schnorr.construct_schnorr_group;
      cbn.
      exact eq_refl.
    Qed.

Compatibility of scalar multiplication with field multiplication: g^(u·v mod q) = (g^u)^v. Write u·v = k₁·q + w₁ with w₁ = u·v mod q; then g^(u·v) = (g^q)^k₁ · g^w₁ ≡ g^w₁ since g^q ≡ 1.
    Lemma is_smul_associative_fmul_proof :
      ∀
      (g : @Schnorr.Schnorr_group p q)
      (u v : @Zpfield.Zp q),
      pow g (Zpfield.zp_mul u v) = pow (pow g u) v.
    Proof.
      intros [g Hg] [u Hu] [v Hv].
      apply Schnorr.construct_schnorr_group.
      rewrite !zmod_nmod,
      !Z2N.id, !Zpow_mod_correct,
      <-Zpower_mod,
      <-Z.pow_mul_r.
      eapply mod_more_gen_bound in Hu, Hv.
      assert (Htt : 0 ≤ u × v) by nia.
      destruct (@mod_exists_pos q Hq (u × v) Htt) as
      [k₁ [w₁ [Hl [Hr Hw]]]].
      rewrite Hl.
      eapply mod_more_gen_bound in Hr.
      replace (k₁ × q + w₁) with
      (w₁ + k₁ × q).
      rewrite Z_mod_plus_full,
      Hr,
      Z.pow_add_r,
      Zmult_mod.
      replace (k₁ × q) with (q × k₁).
      rewrite Z.pow_mul_r.
      assert (Hvt : (g ^ q) ^ k₁ mod p =
        (g ^ q mod p) ^ k₁ mod p).
      rewrite Zpower_mod;
      try reflexivity.
      nia.
      rewrite Zpow_mod_correct in Hb.
      rewrite Hvt, Hb.
      rewrite Z.pow_1_l,
      Z.mod_1_l,
      Z.mul_1_r,
      Zmod_mod;
      try reflexivity.
      all: try nia.
      eapply mod_more_gen_bound in Hr;
      try nia.
      try (eapply mod_more_gen_bound in Hu;
      try nia).
      all : (eapply mod_more_gen_bound in Hv;
      try nia).
      eapply mod_more_gen_bound in Hu;
      try nia.
      rewrite Z2N.id.
      eapply mod_more_gen_bound in Hu.
      destruct Hu as [Hul Hur].
      pose proof fermat_bound_gen
        g u p Hp Hul Hg.
      nia.
      eapply mod_more_gen_bound in Hu;
      try nia.
      eapply Z_mod_nonneg_nonneg;
      try nia.
      eapply mod_more_gen_bound in Hu.
      try nia.
      all: rewrite Z2N.id;
        try nia; exact Hp.
      Unshelve.
      all: try (exact Hp); try (exact Hq).
    Qed.

Distributivity over field addition: g^((u+v) mod q) = g^u · g^v, by the same reduction of the exponent modulo q.
    Lemma is_smul_distributive_fadd_proof :
      ∀
      (g : @Schnorr.Schnorr_group p q)
      (u v : @Zpfield.Zp q),
      pow g (Zpfield.zp_add u v) =
      @Schnorr.mul_schnorr_group p q Hp Hq (pow g u) (pow g v).
    Proof.
      intros [g Hg] [u Hu] [v Hv].
      apply Schnorr.construct_schnorr_group.
      rewrite !zmod_nmod,
      !Z2N.id, !Zpow_mod_correct,
      <-Zmult_mod,
      <-Z.pow_add_r.
      eapply mod_more_gen_bound in Hu, Hv.
      assert (Htt : 0 ≤ u + v) by nia.
      destruct (@mod_exists_pos q Hq (u + v) Htt) as
      [k₁ [w₁ [Hl [Hr Hw]]]].
      rewrite Hl.
      eapply mod_more_gen_bound in Hr.
      replace (k₁ × q + w₁) with
      (w₁ + k₁ × q).
      rewrite Z_mod_plus_full,
      Hr,
      Z.pow_add_r,
      Zmult_mod.
      replace (k₁ × q) with (q × k₁).
      rewrite Z.pow_mul_r.
      assert (Hvt : (g ^ q) ^ k₁ mod p =
        (g ^ q mod p) ^ k₁ mod p).
      rewrite Zpower_mod;
      try reflexivity.
      nia.
      rewrite Zpow_mod_correct in Hb.
      rewrite Hvt, Hb.
      rewrite Z.pow_1_l,
      Z.mod_1_l,
      Z.mul_1_r,
      Zmod_mod;
      try reflexivity.
      all: try nia.
      eapply mod_more_gen_bound in Hr;
      try nia.
      try (eapply mod_more_gen_bound in Hu;
      try nia).
      all : (eapply mod_more_gen_bound in Hv;
      try nia).
      eapply mod_more_gen_bound in Hu;
      try nia.
      all: eapply mod_more_gen_bound in Hu, Hv; try nia.
      all: try rewrite Z2N.id;
        try nia; try (exact Hp).
      eapply mod_more_gen_bound in Hu, Hv;
      eapply Z_mod_nonneg_nonneg;
      try nia.
      eapply mod_more_gen_bound in Hu.
      nia.
      Unshelve.
      all: try (exact Hp); try (exact Hq).
    Qed.

Distributivity over group multiplication: (u·v)^r = u^r · v^r modulo p.
    Lemma is_smul_distributive_vadd_proof :
      ∀
      (u v : @Schnorr.Schnorr_group p q)
      (r : @Zpfield.Zp q),
      pow (@Schnorr.mul_schnorr_group p q Hp Hq u v) r =
      @Schnorr.mul_schnorr_group p q Hp Hq (pow u r) (pow v r).
    Proof.
      intros [u Hua Hub] [v Hva Hvb] [r Hr].
      apply Schnorr.construct_schnorr_group.
      rewrite !zmod_nmod,
      !Z2N.id, !Zpow_mod_correct,
      <-Zpower_mod,
      Z.pow_mul_l,
      Zmult_mod;
      try reflexivity.
      all: try nia.
      eapply mod_more_gen_bound in Hr.
      try nia.
      pose proof @multiplication_bound p Hp u v Hua Hva.
      try nia.
      all: rewrite Z2N.id;
      [exact Hp | nia].
      Unshelve.
      exact Hq.
    Qed.

The Schnorr group with exponentiation is a vector space over Z_q: the group axioms come from Schnorr.schnorr_comm, the field axioms from Zpfield.zp_field and the action axioms from the four lemmas above.
    Global Instance pow_vspace :
      @vector_space
        (@Zpfield.Zp q)
        (@eq (@Zpfield.Zp q))
        (@Zpfield.zero q Hq)
        (@Zpfield.one q Hq)
        (@Zpfield.zp_add q)
        (@Zpfield.zp_mul q)
        (@Zpfield.zp_sub q)
        (@Zpfield.zp_div q)
        (@Zpfield.zp_opp q Hq)
        (@Zpfield.zp_inv q)
        (@Schnorr.Schnorr_group p q)
        (@eq (@Schnorr.Schnorr_group p q))
        (@Schnorr.one p q Hp Hq)
        (@Schnorr.inv_schnorr_group k p q Hk Hp Hq)
        (@Schnorr.mul_schnorr_group p q Hp Hq)
        pow.
    Proof.
      econstructor.
      + apply Schnorr.schnorr_comm.
      + apply Zpfield.zp_field.
      + intros ?; apply is_field_one_proof.
      + intros ?; apply is_field_zero_proof.
      + intros ? ? ?;
        apply is_smul_associative_fmul_proof.
      + intros ? ? ?;
        apply is_smul_distributive_fadd_proof.
      + intros ? ? ?;
        apply is_smul_distributive_vadd_proof.
      + intros x y Heq u v Huv.
        subst. reflexivity.
    Qed.

  End VectorSpace.
