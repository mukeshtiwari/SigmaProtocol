Inequality of discrete logarithms (NEQ)

This file formalises a Σ-protocol for k = 2 + n discrete-logarithm statements hs[i] = gs[i] ^ xs[i] whose witnesses are pairwise distinct. The prover shows that it knows xs such that

      ∀ i, hs[i] = gs[i] ^ xs[i] and ∀ i ≠ j, xs[i] ≠ xs[j]
The protocol combines two existing proofs and uses one verifier challenge c for all of them:
  • an AND-composition of k Schnorr proofs, one for each hs[i] = gs[i] ^ xs[i], taken from AndSigmaGen;
  • for every unordered pair (i, j) (there are k (k - 1) / 2 of them, listed by generate_pairs_of_vector), an Okamoto proof from Okamoto of a representation of gs[j] in the two bases gs[i] · gs[j] and hs[i] · hs[j]:

      gⱼ = (gᵢ · gⱼ) ^ a · (hᵢ · hⱼ) ^ b, a = xᵢ / (xᵢ - xⱼ), b = 1 / (xⱼ - xᵢ)
When hᵢ = gᵢ ^ xᵢ and hⱼ = gⱼ ^ xⱼ, the right-hand side is gᵢ ^ (a + b xᵢ) · gⱼ ^ (a + b xⱼ). The first exponent is 0 and the second is 1, so the equation holds; the witness (a, b) exists only when xᵢ ≠ xⱼ. Conversely, if xᵢ = xⱼ = y then hᵢ · hⱼ = (gᵢ · gⱼ) ^ y, and any representation gives gⱼ = (gᵢ · gⱼ) ^ γ with γ = a + b y. That is a non-trivial discrete-logarithm relation between gᵢ and gⱼ, or one of them is the identity.
Sizes: a transcript has k + k (k - 1) / 2 commitments, a challenge vector of length 1 and k + k (k - 1) responses, written (2 + n) + (2 + n) (1 + n) in the types. The prover consumes as many random scalars as there are responses. The proof therefore grows quadratically in k.
Main results:
  • completeness generalised_neq_real_transcript_accepting_conversations: if gs[i] ^ xs[i] = hs[i] for all i and the xs are pairwise distinct, the honest transcript is accepted for all randomness and challenges;
  • simulator correctness generalised_neq_simulator_transcript_accepting_conversations: the simulator's transcripts are always accepted;
  • special soundness generalised_neq_accepting_conversations_soundness: from two accepting transcripts with the same commitments and different challenges one obtains xs with hs[i] = gs[i] ^ xs[i], and either the xs are pairwise distinct, or for some i ≠ j the generator gs[j] is a power of gs[i], or gs[i] or gs[j] is the identity. The theorem does not assume independent generators; it states this dichotomy instead. See the remark on that theorem for how weak the second alternative is in a cyclic group;
  • special honest-verifier zero knowledge: the weak form generalised_neq_special_honest_verifier_zkp compares the two distributions after mapping each transcript to its verification bit. The strong form generalised_neq_special_honest_verifier_zkp_perm shows that the real and simulated distributions are permutations of each other when the sampling list enumerates the field without duplicates.
The file depends on Sigma for transcripts, on AndSigmaGen for the AND-composition and its soundness (generalise_and_sigma_soundness_neq), on Okamoto for the two-base representation proof and its special soundness, and on Utility.Util for generate_pairs_of_vector, pair_zip, pair_unzip and nat_div_2 (the identity k (k - 1) / 2 + k (k - 1) / 2 = k (k - 1)). It is instantiated in Examples.NeqSigmaIns and extracted through Extraction/NeqSigmalib. The Okamoto protocol is from T. Okamoto, Provably Secure and Practical Identification Schemes and Corresponding Signature Schemes, CRYPTO 1992.

Definitions

Every definition splits its randomness or response vector at 2 + n: the first part belongs to the AND-composition of Schnorr proofs, the second part to the pairwise Okamoto proofs. The second part has length (2 + n) (1 + n). It is cast to P + P with P = (2 + n) (1 + n) / 2 (using nat_div_2) and grouped by pair_zip into P two-element vectors, one per pair.
    Section Def.

Prover commitment. From us = usl ++ usr it computes the AND commitments gs[i] ^ usl[i], one per statement, followed by one Okamoto commitment (gᵢ · gⱼ) ^ u₁ · (hᵢ · hⱼ) ^ u₂ per pair (i, j), where (u₁, u₂) is that pair's slice of usr. The commitment does not depend on the witness.
        Definition generalised_construct_neq_commitment {n : nat} :
          Vector.t G (2 + n) → Vector.t G (2 + n) →
          Vector.t F ((2 + n) + ((2 + n) × (1 + n))) →
          Vector.t G ((2 + n) + Nat.div ((2 + n) × (1 + n)) 2).
        Proof.
          intros gs hs us.
          destruct (splitat (2 + n) us) as (usl & usr).
          set (and_commit := @construct_and_conversations_schnorr_commitment
            F G gpow _ gs usl).
          set (gs_pairs := Vector.map (fun '(g₁, g₂) ⇒ gop g₁ g₂)
            (generate_pairs_of_vector gs)).
          set (hs_pairs := Vector.map (fun '(h₁, h₂) ⇒ gop h₁ h₂)
            (generate_pairs_of_vector hs)).
          assert(ha : ((Nat.div ((2 + n) × (1 + n)) 2) +
           (Nat.div ((2 + n) × (1 + n)) 2) =
          ((2 + n) × (1 + n)))%nat). eapply nat_div_2.
          rewrite <-ha in usr; clear ha.
          set (oka_commitment := zip_with (fun '(gg, hh) us ⇒
            @okamoto_commitment F G gid gop gpow
            [gg; hh] us) (zip_with pair gs_pairs hs_pairs)
            (pair_zip usr)).
          refine(and_commit ++ oka_commitment).
        Defined.

Prover response for challenge c. The AND part responds usl[i] + c · xs[i]; the Okamoto part of pair (i, j) responds to the witness (xᵢ · (xᵢ - xⱼ)⁻¹, (xⱼ - xᵢ)⁻¹) with its two random values. Here inv is the field inverse. It is total, so the definition makes sense even when two xs coincide, but the transcript is then not accepting in general. The pair responses are flattened back with pair_unzip.
        Definition generalised_construct_neq_response {n : nat} :
          Vector.t F (2 + n) → Vector.t F ((2 + n) + ((2 + n) × (1 + n))) →
          F → Vector.t F ((2 + n) + (2 + n) × (1 + n)).
        Proof.
          intros xs us c.
          set (xs_pair := generate_pairs_of_vector xs).
          destruct (splitat (2 + n) us) as (usl & usr).
          set (and_response := @construct_and_conversations_schnorr_response
            F add mul _ xs usl c).
          assert(ha : ((Nat.div ((2 + n) × (1 + n)) 2) +
           (Nat.div ((2 + n) × (1 + n)) 2) =
          ((2 + n) × (1 + n)))%nat). eapply nat_div_2.
          rewrite <-ha in usr; clear ha.
          set (oka_response := pair_unzip (zip_with (fun '(x₁, x₂) us ⇒
              @okamoto_response F add mul [x₁ × inv (x₁ - x₂); inv (x₂ - x₁)]
              us c) xs_pair (pair_zip usr))).
          rewrite nat_div_2 in oka_response.
          exact (and_response ++ oka_response).
        Defined.

Honest transcript (commitment; [c]; response) for witnesses xs, statement gs, hs, randomness us and challenge c.
        Definition generalised_construct_neq_conversations_real_transcript {n : nat} :
          Vector.t F (2 + n) → Vector.t G (2 + n) →
          Vector.t G (2 + n) →
          Vector.t F ((2 + n) + ((2 + n) × (1 + n))) → F →
          @sigma_proto F G ((2 + n) + Nat.div ((2 + n) × (1 + n)) 2) 1
            ((2 + n) + (2 + n) × (1 + n)).
        Proof.
          intros xs gs hs us c.
          exact (generalised_construct_neq_commitment gs hs us; [c];
          generalised_construct_neq_response xs us c).
        Defined.

Special honest-verifier simulator. It uses the randomness us directly as the response vector and computes the commitments that make every check pass: the AND simulator commitment gs[i] ^ usl[i] · hs[i] ^ (opp c), and for each pair the Okamoto simulator commitment for bases gᵢ · gⱼ and hᵢ · hⱼ and target gⱼ. The simulator does not use any witness.
        Definition generalised_construct_neq_conversations_simulator_transcript
          {n : nat} : Vector.t G (2 + n) → Vector.t G (2 + n) →
          Vector.t F ((2 + n) + ((2 + n) × (1 + n))) → F →
          @sigma_proto F G ((2 + n) + Nat.div ((2 + n) × (1 + n)) 2) 1
            ((2 + n) + (2 + n) × (1 + n)).
        Proof.
          intros gs hs us c.
          destruct (splitat (2 + n) us) as (usl & usr).
          set (and_sim_comm :=
            @construct_and_conversations_simulator_commitment
            F opp G gop gpow _ gs hs usl c).
          assert(ha : ((Nat.div ((2 + n) × (1 + n)) 2) +
           (Nat.div ((2 + n) × (1 + n)) 2) =
          ((2 + n) × (1 + n)))%nat). eapply nat_div_2.
          rewrite <-ha in usr; clear ha.
          set (oka_sim_comm := zip_with (fun '((g₁, g₂), (h₁, h₂)) vs ⇒
            @okamoto_simulator_protocol_commitment F opp G gid gop gpow
              [gop g₁ g₂; gop h₁ h₂] g₂ vs c)
              (zip_with pair
                (generate_pairs_of_vector gs)
                (generate_pairs_of_vector hs))
              (pair_zip usr)).
          refine (and_sim_comm ++ oka_sim_comm; [c]; us).
        Defined.

Verifier. It splits commitments and responses at 2 + n and first runs the AND verifier generalised_and_accepting_conversations on the Schnorr part. If that succeeds it checks, for every pair (i, j), the Okamoto equation (gᵢ · gⱼ) ^ r₁ · (hᵢ · hⱼ) ^ r₂ = aᵢⱼ · gⱼ ^ c with the pair's commitment aᵢⱼ and responses r₁ and r₂. It accepts iff all these checks pass.
        Definition generalised_neq_accepting_conversations {n : nat} :
          Vector.t G (2 + n) → Vector.t G (2 + n) →
          @sigma_proto F G ((2 + n) + Nat.div ((2 + n) × (1 + n)) 2) 1
            ((2 + n) + (2 + n) × (1 + n)) → bool.
        Proof.
          intros gs hs pf.
          refine
            match pf with
            |(a; c; r) ⇒ _
            end.
          destruct (splitat (2 + n) a) as (al & ar).
          destruct (splitat (2 + n) r) as (rl & rr).
          refine
            match
              @generalised_and_accepting_conversations F G gop gpow Gdec _
              gs hs (al; c; rl)
            with
            | true ⇒ _
            | _ ⇒ false
            end.
          assert(ha : ((Nat.div ((2 + n) × (1 + n)) 2) +
           (Nat.div ((2 + n) × (1 + n)) 2) =
          ((2 + n) × (1 + n)))%nat). eapply nat_div_2.
          rewrite <-ha in rr; clear ha.
          set (oka_veri :=
            (zip_with (fun '((g₁, g₂), (h₁, h₂)) '(a, rs) ⇒
            @okamoto_accepting_conversation F G gid gop gpow Gdec
              [gop g₁ g₂; gop h₁ h₂] g₂ ([a]; c; rs))
              (zip_with pair
                (generate_pairs_of_vector gs)
                (generate_pairs_of_vector hs))
              (zip_with pair ar (pair_zip rr)))).
            exact (vector_forallb (fun x ⇒ x) oka_veri).
        Defined.

Real transcript distribution for a fixed challenge c: draw (2 + n) + (2 + n) (1 + n) scalars independently and uniformly from the non-empty list lf and run the honest prover.
        Definition generalised_neq_schnorr_distribution
          {n : nat} (lf : list F) (Hlfn : lf ≠ List.nil)
          (xs : Vector.t F (2 + n)) (gs hs : Vector.t G (2 + n)) (c : F) :
          dist (@sigma_proto F G ((2 + n) + Nat.div ((2 + n) × (1 + n)) 2) 1
          ((2 + n) + (2 + n) × (1 + n))) :=
          us <- repeat_dist_ntimes_vector
            (uniform_with_replacement lf Hlfn) ((2 + n) + ((2 + n) × (1 + n))) ;;

Inversion lemma for the commitment: if the commitment on randomness usl ++ (usrl ++ usr) (after the length cast) equals al ++ ar, then al is the AND commitment on usl and ar is the vector of Okamoto commitments on the pairs.
      Theorem generalised_construct_neq_commitment_proof :
        ∀ (n : nat) (gs hs al : Vector.t G (2 + n))
        (ar : Vector.t G ((2 + n) × (1 + n) / 2))
        (usl : Vector.t F (2 + n))
        (usrl usrr : Vector.t F (Nat.div ((2 + n) × (1 + n)) 2)),
        generalised_construct_neq_commitment gs hs
          (usl ++ @eq_rect _ _ (Vector.t F)
          (usrl ++ usrr) _ (nat_div_2 n)) = al ++ ar →
        @construct_and_conversations_schnorr_commitment F G gpow _
        gs usl = al ∧
        zip_with (λ '(gg, hh) us,
          @okamoto_commitment F G gid gop gpow [gg; hh] us)
          (zip_with pair
          (map (λ '(g₁, g₂), gop g₁ g₂) (generate_pairs_of_vector gs))
          (map (λ '(h₁, h₂), gop h₁ h₂) (generate_pairs_of_vector hs)))
          (pair_zip (usrl ++ usrr)) = ar.
      Proof.
        intros × ha.
        unfold generalised_construct_neq_commitment in ha.
        rewrite !VectorSpec.splitat_append in ha.
        rewrite rew_opp_l in ha.
        eapply VectorSpec.append_inj in ha.
        exact ha.
      Qed.

Completeness. If gs[i] ^ xs[i] = hs[i] for every i and the xs are pairwise distinct, then for all randomness us and challenges c the honest transcript is accepted.
Proof idea: the AND part is completeness of AndSigmaGen. For every pair, generate_pairs_distinct_triple gives indices j ≠ k with (g₁, g₂) = (gs[j], gs[k]) and corresponding hs and xs. Okamoto completeness then reduces to the identity (g₁ g₂) ^ (x₁ / (x₁ - x₂)) · (h₁ h₂) ^ (1 / (x₂ - x₁)) = g₂, an exercise in field arithmetic that needs x₁ ≠ x₂.

Special soundness. Suppose two transcripts (a; [c₁]; rs₁) and (a; [c₂]; rs₂) share their commitments, have c₁ ≠ c₂, and are both accepted. Then there are xs with hs[i] = gs[i] ^ xs[i] for every i, and either
  • the xs are pairwise distinct, or
  • there are i ≠ j such that gs[j] = gs[i] ^ α for some α, or gs[i] or gs[j] is the identity gid.
Remark: the existential ∃ α, gs[j] = gs[i] ^ α is a proposition. In a cyclic group it holds for every gs[i] ≠ gid, so the second alternative has no logical content there. The useful reading is computational: the proof builds α explicitly from the extracted Okamoto witness, as γ / (1 - γ) or its inverse. So a prover that convinces the verifier with two equal witnesses yields a discrete-logarithm relation between two generators. The formal statement does not include the assumption that such relations are hard to find.

      Lemma neq_pair_relation {n : nat} (gs hs : Vector.t G (2 + n))
        (xs : Vector.t F (2 + n))
        (ha : ∀ (i : Fin.t (2 + n)), gs[@i] ^ xs[@i] = hs[@i])
        (hb : ∀ (i j : Fin.t (2 + n)), i ≠ j → xs[@i] ≠ xs[@j]) :
        ∀ (i : Fin.t ((2 + n) × (1 + n) / 2)) (g₁ g₂ h₁ h₂ : G) (x₁ x₂ : F),

        (generate_pairs_of_vector hs)[@i] = (h₁, h₂) →
        (generate_pairs_of_vector xs)[@i] = (x₁, x₂) →
        g₂ = fold_right (λ '(g, x) acc, gop (g ^ x) acc)
          (zip_with pair [gop g₁ g₂; gop h₁ h₂]
            [x₁ × inv (x₁ - x₂); inv (x₂ - x₁)]) gid.
      Proof.
        intros × hc hd hf.
        cbn.
        destruct (@generate_pairs_distinct_triple G F _
          gs hs xs i g₁ g₂ h₁ h₂ x₁ x₂ hc hd hf) as
          (j & k & hg & hi & hj & hk & hl & hm & hn).
        clear hc hd hf.

        rewrite <- hi, <-hk, <-hm in hc.
        rewrite <-hc.
        clear hc.
        pose proof (ha k) as hc.
        rewrite <- hj, <-hl, <-hn in hc.
        rewrite <-hc.
        rewrite right_identity, !smul_distributive_vadd,
        <-!smul_associative_fmul.
        rewrite gop_simp.
        rewrite <-!smul_distributive_fadd.
        assert (hd : (x₁ × inv (x₁ - x₂) + x₁ × inv (x₂ - x₁)) = zero).
        {
          field.
          pose proof (hb j k hg) as hd.
          rewrite <-hm, <-hn in hd.
          split; intro hw; eapply hd;
          [eapply eq_sym, ring_sub_zero_iff | eapply ring_sub_zero_iff]; exact hw.
        }
        rewrite !hd; clear hd.
        rewrite field_zero, left_identity.
        assert (hd : (x₁ × inv (x₁ - x₂) + x₂ × inv (x₂ - x₁)) =
          (x₂ - x₁) × inv (x₂ - x₁)).
        {

          [eapply eq_sym, ring_sub_zero_iff | eapply ring_sub_zero_iff]; exact hw.

        (gs hs : Vector.t G (2 + n)) (c : F)
        (ha : ∀ (i : Fin.t (2 + n)), gs[@i] ^ xs[@i] = hs[@i])
        (hb : ∀ (i j : Fin.t (2 + n)), i ≠ j → xs[@i] ≠ xs[@j]) :
        ∀ (us : Vector.t F ((2 + n) + ((2 + n) × (1 + n)))),
        generalised_construct_neq_conversations_real_transcript xs gs hs us c =
        generalised_construct_neq_conversations_simulator_transcript gs hs
          (generalised_construct_neq_response xs us c) c.
      Proof.

        destruct (splitat (2 + n) us) as (usl & usr) eqn:he.
        apply append_splitat in he; subst us.
        unfold generalised_construct_neq_conversations_real_transcript,
          generalised_construct_neq_conversations_simulator_transcript,
          generalised_construct_neq_commitment, generalised_construct_neq_response.

Special honest-verifier zero knowledge as equality of distributions. Assume the witness hypotheses (gs[i] ^ xs[i] = hs[i] and pairwise distinct xs), and that lf has no duplicates and contains every field element. Then, for every challenge c, the real transcript distribution is a permutation of the simulated one, so both give every transcript the same probability.
Proof idea: construct_neq_shift writes the prover as the simulator composed with the response map phi. phi is a bijection with inverse the response map for opp c (neq_response_compose, neq_response_zero), so it permutes the uniform product distribution (repeat_uniform_bijection_perm), and bind_ret_perm concludes.
      Theorem generalised_neq_special_honest_verifier_zkp_perm {n : nat} :
        ∀ (lf : list F) (Hlfn : lf ≠ List.nil)
        (xs : Vector.t F (2 + n)) (gs hs : Vector.t G (2 + n)) (c : F),
        (∀ (i : Fin.t (2 + n)), gs[@i] ^ xs[@i] = hs[@i]) →
        (∀ (i j : Fin.t (2 + n)), i ≠ j → xs[@i] ≠ xs[@j]) →
        List.NoDup lf → (∀ x : F, List.In x lf) →
        Permutation
          (@generalised_neq_schnorr_distribution n lf Hlfn xs gs hs c)
          (@generalised_neq_simulator_distribution n lf Hlfn gs hs c).
      Proof.
        intros × ha hb hnd hall.
        change (Permutation
          (Bind (repeat_dist_ntimes_vector (uniform_with_replacement lf Hlfn)
              ((2 + n) + ((2 + n) × (1 + n))))
            (fun us ⇒ Ret (generalised_construct_neq_conversations_real_transcript
              xs gs hs us c)))
          (Bind (repeat_dist_ntimes_vector (uniform_with_replacement lf Hlfn)
              ((2 + n) + ((2 + n) × (1 + n))))
            (fun us ⇒ Ret (generalised_construct_neq_conversations_simulator_transcript
              gs hs us c)))).
        eapply bind_ret_perm with
          (phi := fun us ⇒ generalised_construct_neq_response xs us c).
        + apply (repeat_uniform_bijection_perm lf Hlfn _ _
            (fun us ⇒ generalised_construct_neq_response xs us (opp c)) hnd hall).
          × intros us.
            rewrite neq_response_compose.
            assert (hc : c + opp c = zero) by field.
            rewrite hc; apply neq_response_zero.
          × intros us.
            rewrite neq_response_compose.
            assert (hc : opp c + c = zero) by field.
            rewrite hc; apply neq_response_zero.
        + intros us p _. apply construct_neq_shift; assumption.
      Qed.
