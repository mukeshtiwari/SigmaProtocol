Library Examples.WasmBenchSmallDefs

Reduced-parameter WebAssembly benchmarks

This file contains the same fixed 7-candidate approval ballot as Examples/WasmBenchDefs.v, but over three small Schnorr groups (p = k q + 1) with a 64-, 128- and 256-bit modulus p. It is used to locate the point at which the 2 GB linear-memory limit of the CertiRocq WebAssembly backend binds. The terms are compiled by bench/wasm/WasmBenchSmall.v (CertiRocq Compile Wasm) and run in Node. Results are in bench/README.md: the full ballot and its verification complete at up to 128-bit parameters, and memory grows roughly eightfold per doubling of the parameter size.
The parameters (primes, generator, public key and the fixed randomness) were generated by bench/wasm/gen_small_params.py, which uses Miller–Rabin. The primality lemmas prime_q and prime_p in each module are Admitted. They are only needed as arguments to the group operations, which compilation erases. Because of these admissions, nothing in this file may be used as evidence of correctness. It exists for performance measurement only. As a consequence the file does not depend on Coqprime, so it builds on a switch without it.
Each module (Small64, Small128, Small256) defines the group, the encryption and verification functions of Frontend/Approval.v at that group, the fixed inputs, and the benchmark terms ballot_bench and ballot_verify_bench. Small256 also has a single-vote term vote_bench.

The 32-bit prime order q of the subgroup.
  Definition q : Z := 3199286161%Z.
Primality of q. Admitted (checked outside Rocq by Miller–Rabin) and erased by compilation.
  Lemma prime_q : Znumtheory.prime q. Admitted.
The 64-bit prime modulus p.
  Definition p : Z := 10690002613329673913%Z.
Primality of p. Admitted, as for prime_q.
  Lemma prime_p : Znumtheory.prime p. Admitted.

The cofactor k = p / q. safe_prime is the Schnorr-group equation p = k q + 1, checked by evaluation.
  Definition k : Z := Z.div p q.
  Theorem safe_prime : p = (k × q + 1)%Z.
  Proof. vm_cast_no_check (eq_refl p). Qed.

The generator g of the order-q subgroup. Membership (gval^q mod p = 1) is checked by vm_compute.
  Definition gval : Z := 1124220994599102764%Z.

Encryption of an approval ballot with its 0-or-1 proofs (Approval.encrypt_ballot_and_generate_enc_proof) at this group.
  Definition small_encrypt_ballot_and_generate_enc_proof {n : nat}
    (rs ms : Vector.t (@Zp q) n)
    (uscs : Vector.t (Vector.t (@Zp q) 3) n)
    (c : Vector.t (@Zp q) n) :
    Vector.t ((@Schnorr_group p q) × (@Schnorr_group p q) ×
      @Sigma.sigma_proto (@Zp q) (@Schnorr_group p q × @Schnorr_group p q) 2 3 2) n.
  Proof.
    refine(@encrypt_ballot_and_generate_enc_proof (@Zp q)
      Zpfield.zero Zpfield.one zp_add zp_mul zp_sub
      zp_opp zp_dec (@Schnorr_group p q)
      (@inv_schnorr_group k p q safe_prime prime_p prime_q)
      (@mul_schnorr_group p q prime_p prime_q)
      (@pow k p q safe_prime prime_p prime_q) _
      g h rs ms uscs c).
    all: (try eapply prime_q).
    all: (try eapply prime_p).
    all: (try eapply safe_prime).
  Defined.

Verification of the 0-or-1 proofs of a ballot at this group.
  Definition small_verify_encryption_ballot_proof {n : nat}
    (proof : Vector.t ((@Schnorr_group p q) × (@Schnorr_group p q) ×
    @Sigma.sigma_proto (@Zp q)
    (@Schnorr_group p q × @Schnorr_group p q) 2 3 2) n) : bool.
  Proof.
    refine(@verify_encryption_ballot_proof (@Zp q)
      Zpfield.zero Zpfield.one zp_add zp_dec
      (@Schnorr_group p q)
      (@inv_schnorr_group k p q safe_prime prime_p prime_q)
      (@mul_schnorr_group p q prime_p prime_q)
      (@pow k p q safe_prime prime_p prime_q)
      Schnorr.dec_zpstar _ g h proof).
    all: (try eapply prime_q).
    all: (try eapply prime_p).
    all: (try eapply safe_prime).
  Defined.

  Definition bench_uscs : Vector.t (Vector.t (@Zp q) 3) 7 :=

     [mkzp 2208283729; mkzp 1022222126; mkzp 1196050748];
     [mkzp 2873237672; mkzp 2084839400; mkzp 920140091];
     [mkzp 2315992116; mkzp 568275056; mkzp 3106775596];
     [mkzp 2452611419; mkzp 2474810180; mkzp 2030106618];
     [mkzp 1043665193; mkzp 2031403297; mkzp 1748309235];
     [mkzp 817804384; mkzp 405126229; mkzp 416314668]].

  Definition bench_cs : Vector.t (@Zp q) 7 :=
    [mkzp 30884439; mkzp 304912983; mkzp 3040153711; mkzp 2710566583;
     mkzp 252860897; mkzp 983297493; mkzp 289482183].

    small_encrypt_ballot_and_generate_enc_proof bench_rs bench_ms bench_uscs bench_cs.
