Library Curve.P256Primes

Primality of the NIST P-256 parameters

Machine-checked primality proofs for the two primes of the NIST P-256 curve (FIPS 186-4, SEC 2 secp256r1):
  • prime_p256_p: the field modulus p = 2 ^ 256 - 2 ^ 224 + 2 ^ 192 + 2 ^ 96 - 1;
  • prime_p256_n: the group order n of the base point.
Each proof is a Pocklington certificate in the format of the Coqprime library. A Pock_certif N a factors r entry asserts that N is prime because a is a Pocklington witness for N with respect to a partial factorisation (factors, a list of (prime, exponent) pairs) of N - 1; the list chains such certificates down to the base case prime_2, so every prime factor used is itself certified. Pocklington_refl reduces the claim to a boolean check, which is evaluated by the kernel's virtual machine (vm_cast_no_check defers the conversion check to Qed; the check is still performed by the kernel). The certificates were generated externally; only their verification is trusted to Rocq.
These lemmas are used in Curve/P256.v to build the scalar field Z_n and the base field F_p.
