Library Examples.ElectionGuardIns

The ElectionGuard 2.0 verifier at the standard parameters

This file instantiates the certified ElectionGuard verifier (Backend/ElectionGuardTally.v) at the parameters of the ElectionGuard 2.0 specification (section 3.1.1): the 4096-bit prime p, the 256-bit prime q = 2^256 - 189 with p - 1 = q·r, and the generator g = 2^r mod p of the subgroup of order q. The scalar field is Z_q and the group is the order-q subgroup of Z_p^* (Utility/Zpstar.v), as for Helios.
All parameters are certified. q is prime by the Pocklington certificate of primeQEG.v. For p, the cofactor r (about 3840 bits) is not factored, so Pocklington's criterion does not apply; p is proved prime by the 147-step elliptic-curve (ECPP) certificate of primePEG.v, generated by PARI/GP's primecert and converted by bench/ecpp2coq.py. The relation p = r·q + 1 and the membership g^q mod p = 1 are checked by computation, the latter with the BigN exponentiation of BigNPow.v.
The hash functions of ElectionGuard (HMAC-SHA-256 over the encodings of section 5) are computed by the OCaml driver Executable/Egverifier and passed in through the hash records; they are trusted, as are the parser and the checks that concern only hashes (manifest, base hashes, confirmation codes), which the driver performs. The file is extracted by src/Extraction/Electionguardlib.

How an ElectionGuard 2.0 election is checked

Guardian i chooses a polynomial with coefficients a_ij and publishes K_ij = g^a_ij, each with a Schnorr proof of knowledge; the joint key is K = ∏ᵢ K_i0. Version 2.0 puts the vote in the exponent of K: a selection σ is encrypted with nonce ξ as (α, β) = (g^ξ, K^ξ·K^σ).
Each option carries a range proof that it encrypts a value in 0..R, and each contest a selection-limit proof that the product of its option ciphertexts encrypts a value in 0..L. Both are disjunctions over j of the Chaum–Pedersen statement (α, β/K^j) = (g, K)^ξ, a Schnorr statement in G × G. ElectionGuard stores (c_j, v_j) per branch; the verifier reconstructs the announcements and accepts if the hash (keyed by the extended base hash) equals Σ c_j. This is the same reconstruction as in Belenios, so the Fiat–Shamir layer of Backend/BeleniosTally.v is reused.
The tally is the product of the cast ballots' ciphertexts per option. The guardians publish M = A^s for the joint secret s with a Chaum–Pedersen proof of (K, M) = (g, A)^s, and the decrypted value t satisfies B/M = K^t.
Backend/ElectionGuardTally.v proves that accepted coefficient, range, selection-limit and decryption proofs are accepting transcripts of the library's protocols, and compute_final_count returns a certificate of the counting relation. This file restates two of those theorems at the concrete parameters.

The verifier

Checks one ballot: its contest indices are strictly increasing and name contests of the manifest, and each contest is valid (the range proofs of its selections and its selection-limit proof).
  Definition verify_ballot_ins (E : election) (hs : ballot_hashes) (b : ballot) : bool :=
    verify_ballot (zero := Fzero) (one := Fone) (add := Fadd) (Fdec := Fdec)
      (gid := Gone) (ginv := Ginv) (gop := Gmul) (gpow := Gpow) E hs b.

The encrypted tally: per contest and option, the product of the ballots' ciphertexts.
  Definition encrypted_tally_ins (E : election) (bs : list ballot) : list (list ciphertext) :=
    encrypted_tally (gid := Gone) (gop := Gmul) E bs.

Checks the guardians (verifications 2 and 3 of the specification): their number and indices, each coefficient's Schnorr proof, and that the joint key equals K.
  Definition verify_guardians_ins (E : election) (gh : guardian_hashes) (gs : list guardian) : bool :=
    verify_guardians (zero := Fzero) (add := Fadd) (Fdec := Fdec)
      (gid := Gone) (gop := Gmul) (gpow := Gpow) (Gdec := Gdec) E gh gs.

Checks the decryption of a challenged ballot (verifications 12 and 13); not part of the counting relation.
  Definition verify_ballot_decryptions_ins (E : election) (dh : decryption_hashes)
    (b : ballot) (ds : list (list decryption)) : bool :=
    verify_ballot_decryptions (zero := Fzero) (add := Fadd) (Fdec := Fdec)
      (gid := Gone) (ginv := Ginv) (gop := Gmul) (gpow := Gpow) (Gdec := Gdec) E dh b ds.

The certified verifier and entry point of the extracted code: from the ballots, guardians, published tally and decryptions it returns the valid and invalid ballots, the final flag and a certificate of the counting relation count.
  Definition compute_final_count_ins (E : election) (hs : ballot → ballot_hashes)

    (published : list (list ciphertext)) (dh : decryption_hashes)
    (ds : list (list decryption)) :
    existsT (vbs inbs : list ballot) (bfinal : bool),
      count (zero := Fzero) (one := Fone) (add := Fadd) (Fdec := Fdec)

      (gid := Gone) (ginv := Ginv) (gop := Gmul) (gpow := Gpow) (Gdec := Gdec)
      E hs gh gs bs published dh ds.

Theorems at these parameters

The vector-space structure of G over Z_q, needed to apply the backend's theorems.
  Definition eg_vspace :
    @vector_space F (@eq F) Fzero Fone Fadd (@zp_mul q) (@zp_sub q) (@zp_div q)
      (@zp_opp q prime_q) (@zp_inv q) G (@eq G) Gone Ginv Gmul Gpow :=
    @pow_vspace r p q cofactor prime_p prime_q.

A range (or selection-limit) proof with R = n + 1 ≥ 1 accepted by verify_range, for any hash H, is an accepting conversation of the generalised OR composition (Crypto/OrSigmaGen.v) for the statements (α, β/K^j) = (g, K)^ξ, j = 0..R, with the reconstructed announcements and the challenge vector (-Σ cⱼ) :: (-c₀, …, -c_R). Instance of verify_range_or_accepting.
  Theorem verify_range_or_accepting_ins : ∀ (E : election) (H : list (G × G) → F)
    (c : ciphertext) (n : nat) (cs ss : Vector.t F (2 + n)),
    verify_range (zero := Fzero) (one := Fone) (add := Fadd) (Fdec := Fdec)
      (ginv := Ginv) (gop := Gmul) (gpow := Gpow)
      E H c (S n) (Vector.to_list (Vector.map2 pair cs ss)) = true →
    @generalised_or_accepting_conversations F Fzero Fadd Fdec (G × G)
      (gop2 (gop := Gmul)) (gpow2 (gpow := Gpow)) (Gdec2 (Gdec := Gdec)) (2 + n)
      (Vector.const (g E, K E) (2 + n))
      (messages_from (zero := Fzero) (one := Fone) (add := Fadd) (ginv := Ginv) (gop := Gmul) (gpow := Gpow) E c 0 (2 + n))
      (mk_sigma _ _ _
        (announcements_vec (vadd := gop2 (gop := Gmul)) (smul := gpow2 (gpow := Gpow))
          (Vector.const (g E, K E) (2 + n))
          (messages_from (zero := Fzero) (one := Fone) (add := Fadd) (ginv := Ginv) (gop := Gmul) (gpow := Gpow) E c 0 (2 + n)) cs ss)
        (Vector.cons _ (@zp_opp q prime_q (Vector.fold_right Fadd cs Fzero)) _ (Vector.map (@zp_opp q prime_q) cs)) ss) = true.
  Proof.
    intros × hv; exact (verify_range_or_accepting (Hvec := eg_vspace) E H c n cs ss hv).
  Qed.

A decryption share d of ciphertext c = (α, β) accepted by verify_decryption is an accepting Schnorr conversation in G × G for the Chaum–Pedersen statement (K, β·T⁻¹) = (g, α)^s, with the reconstructed announcement and challenge -c. Instance of verify_decryption_schnorr_accepting.
  Theorem verify_decryption_schnorr_accepting_ins : ∀ (E : election) (H : list (G × G) → F)
    (c : ciphertext) (d : decryption),
    verify_decryption (zero := Fzero) (add := Fadd) (Fdec := Fdec)
      (ginv := Ginv) (gop := Gmul) (gpow := Gpow) (Gdec := Gdec) E H c d = true →
    @accepting_conversation F (G × G) (gop2 (gop := Gmul)) (gpow2 (gpow := Gpow)) (Gdec2 (Gdec := Gdec))
      (g E, fst c) (K E, Gmul (snd c) (Ginv d.(dT)))
      (mk_sigma _ _ _
        (Vector.cons _ (reconstruct (vadd := gop2 (gop := Gmul)) (smul := gpow2 (gpow := Gpow))
          (g E, fst c) (K E, Gmul (snd c) (Ginv d.(dT))) (fst d.(dproof)) (snd d.(dproof))) _ (Vector.nil _))
        (Vector.cons _ (@zp_opp q prime_q (fst d.(dproof))) _ (Vector.nil _))
        (Vector.cons _ (snd d.(dproof)) _ (Vector.nil _))) = true.
  Proof.
    intros × hv; exact (verify_decryption_schnorr_accepting (Hvec := eg_vspace) E H c d hv).
  Qed.
