Schulze benchmarks at the Helios group parameters

This file instantiates the receipt-free Schulze election at the real Helios parameters of Examples/HeliosTallyIns.v: a 2048-bit safe prime p with a 256-bit prime-order subgroup q, and its generator g. It stays generic in the number of candidates m = S n, the ballot bound N = S n' and the bit length L. The extracted functions take n, n' and L at run time, so a single extracted library benchmarks every election size. Extraction is in src/Extraction/SchulzeBenchlib/Extraction.v (Separate Extraction SchulzeBenchIns), and the drivers are in src/Executable/SchulzeBenchcode (main.ml, batched.ml, simple.ml) and src/Executable/SchulzeGentoocode.
It provides wrappers for three ballot front ends and for the tally:
  • the per-cell ballot of Frontend/Schulze.v (non-interactive encryption and verification, and bulletin-board size);
  • the tally of Backend/SchulzeTally.v (counts, encryption of the counts, defeats, closure, winner, non-interactive tally proof and verification, the individual checks, and board size);
  • the batched ballot of Frontend/SchulzeBatched.v (ballot2);
  • the simplified batched ballot of Frontend/SchulzeSimple.v (ballot3).
Nothing is proved here. The wrappers only fix the group operations. The randomness is an oracle rnd : nat → F supplied by the extracted program. Some wrappers reuse a single oracle value across several components (see pos_rand_of and encrypt_margins_bench). This is fine for timing but not for a real election.

  Local Notation F := (@Zp q).
  Local Notation G := (@Schnorr_group p q).

The field Z_q and the Schnorr group of HeliosTallyIns (k = p / q is the cofactor), named for passing to the generic definitions.
  Definition Fzero : F := @Zpfield.zero q prime_q.
  Definition Fone : F := @Zpfield.one q prime_q.
  Definition Fadd : F → F → F := @zp_add q.
  Definition Fmul : F → F → F := @zp_mul q.
  Definition Fsub : F → F → F := @zp_sub q.
  Definition Fopp : F → F := @zp_opp q prime_q.
  Definition Fdec : ∀ x y : F, {x = y} + {x ≠ y} := @zp_dec q.
  Definition Gone : G := @Schnorr.one p q prime_p prime_q.
  Definition Ginv : G → G := @inv_schnorr_group k p q safe_prime prime_p prime_q.
  Definition Gmul : G → G → G := @mul_schnorr_group p q prime_p prime_q.
  Definition Gpow : G → F → G := @pow k p q safe_prime prime_p prime_q.
  Definition Gdec : ∀ x y : G, {x = y} + {x ≠ y} := @Schnorr.dec_zpstar p q.

q ≠ 0, and field elements from integers.
  Lemma q_nz : q ≠ 0%Z.
  Proof. unfold q; discriminate. Qed.

  Definition zp_of (z : Z) : F := @Zpfield.mk_zp q (z mod q)%Z (Z.mod_mod z q q_nz).

A trustee key for the benchmark, h = g^x with x = 123456789. The Helios election key has no known secret, so a fresh key is used.
  Definition x : F := zp_of 123456789.
  Definition h : G := Gpow g x.

The per-cell ballot (m = S n candidates)

The voter's randomness records, filled from the oracle rnd. pos_rand_of and pair_rand_of read fixed oracle indices, and in the extracted program each call of rnd returns fresh randomness.
  Definition pos_rand_of (n : nat) (rnd : nat → F) : @pos_rand F n :=
    mk_pos_rand (rnd 0) (Vector.map (fun _ ⇒ rnd 1) (fin_enum _)) (rnd 2).

  Definition pair_rand_of (n : nat) (rnd : nat → F) : @pair_rand F n :=
    mk_pair_rand (rnd 0) (Vector.map (fun _ ⇒ rnd 1) (fin_enum 3)) (rnd 2)
      (Vector.map (fun _ ⇒ rnd 3) (fin_enum _)) (rnd 4).

The randomness of a whole ballot, one record per position and per pair.
  Definition ballot_rand_of (n : nat) (rnd : nat → F) : @ballot_rand F n :=
    mk_ballot_rand
      (Vector.map (fun _ ⇒ pos_rand_of n rnd) (fin_enum (S n)))
      (Vector.map (fun _ ⇒ Vector.map (fun _ ⇒ pair_rand_of n rnd) (fin_enum (S n)))
        (fin_enum (S n))).

The non-interactive honest voter for ranking s, with hash H.

The number of group-element pairs a ballot puts on the bulletin board (the length of its hashed transcript of ciphertexts and announcements). Challenges and responses in F come on top.

The tally

The tally is benchmarked on counts computed from plaintext rankings and encrypted directly, independently of the ballot proofs.
The pairwise counts margin_count of a list of rankings.
  Definition margins_bench (n : nat) (ss : list (Vector.t nat (S n))) :
    Vector.t (Vector.t Z (S n)) (S n) :=
    mat_of (n := n) (fun i j ⇒ Z.of_nat (Schulze.margin_count (Vector.of_list ss) i j)).

Encrypts a count matrix entrywise under (g, h). Every entry uses the same randomness rnd 0.
  Definition encrypt_margins_bench (n : nat) (D : Vector.t (Vector.t Z (S n)) (S n))
    (rnd : nat → F) : Vector.t (Vector.t (G × G) (S n)) (S n) :=
    Vector.map (Vector.map (fun z ⇒
      @enc F G Gmul Gpow g h (nat_to_F Fzero Fone Fadd (Z.to_nat z)) (rnd 0))) D.

The defeats, the strongest-path closure (minmax_closure) and the winner (winner_of) of a count matrix. These time the trustees' plaintext computation, in particular the tabulated closure.
  Definition defeats_bench (n : nat) (D : Vector.t (Vector.t Z (S n)) (S n)) :
    Vector.t (Vector.t Z (S n)) (S n) :=
    mat_of (n := n) (defeat (fun_of (n := n) D)).

  Definition closure_bench (n : nat) (D : Vector.t (Vector.t Z (S n)) (S n)) :
    Vector.t (Vector.t Z (S n)) (S n) :=
    mat_of (n := n) (minmax_closure (defeat (fun_of (n := n) D))).

  Definition winner_bench (n : nat) (D : Vector.t (Vector.t Z (S n)) (S n)) : option (Fin.t (S n)) :=
    winner_of (minmax_closure (defeat (fun_of (n := n) D))).
