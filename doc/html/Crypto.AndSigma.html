Library Crypto.AndSigma

AND composition of Schnorr proofs with a common base

This file proves knowledge of n discrete logarithms simultaneously, all with respect to the same generator g: the relation is

      R(g, (h₁, …, hₙ); (x₁, …, xₙ)) :⇔ ∀ i, g ^ xᵢ = hᵢ.
    
The composition runs n Schnorr protocols in parallel but, unlike ParallelSigma, under a single shared challenge c: the prover sends (g ^ u₁, …, g ^ uₙ), receives c and answers (u₁ + c · x₁, …, uₙ + c · xₙ). The verifier generalised_and_accepting_conversations checks g ^ rᵢ = aᵢ · hᵢ ^ c for every i. Transcripts have type @sigma_proto F G n 1 n.
Results._
  • Characterisation of the verifier: it accepts iff every component is an accepting Schnorr transcript (and rejects iff some component rejects).
  • Completeness of the prover (under ∀ i, g ^ xᵢ = hᵢ) and of the simulator (unconditionally).
  • Special soundness generalise_and_sigma_soundness: two accepting transcripts with the same announcement vector and different shared challenges yield a full witness vector ys with g ^ yᵢ = hᵢ for all i, computed componentwise by Schnorr's extractor (r₁ᵢ - r₂ᵢ) · (c₁ - c₂)⁻¹.
  • Special HVZK, weak form (generalised_and_special_honest_verifier_zkp: equal lists of acceptance bits and probabilities) and as equality of distributions up to permutation (generalised_and_special_honest_verifier_zkp_perm, generalised_and_special_honest_verifier_zkp_enum).
A generalisation with an independent base per component lives in AndSigmaGen. This file is used by Okamoto and instantiated (and extracted) in Examples/AndSigmaIns.v. Reference: Cramer, Damgård and Schoenmakers, ‘Proofs of partial knowledge’, CRYPTO 1994, for AND/OR composition of Sigma protocols.

Definitions

    Section Def.

Announcement vector (g ^ u₁, …, g ^ uₙ) for randomness us.
        Definition construct_and_conversations_schnorr_commitment
          {n : nat} (g : G) (us : Vector.t F n) : Vector.t G n :=
          Vector.map (fun y ⇒ g^y) us.

Honest prover with witnesses xs, generator g, randomness us and the single challenge c: announcement (g ^ uᵢ)ᵢ, one-element challenge vector c :: nil, responses (uᵢ + c · xᵢ)ᵢ.
        Definition construct_and_conversations_schnorr {n : nat}
          (xs : Vector.t F n) (g : G)
          (us : Vector.t F n) (c : F) : @sigma_proto F G n 1 n.
        Proof.
          set (comm := construct_and_conversations_schnorr_commitment
            g us).
          set (usxs := zip_with (fun u x ⇒ (u, x)) us xs).
          set (res := Vector.map (fun '(u, x) ⇒ u + c × x) usxs).
          exact (comm; [c]; res).
        Defined.

Simulator for statements hs, randomness us and challenge c: announcement (g ^ uᵢ · hᵢ ^ (-c))ᵢ, one-element challenge vector c :: nil, responses us. No witness is used.
        Definition construct_and_conversations_simulator {n : nat}
          (g : G) (hs : Vector.t G n) (us : Vector.t F n)
          (c : F) : @sigma_proto F G n 1 n.
        Proof.
          set (ushs := zip_with (fun u h ⇒ (u, h)) us hs).
          set (comm := Vector.map (fun '(u, h) ⇒ gop (g^u) (h^(opp c))) ushs).
          refine(comm; [c]; us).
        Defined.

Verifier for the AND composition: by recursion on n, checks the Schnorr equation g ^ rᵢ = aᵢ · hᵢ ^ c for the head component and recurses on the tails, passing the same one-element challenge vector c down. Accepts trivially when n = 0.
        Definition generalised_and_accepting_conversations :
          ∀ {n : nat}, G → Vector.t G n →
          @sigma_proto F G n 1 n → bool.
        Proof.
          refine(fix Fn n {struct n} :=
            match n with
            | 0 ⇒ fun _ _ p ⇒ true
            | S n' ⇒ fun g hs p ⇒
              match p with
              | (a; c ; r) ⇒ _
              end
            end).
          destruct (vector_inv_S a) as (ah & atl & _).
          destruct (vector_inv_S c) as (ch & ctl & _).
          destruct (vector_inv_S r) as (rh & rtl & _).
          destruct (vector_inv_S hs) as (h & htl & _).
          exact ((@accepting_conversation F G gop gpow Gdec g h ([ah]; [ch]; [rh])) &&
            (Fn _ g htl (atl; c; rtl))).
        Defined.

Real transcript distribution for a fixed challenge c: draw n independent uniform values from lf and run the honest prover.
        Definition generalised_and_schnorr_distribution
          {n : nat} (lf : list F) (Hlfn : lf ≠ List.nil)
          (xs : Vector.t F n) (g : G)
          (c : F) : dist (@sigma_proto F G n 1 n) :=
          us <- repeat_dist_ntimes_vector
            (uniform_with_replacement lf Hlfn) n ;;
          Ret (construct_and_conversations_schnorr xs g us c).

Simulated transcript distribution for a fixed challenge c: draw n independent uniform values from lf and run the simulator.
        Definition generalised_and_simulator_distribution
          {n : nat} (lf : list F) (Hlfn : lf ≠ List.nil)
          (g : G) (hs : Vector.t G n)
          (c : F) : dist (@sigma_proto F G n 1 n) :=
          us <- repeat_dist_ntimes_vector
            (uniform_with_replacement lf Hlfn) n ;;
          Ret (construct_and_conversations_simulator g hs us c).

    End Def.

If the AND verifier accepts (a; c; r), then for every f the Schnorr transcript (a_f; c; r_f) is accepting for statement h_f.
        Lemma generalised_and_accepting_conversations_correctness_forward :
          ∀ (n : nat) (g : G) (hs : Vector.t G n) (s : @sigma_proto F G n 1 n),
          generalised_and_accepting_conversations g hs s = true →
          (∀ (f : Fin.t n),
            match s with
            | (a; c; r) ⇒
              @accepting_conversation F G gop gpow Gdec g (nth hs f)
                ([(nth a f)]; c; [(nth r f)]) = true
            end).
        Proof.
          unfold accepting_conversation.
          induction n as [|n IHn];
          simpl.
          +
            intros × Ha f.
            refine (match f with end).
          +
            intros × Ha f.
            refine
            (match s as s'
            return s = s' → _ with
            |(a; c; r) ⇒ fun Hc ⇒ _
            end eq_refl).
            rewrite Hc in Ha.
            destruct (vector_inv_S a) as (ha & ta & Hd).
            destruct (vector_inv_S c) as (hc & tc & He).
            destruct (vector_inv_S r) as (hr & tr & Hf).
            destruct (vector_inv_S hs) as (hsa & hstl & Hj).
            eapply andb_true_iff in Ha.
            destruct Ha as [Hal Har].
            destruct (fin_inv_S _ f) as [hf | (hf & Hg)].
            ++
              subst; cbn;
              exact Hal.
            ++
              rewrite Hf, Hd, Hj, He,
              Hg; cbn.
              specialize (IHn _ _ _ Har hf);
              cbn in IHn.
              rewrite He in IHn;
              cbn in IHn; exact IHn.
        Qed.

If the AND verifier rejects, some component Schnorr transcript is rejecting.
        Lemma generalised_and_accepting_conversations_correctness_forward_reject :
          ∀ (n : nat) (g : G) (hs : Vector.t G n) (s : @sigma_proto F G n 1 n),
          generalised_and_accepting_conversations g hs s = false →
          (∃ (f : Fin.t n),
            match s with
            | (a; c; r) ⇒
              @accepting_conversation F G gop gpow Gdec g (nth hs f)
                ([(nth a f)]; c; [(nth r f)]) = false
            end).
        Proof.
          induction n as [|n ihn].
          +
            intros × ha.
            cbn in ha.
            congruence.
          +
            intros × Ha.
            refine
            (match s as s'
            return s = s' → _ with
            |(a; c; r) ⇒ fun Hb ⇒ _
            end eq_refl).
            rewrite Hb in Ha.
            destruct (vector_inv_S a) as (ha & ta & Hd).
            destruct (vector_inv_S c) as (hc & tc & He).
            destruct (vector_inv_S r) as (hr & tr & Hf).
            destruct (vector_inv_S hs) as (hsa & hstl & Hj).
            subst.
            cbn in Ha.
            eapply andb_false_iff in Ha.
            destruct Ha as [Ha | Ha].
            ++
              ∃ Fin.F1.
              exact Ha.
            ++
              destruct (ihn g hstl (ta; hc :: tc; tr) Ha) as (f & ihnn).
              ∃ (Fin.FS f).
              cbn.
              exact ihnn.
        Qed.

If every component Schnorr transcript is accepting, the AND verifier accepts.
        Lemma generalised_and_accepting_conversations_correctness_backward :
          ∀ (n : nat) (g : G) (hs : Vector.t G n) (s : @sigma_proto F G n 1 n),
          (∀ (f : Fin.t n),
          match s with
          | (a; c; r) ⇒
            @accepting_conversation F G gop gpow Gdec g (nth hs f)
              ([(nth a f)]; c; [(nth r f)]) = true
          end) →
          generalised_and_accepting_conversations g hs s = true.
        Proof.
          unfold accepting_conversation.
          induction n as [|n IHn];
          simpl.
          +
            intros × Ha.
            reflexivity.
          +
            intros × Ha.
            refine
            (match s as s'
            return s = s' → _ with
            |(a; c; r) ⇒ fun Hb ⇒ _
            end eq_refl).
            destruct (vector_inv_S a) as (ha & ta & Hc).
            destruct (vector_inv_S c) as (hc & tc & Hd).
            destruct (vector_inv_S r) as (hr & tr & He).
            destruct (vector_inv_S hs) as (hsa & hstl & Hj).
            eapply andb_true_iff; split.
            ++
              subst.
              exact (Ha Fin.F1).
            ++
              eapply IHn;
              intro fz.
              pose proof (Ha (Fin.FS fz)) as Hk.
              subst; cbn in Hk |- ×.
              exact Hk.
        Qed.

If some component Schnorr transcript rejects, the AND verifier rejects. The n = 0 case is discharged by an empty dependent match on Fin.t 0.
        Lemma generalised_and_accepting_conversations_correctness_backward_reject :
          ∀ (n : nat) (g : G) (hs : Vector.t G n) (s : @sigma_proto F G n 1 n),
          (∃ (f : Fin.t n),
          match s with
          | (a; c; r) ⇒
            @accepting_conversation F G gop gpow Gdec g (nth hs f)
              ([(nth a f)]; c; [(nth r f)]) = false
          end) →
          generalised_and_accepting_conversations g hs s = false.
        Proof.
          induction n as [|n ihn].
          +
            intros × (f & ha).
            refine
            match f as f' in Fin.t n return
              match n as n' return sigma_proto → Type
              with
              | 0 ⇒ fun s' ⇒ generalised_and_accepting_conversations g hs s' = false
              | _ ⇒ fun _ ⇒ IDProp
              end s
            with end.
          +
            intros × (f & Ha).
            refine
            (match s as s'
            return s = s' → _ with
            |(a; c; r) ⇒ fun Hb ⇒ _
            end eq_refl).
            rewrite Hb in Ha.
            destruct (vector_inv_S a) as (ha & ta & Hc).
            destruct (vector_inv_S c) as (hc & tc & Hd).
            destruct (vector_inv_S r) as (hr & tr & He).
            destruct (vector_inv_S hs) as (hsa & hstl & Hj).
            destruct (fin_inv_S _ f) as [hf | (hf & Hg)].
            subst.
            ++
              cbn in Ha |- ×.
              rewrite Ha; reflexivity.
            ++
              subst; cbn in Ha |- ×.
              specialize (ihn g hstl (ta; hc :: tc; tr) (ex_intro _ hf Ha)).
              now rewrite ihn, andb_false_r.
        Qed.

The AND verifier accepts iff every component is an accepting Schnorr transcript.

          ∀ (n : nat) (g : G) (hs : Vector.t G n) (s : @sigma_proto F G n 1 n),
          (∀ (f : Fin.t n),
          match s with
          | (a; c; r) ⇒
            @accepting_conversation F G gop gpow Gdec g (nth hs f)

          generalised_and_accepting_conversations g hs s = true.

          split.

            try assumption.
          +
            eapply generalised_and_accepting_conversations_correctness_forward;
            try assumption.
        Qed.

Componentwise completeness: if g ^ xᵢ = hᵢ for all i, then for every index f the f-th component of the honest AND transcript is an accepting Schnorr transcript for h_f. Stated over generic n so that it can be proved by induction.
        Theorem construct_and_conversations_schnorr_completeness_generic :
          ∀ (n : nat) (f : Fin.t n) (g : G) (hs : Vector.t G n)
          (us : Vector.t F n) (xs : Vector.t F n) (c : F),
          (∀ (f : Fin.t n), g^(Vector.nth xs f) = Vector.nth hs f) →
          @accepting_conversation F G gop gpow Gdec g hs[@f]
          ([(map (λ y : F, g ^ y) us)[@f]]; [c];
          [(map (λ '(u, x), u + c × x)
          (zip_with (λ u x : F, (u, x)) us xs))[@f]]) = true.
        Proof.
          induction n as [|n ihn].
          +
            intros × R. refine match f with end.
          +
            intros × R.
            destruct (vector_inv_S hs) as (hh & hst & ha).
            destruct (vector_inv_S us) as (uh & ust & hb).
            destruct (vector_inv_S xs) as (xh & xst & hc).
            subst.
            destruct (fin_inv_S _ f) as [f' | (f' & ha)].
            ++
              specialize (R Fin.F1); cbn in R.
              subst; cbn.
              eapply dec_true.
              assert (Hg : (g ^ xh) ^ c = (g ^ (xh × c))).
              rewrite smul_pow_up.
              reflexivity.
              rewrite Hg; clear Hg.
              assert (Hxc : xh × c = c × xh) by field.
              rewrite Hxc; clear Hxc.
              rewrite <- (@vector_space_smul_distributive_fadd F (@eq F)
                zero one add mul sub div
                opp inv G (@eq G) gid ginv gop gpow);
              subst; [exact eq_refl
              | assumption].
            ++
              subst; cbn.
              eapply dec_true.
              specialize (ihn f' g hst ust xst c).
              cbn in ihn. rewrite dec_true in ihn.
              eapply ihn.
              intro f.
              specialize (R (Fin.FS f)); cbn in R.
              exact R.
        Qed.

Componentwise simulator completeness: the f-th component of a simulated AND transcript is always an accepting Schnorr transcript.
        Theorem construct_and_conversations_simulator_completeness_generic :
          ∀ (n : nat) (f : Fin.t n) (g : G) (hs : Vector.t G n)
          (us : Vector.t F n) (c : F),
          @accepting_conversation F G gop gpow Gdec g hs[@f]
          ([(map (λ '(u, h), gop (g ^ u) (h ^ opp c))
          (zip_with (λ (u : F) (h : G), (u, h)) us hs))[@f]];
          [c]; [us[@f]]) = true.
        Proof.
           induction n as [|n ihn].
          +
            intros ×. refine match f with end.
          +
            intros ×.
            destruct (vector_inv_S hs) as (hh & hst & ha).
            destruct (vector_inv_S us) as (uh & ust & hb).
            subst.
            destruct (fin_inv_S _ f) as [f' | (f' & ha)].
            ++
              subst; cbn.
              eapply dec_true.
              rewrite <-associative.
              rewrite <-(@vector_space_smul_distributive_fadd F (@eq F)
                zero one add mul sub div
                opp inv G (@eq G) gid ginv gop gpow).
              rewrite field_zero_iff_left,
              vector_space_field_zero,
              monoid_is_right_identity.
              reflexivity.
              typeclasses eauto.
            ++
              subst; cbn in ihn |- ×.
              eapply ihn.
        Qed.

        Lemma construct_and_conversations_schnorr_completeness :
          ∀ (us : Vector.t F n) (c : F),
          generalised_and_accepting_conversations g hs

          intros ×.
          eapply generalised_and_accepting_conversations_correctness.
          unfold construct_and_conversations_schnorr.
          intro f.
          eapply construct_and_conversations_schnorr_completeness_generic.

        Qed.

Special soundness._ Two accepting AND transcripts (a; c₁; r₁) and (a; c₂; r₂) with the same announcement vector and different challenges c₁ ≠ c₂ yield witnesses ys with g ^ ys_f = hs_f for every f. Does not use the section witness xs.
Proof by induction on n: the induction hypothesis gives the tail witnesses, and the head witness is (r₁₀ - r₂₀) · (c₁ - c₂)⁻¹, verified with the same algebra as special_soundness_extractor.
        Lemma generalise_and_sigma_soundness :
          ∀ (a : Vector.t G n) (c₁ : Vector.t F 1)
          (r₁ : Vector.t F n) (c₂ : Vector.t F 1) (r₂ : Vector.t F n),
          generalised_and_accepting_conversations g hs (a; c₁; r₁) = true →
          generalised_and_accepting_conversations g hs (a; c₂; r₂) = true →
          c₁ ≠ c₂ →
          (∃ ys : Vector.t F n, ∀ (f : Fin.t n),
            g^(nth ys f) = (nth hs f)).
        Proof using -(xs R).
          clear xs R.
          induction n as [|n' IHn].
          +
            intros × Ha Hb Hc.
            ∃ [];
            intros f; inversion f.
          +
            intros × Ha Hb Hc.
            destruct (vector_inv_S a) as (ah & atl & Hd).
            destruct (vector_inv_S c₁) as (ch₁ & ctl₁ & He).
            destruct (vector_inv_S r₁) as (rh₁ & rtl₁ & Hf).
            destruct (vector_inv_S c₂) as (ch₂ & ctl₂ & Hg).
            destruct (vector_inv_S r₂) as (rh₂ & rtl₂ & Hi).

        Lemma generalised_and_schnorr_distribution_transcript_generic :
          ∀ (l : dist (Vector.t F n))
          (trans : sigma_proto) (pr : prob) (c : F ),
          List.In (trans, pr) (Bind l (λ us : t F n,
            Ret (construct_and_conversations_schnorr xs g us c))) →
          generalised_and_accepting_conversations g hs trans = true.

            intros × Ha.
            cbn in Ha;
            inversion Ha.
          +
            destruct l as [|(la, lp) l].
            ++
              intros × Ha.
              cbn in Ha.
              destruct Ha as [Ha | Ha];
              inversion Ha.
              eapply construct_and_conversations_schnorr_completeness.
            ++
              intros × Ha.
              remember (((la, lp) :: l)%list) as ls.
              cbn in Ha.

              +++
                inversion Ha.

                exact Ha.
        Qed.

Shift lemma: if g ^ xᵢ = hᵢ for all i, the honest transcript with randomness us equals the simulated transcript with randomness shifted componentwise, uᵢ ↦ uᵢ + c · xᵢ. Stated for arbitrary length m and vectors (not the section ones) so that it can be proved by induction.
        Lemma construct_and_shift (c : F) :
          ∀ (m : nat) (xs us : Vector.t F m) (hs : Vector.t G m),
          (∀ f : Fin.t m, g ^ (Vector.nth xs f) = Vector.nth hs f) →
          construct_and_conversations_schnorr xs g us c =
          construct_and_conversations_simulator g hs
            (vec_apply (Vector.map (fun x u ⇒ u + c × x) xs) us) c.
        Proof.
          induction m as [| m ih]; intros ys vs ks Rm.
          + rewrite (vector_inv_0 ys), (vector_inv_0 vs), (vector_inv_0 ks);
            reflexivity.
          + destruct (vector_inv_S ys) as (y & ys' & hy).
            destruct (vector_inv_S vs) as (v & vs' & hv).
            destruct (vector_inv_S ks) as (k & ks' & hk).
            subst.
            specialize (ih ys' vs' ks' (fun f ⇒ Rm (Fin.FS f))).
            unfold construct_and_conversations_schnorr,
              construct_and_conversations_simulator,
              construct_and_conversations_schnorr_commitment in ×.
            cbn in ×.
            inversion ih as [[ha hr]].
            f_equal.
            × f_equal;
              [apply schnorr_commitment_shift; symmetry; exact (Rm Fin.F1) | exact ha].
            × f_equal; exact hr.
        Qed.

Special HVZK, distribution equality._ If for every x the translation u ↦ u + c · x permutes lf as a multiset, then for the section statement and witnesses the real and simulated AND distributions are permutations of each other. Proof: the shift lemma, repeat_uniform_perm and bind_ret_perm.
        Theorem generalised_and_special_honest_verifier_zkp_perm :
          ∀ (lf : list F) (Hlfn : lf ≠ List.nil) (c : F),
          (∀ x : F, Permutation (List.map (fun u ⇒ u + c × x) lf) lf) →
          Permutation
            (@generalised_and_schnorr_distribution n lf Hlfn xs g c)
            (@generalised_and_simulator_distribution n lf Hlfn g hs c).
        Proof.
          intros × hp.
          change (Permutation
            (Bind (repeat_dist_ntimes_vector (uniform_with_replacement lf Hlfn) n)
              (fun us ⇒ Ret (construct_and_conversations_schnorr xs g us c)))
            (Bind (repeat_dist_ntimes_vector (uniform_with_replacement lf Hlfn) n)
              (fun us ⇒ Ret (construct_and_conversations_simulator g hs us c)))).
          eapply bind_ret_perm with
            (phi := vec_apply (Vector.map (fun x u ⇒ u + c × x) xs)).
          + apply repeat_uniform_perm; intros i.
            rewrite (nth_map _ _ i i eq_refl).
            apply hp.
          + intros us p _.
            apply construct_and_shift; exact R.
        Qed.

Special HVZK for an enumerated field._ If lf lists every element of F exactly once, the real and simulated AND transcript distributions are equal up to permutation.
        Theorem generalised_and_special_honest_verifier_zkp_enum :
          ∀ (lf : list F) (Hlfn : lf ≠ List.nil) (c : F),
          List.NoDup lf → (∀ y : F, List.In y lf) →
          Permutation
            (@generalised_and_schnorr_distribution n lf Hlfn xs g c)
            (@generalised_and_simulator_distribution n lf Hlfn g hs c).
        Proof.
          intros × hnd hall.
          eapply generalised_and_special_honest_verifier_zkp_perm.
          intro x.
          eapply enumerates_perm_map with (psi := fun u ⇒ u - c × x);
          [exact hnd | exact hall | intros u; field | intros u; field].
        Qed.
