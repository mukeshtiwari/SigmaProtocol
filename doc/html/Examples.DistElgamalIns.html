Library Examples.DistElgamalIns

Distributed (n-out-of-n) ElGamal over a toy Schnorr group

A concrete instance of the distributed ElGamal scheme of Crypto/DistElgamal.v with three trustees, as used by Helios-style elections. Trustee i holds a secret share xᵢ and publishes hᵢ = g^xᵢ; the joint public key is h = h₁·h₂·h₃, whose secret x₁ + x₂ + x₃ no single trustee knows. Encryption is exponential ElGamal under h: (c₁, c₂) = (g^r, g^m·h^r). To decrypt, every trustee publishes a decryption factor c₁^xᵢ, and anyone combines them as c₂·(c₁^x₁·c₁^x₂·c₁^x₃)⁻¹ = g^m. All three trustees are needed; this is not a threshold scheme. The file is extracted to OCaml by src/Extraction/DistElgamallib.
The group is the order-q subgroup of Z_p^* for the toy safe prime p = 2q + 1 = 5927 with q = 2963 (from Utility/Zpstar.v: Zp q is the scalar field and Schnorr_group p q the group of quadratic residues mod p). The parameters are far too small to be secure; they are chosen so that primality can be proved by trial division (Examples/Prime.v) and the extracted code runs instantly.
The trustees' shares are x₁ = 3, x₂ = 5 and x₃ = 7. Each operation is given for a single value and pointwise for a ballot of n values. The proofs of correct decryption that normally accompany each factor are not part of this file (see ChaumPedersenIns.v).

p = 2q + 1, the shape required by the Zpstar group operations.
  Theorem safe_prime : p = (2 × q + 1)%Z.
  Proof. compute. exact eq_refl. Qed.

The generator g = 4 = 2²: a quadratic residue, hence of order q; membership (4^q mod p = 1) is checked by vm_compute.
  Definition g : @Schnorr_group p q.
  Proof.
    refine
    {| Schnorr.v := 4;
    Ha := conj eq_refl eq_refl : (0 < 4 < p)%Z;
    Hb := _ |}.
    vm_cast_no_check (eq_refl (Zpow_facts.Zpow_mod 4 q p)).
  Defined.
