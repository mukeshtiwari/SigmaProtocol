Library Examples.EqSigmaIns

Equality of discrete logarithms across three bases, toy instance

A concrete instance of the generalised equality protocol of Crypto/EqSigma.v: a proof of knowledge of a single x with h₁ = g₁^x, h₂ = g₂^x and h₃ = g₃^x. It generalises Chaum–Pedersen to n bases (here n = 3). The prover sends gᵢ^u for every base, receives one challenge c and answers r = u + c·x; the verifier checks gᵢ^r = (gᵢ^u)·hᵢ^c for each i. The file is extracted to OCaml by src/Extraction/EqSigmalib.
The group is the order-q subgroup of Z_p^* for the toy safe prime p = 2q + 1 = 5927 with q = 2963 (from Utility/Zpstar.v: Zp q is the scalar field and Schnorr_group p q the group of quadratic residues mod p). The parameters are far too small to be secure; they are chosen so that primality can be proved by trial division (Examples/Prime.v) and the extracted code runs instantly.
The bases are 12, 16 and 18, the witness is x = 3, and hfake is an unrelated element that can be substituted for one of the hᵢ to watch the verifier reject.

The non-interactive proof: c is fn applied to p, q, all the pairs (gᵢ, hᵢ) and the commitments; fn is a hash function supplied by the OCaml caller.
  Definition nizk_construct_eq_conversations_schnorr_ins
    (fn : ∀ {m : nat}, Vector.t (Z + (@Schnorr_group p q)) m → (@Zp q))
    (u : @Zp q) :
    @sigma_proto (@Zp q) (@Schnorr_group p q) 3 1 1.
  Proof.
    set (comm := construct_eq_conversations_schnorr_commitment_ins u).
    set (c := fn _ ([inl p; inl q; inr g₁; inr h₁; inr g₂; inr h₂; inr g₃;
      inr h₃] ++ Vector.map inr comm)).
    refine(construct_eq_conversations_schnorr_ins u c).
  Defined.

The verifier: accepts iff gᵢ^r = aᵢ·hᵢ^c for i = 1, 2, 3.
  Definition generalised_eq_accepting_conversations_ins
    (proof : @sigma_proto (@Zp q) (@Schnorr_group p q) 3 1 1) : bool.
  Proof.
    refine(@generalised_eq_accepting_conversations (@Zp q) (@Schnorr_group p q)

    eapply prime_p.
    eapply prime_q.
  Defined.
