Library Probability.Distr

Finite probability distributions as a monad

This file provides the discrete probability model used to state special honest-verifier zero knowledge (SHVZK) throughout src/Crypto. A distribution dist A is simply a finite list of outcomes paired with their probabilities (prob, exact unreduced fractions from Prob.v). The list is not required to be normalised, duplicate-free or to sum to one; these are properties proved of particular distributions.
Main ingredients:
  • dist_equiv (written =r=): two distributions are equivalent when their lists are permutations of each other. This is a strong, syntactic notion: equivalent distributions list the same weighted outcomes, so they certainly assign the same probability to every event. It does not identify, for example, the two-entry list (a, 1/2) :: (a, 1/2) :: nil with the one-entry list (a, 1) :: nil.
  • The monad Ret/Bind (distmonad, with laws distmonad_law) and the functor fmap (dist_functor), registered with ExtLib so that the x <- d ;; f x notation can be used.
  • uniform_with_replacement l: the uniform distribution on a non-empty list l, each entry with probability 1 / |l|, and repeat_dist_ntimes_vector d n, the n-fold independent product of d as a distribution on Vector.t A n. Sigma-protocol randomness and challenges are sampled this way.
  • Probability facts about uniform sampling: uniform_with_replacement_adds_to_one, uniform_probability_multidraw_prob (each n-fold sample has probability 1 / |l| ^ n).
  • Permutation lemmas used for distribution-equality SHVZK proofs: bind_ret_perm, uniform_perm, repeat_uniform_perm and repeat_uniform_bijection_perm. Together they say that if a bijection of the randomness space maps the real transcript to the simulated one, then the real and simulated distributions are =r=-equivalent.
  • Events (boolean predicates) and their probabilities, with inclusion–exclusion at the level of lists (union_intersection_proof), the complement rule (sum_prob_event_comp_event), the bound 0 ≤ Pr[e] ≤ 1 for uniform distributions (event_uniform_prob) and the biased coin choice.
The approach of representing distributions as weighted lists follows the usual list monad for finite probability; it is computable, so small distributions can be evaluated with Eval compute (see the Example section at the end).

Distributions, equivalence and the monad

Section Distr.

A finite distribution on A: a list of outcomes with their probabilities. Repeated outcomes are allowed and are not merged.
  Definition dist (A : Type) : Type := list (A × prob).

Two distributions are equivalent (=r=) when one list is a permutation of the other.
  Definition dist_equiv {A : Type} : relation (dist A) :=
    fun xs ys ⇒ Permutation xs ys.

  Local Infix "=r=" := dist_equiv
    (at level 70, no associativity).

dist_refl, dist_sym, dist_trans and dist_Equiv: =r= is an equivalence relation (inherited from Permutation).
  Global Instance dist_refl {A : Type} :
    Reflexive (@dist_equiv A).
  Proof.
    unfold dist_equiv; eauto.
  Qed.

  Global Instance dist_sym {A : Type} :
    Symmetric (@dist_equiv A).
  Proof.
    unfold dist_equiv,
    Symmetric.
    intros × Ha.
    eapply Permutation_sym;
    assumption.
  Qed.

  Global Instance dist_trans {A : Type} :
    Transitive (@dist_equiv A).
  Proof.
    unfold dist_equiv,
    Transitive.
    intros × Ha Hb.
    eapply Permutation_trans;
    [exact Ha | exact Hb].
  Qed.

  Global Instance dist_Equiv {A : Type} :
    Equivalence (@dist_equiv A).
  Proof.
    constructor;
    [apply dist_refl |
     apply dist_sym |
     apply dist_trans].
  Qed.

Consing, appending on the right and appending on the left respect =r=; these instances let rewrite work under list constructors.
  Global Instance cons_proper {A : Type} (d : A × prob)
    : Proper (dist_equiv ==> dist_equiv) (cons d).
  Proof.
    intros x y Hxy.
    unfold dist_equiv in × |- ×.
    eapply Permutation_cons;
    [exact eq_refl | exact Hxy].
  Qed.

  Global Instance app_proper {A : Type} (ys : dist A) :
    Proper (dist_equiv ==> dist_equiv) (fun xs ⇒ xs ++ ys).
  Proof.
    intros x y Hxy.
    unfold dist_equiv in × |- ×.
    eapply Permutation_app_tail;
    assumption.
  Qed.

  Global Instance app_end_proper {A : Type} (ys : dist A) :
    Proper (dist_equiv ==> dist_equiv) (fun xs ⇒ ys ++ xs).
  Proof.
    intros x y Hxy.
    unfold dist_equiv in × |- ×.
    eapply Permutation_app;
    [eapply Permutation_refl | exact Hxy].
  Qed.

If xs =r= ys then a :: xs =r= ys ++ [a].
  Lemma dist_equiv_inv_perm {A : Type} :
    ∀ (xs ys : dist A) a, xs =r= ys →
    cons a xs =r= ys ++ [a].
  Proof.
    unfold dist_equiv.
    intros × Ha.
    pose proof (@Permutation_elt _ [] xs ys [] a) as Hb.
    rewrite app_nil_r, app_nil_l in Hb.
    exact (Hb Ha).
  Qed.

Moving the head to the end: a :: xs =r= xs ++ [a].
  Lemma dist_equiv_first_last {A : Type} :
    ∀ (xs : dist A) a, cons a xs =r= xs ++ [a].
  Proof.
    intros ? ?.
    assert (Ht: xs =r= xs).
    reflexivity.
    exact (dist_equiv_inv_perm xs xs a Ht).
  Qed.

Concatenation is commutative up to =r=.
  Lemma dist_equiv_inv_comm {A : Type} :
    ∀ (xs ys : dist A), xs ++ ys =r= ys ++ xs.
  Proof.
    unfold dist_equiv.
    intros ? ?.
    eapply Permutation_app_comm.
  Qed.

The point (Dirac) distribution: x with probability one.
  Definition Ret {A : Type} (x : A) : dist A := [(x, one)].

Monadic bind: for each outcome ax of weight px, run f ax and scale its weights by px; the results are concatenated in order. No merging of equal outcomes takes place.
  Fixpoint Bind {A B : Type} (xs : dist A)
    (f : A → dist B) : dist B :=
    match xs with
    | [] ⇒ []
    | (ax, px) :: tx ⇒
      (List.map
        (fun '(ut, pt) ⇒ (ut, mul_prob px pt)) (f ax)) ++
      Bind tx f
    end.

dist as an ExtLib Monad, enabling ret and the x <- m ;; k notation.
  Global Instance distmonad : Monad dist.
  Proof.
    constructor.
    + exact @Ret.
    + exact @Bind.
  Defined.

Left identity: Bind (Ret a) f = f a, as a list equality (the weights 1 · p are rewritten to p by lia on the components).
  Lemma bind_ret_left : ∀ (A B : Type)
    (a : A) (f : A → dist B), Bind (Ret a) f = f a.
  Proof.
    intros ? ? ? f.
    unfold Bind, Ret.
    rewrite app_nil_r.
    induction (f a) as [ |(bx, px) ts IHn].
    + simpl; reflexivity.
    + simpl; repeat f_equal.
      destruct px;
      repeat f_equal;
      try lia.
      apply IHn.
  Qed.

Right identity: Bind a Ret = a.
  Lemma bind_ret_right : ∀ (A B : Type)
    (a : dist A), Bind a Ret = a.
  Proof.
    intros ? ? a.
    unfold Bind, Ret, mul_prob.
    induction a as [| (bx, px) ts IHn].
    + simpl; reflexivity.
    + simpl; repeat f_equal.
      destruct px;
      repeat f_equal;
      try lia.
      apply IHn.
  Qed.

Bind distributes over a scaled concatenation; the inductive step of associativity.
  Lemma bind_map : ∀ (A B C : Type)
    (ax : A) (f : A → dist B)
    (g : B → dist C)
    (ts : dist A) (px : prob),
    Bind (map (λ '(ut, pt),
      (ut, mul_prob px pt)) (f ax) ++ Bind ts f) g =
    map (λ '(ut, pt), (ut, mul_prob px pt))
      (Bind (f ax) g) ++ Bind (Bind ts f) g.
  Proof.
    intros ? ? ? ? ?.
    induction (f ax) as [| (axx, pxx) tss IHn].
    + simpl;
      intros ? ? p;
      reflexivity.
    + intros ? ? ?.
      simpl.
      rewrite IHn.
      rewrite app_assoc.
      eapply app_inv_tail_iff.
      rewrite map_app, map_map.
      apply app_inv_tail_iff,
      map_ext.
      intros [ut pt].
      rewrite mul_prob_assoc.
      reflexivity.
  Qed.

Associativity of bind, as a list equality: Bind (Bind am f) g = Bind am (fun a ⇒ Bind (f a) g).
  Lemma bind_assoc : ∀ (A B C : Type)
    (am : dist A) (f : A → dist B) (g : B → dist C),
    Bind (Bind am f) g = Bind am (fun a ⇒ Bind (f a) g).
  Proof.
    intros ? ? ?.
    induction am as [| (ax, px) ts IHn].
    + simpl.
      reflexivity.
    + intros ? ?.
      simpl.
      rewrite <-IHn.
      rewrite bind_map;
      reflexivity.
  Qed.

The three monad laws, packaged for ExtLib.
  Global Instance distmonad_law : MonadLaws distmonad.
  Proof.
    constructor; intros.
    + apply bind_ret_left.
    + apply bind_ret_right;
      exact A.
    + apply bind_assoc.
  Defined.

Uniform distributions and probability arithmetic

The uniform distribution on a non-empty list l: every entry gets weight 1 / |l|. Entries of l that repeat get proportionally more mass, which is why the zero-knowledge results also assume NoDup when they need a genuine uniform distribution on a type. The proof of l ≠ [] is not used computationally; it only documents that |l| > 0, so Pos.of_nat |l| is the true length.
  Definition uniform_with_replacement {A : Type} :
    ∀ (l : list A), l ≠ [] → dist A.
  Proof.
    intros ? H.
    remember (Pos.of_nat (List.length l)) as len.
    exact (List.map (fun x ⇒ (x, mk_prob 1 len)) l).
  Defined.

The total mass of a distribution: the sum of all weights. Despite the name it applies to any distribution.
  Definition sum_of_uniform_with_replacement {A : Type} :
    dist A → prob.
  Proof.
    intros d.
    exact (List.fold_right
      (fun '(_, y) acc ⇒ add_prob acc y)
      zero d).
  Defined.

Propositional equality of probabilities (=p=): prob_eq holds.
  Definition prob_equiv : relation prob :=
    fun p q ⇒ prob_eq p q = true.

  Local Infix "=p=" := prob_equiv
    (at level 70, no associativity).

prob_R, prob_S, prob_T and prob_Equiv: =p= is an equivalence relation.
  Global Instance prob_R : Reflexive (prob_equiv).
  Proof.
    intro x.
    apply prob_eq_refl.
  Qed.

  Global Instance prob_S : Symmetric (prob_equiv).
  Proof.
    intros [ax px] [ay py] Hxy; subst.
    unfold prob_equiv, prob_eq in × |- ×.
    apply PeanoNat.Nat.eqb_eq in Hxy.
    apply PeanoNat.Nat.eqb_eq. nia.
  Qed.

  Global Instance prob_T : Transitive (prob_equiv).
  Proof.
    intros [ax px] [bx qx] [cx rx] Hx Hy.
    unfold prob_equiv, prob_eq in × |- ×.
    apply PeanoNat.Nat.eqb_eq in Hx, Hy.
    apply PeanoNat.Nat.eqb_eq. nia.
  Qed.

  Global Instance prob_Equiv : Equivalence (prob_equiv).
  Proof.
    constructor; [apply prob_R | apply prob_S | apply prob_T].
  Qed.

Addition and multiplication of probabilities respect =p=.
  Global Instance add_proper :
    Proper (prob_equiv ==> prob_equiv ==> prob_equiv) (@add_prob).
  Proof.
    intros [ax px] [bx qx] Hxy [ux uy] [vx vy] Huv.
    unfold add_prob, prob_equiv, prob_eq in × |- ×.
    apply PeanoNat.Nat.eqb_eq in Hxy, Huv.
    apply PeanoNat.Nat.eqb_eq.
    repeat rewrite Pos2Nat.inj_mul,
      PeanoNat.Nat.mul_assoc.
    repeat rewrite PeanoNat.Nat.mul_add_distr_r.
    assert (Ht₁: ax × Pos.to_nat uy × Pos.to_nat qx × Pos.to_nat vy =
      ax × Pos.to_nat qx × Pos.to_nat uy × Pos.to_nat vy) by nia.
    rewrite Ht₁, Hxy;
    clear Ht₁.
    assert (Ht₁: ux × Pos.to_nat px × Pos.to_nat qx × Pos.to_nat vy =
      ux × Pos.to_nat vy × Pos.to_nat px × Pos.to_nat qx) by nia.
    rewrite Ht₁, Huv;
    clear Ht₁.
    nia.
  Qed.

  Global Instance mul_proper :
    Proper (prob_equiv ==> prob_equiv ==> prob_equiv) (@mul_prob).
  Proof.
    intros [ax px] [bx qx] Hxy [ux uy] [vx vy] Huv.
    unfold mul_prob, prob_equiv, prob_eq in × |- ×.
    apply PeanoNat.Nat.eqb_eq in Hxy, Huv.
    apply PeanoNat.Nat.eqb_eq.
    repeat rewrite Pos2Nat.inj_mul,
      PeanoNat.Nat.mul_assoc.
    nia.
  Qed.

Decidability of =p=.
  Definition prop_Eqdec :
    ∀ p q : prob, {p =p= q} + {~(p =p= q)}.
  Proof.
    intros [px qx] [py qy];
    unfold add_prob, prob_equiv, prob_eq in × |- ×.
    destruct (Nat.eqb (px × Pos.to_nat qy) (py × Pos.to_nat qx)).
    + left; reflexivity.
    + right; intro H; inversion H.
  Defined.

A fraction equals one iff numerator and denominator coincide; eq_prob is the same statement for an arbitrary prob.
  Lemma one_prob :
    ∀ a b, mk_prob a b =p= one ↔ a = Pos.to_nat b.
  Proof.
    intros ? ?; simpl; split; intro H.
    unfold one in H.
    unfold prob_equiv, prob_eq in H.
    apply PeanoNat.Nat.eqb_eq in H. nia.
    unfold one.
    unfold prob_equiv, prob_eq.
    apply PeanoNat.Nat.eqb_eq.
    nia.
  Qed.

  Lemma eq_prob :
    ∀ p, p =p= one ↔ num p = Pos.to_nat (denum p).
  Proof.
    intros [ap bp]; simpl; split; intro H.
    apply one_prob in H. nia.
    apply one_prob. nia.
  Qed.

Summing |l| weights 1 / k gives |l| / k.
  Lemma fold_right_map_add : ∀ (A : Type) (l : list A) (k : nat),
    fold_right (λ '(_, y) (acc : prob), add_prob acc y) zero
    (map (λ x : A, (x, {| num := 1; denum := Pos.of_nat k |})) l) =p=
    mk_prob (List.length l) (Pos.of_nat k).
  Proof.
    intros ?.
    induction l.
    + intros ?; reflexivity.
    + intros ?.
      rewrite map_cons.
      simpl; specialize (IHl k).
      rewrite add_prob_comm.
      remember (fold_right (λ '(_, y) (acc : prob), add_prob acc y) zero
        (map (λ x : A, (x, {| num := 1; denum := Pos.of_nat k |})) l)) as Hf.
      destruct Hf. simpl.
      apply PeanoNat.Nat.eqb_eq.
      apply PeanoNat.Nat.eqb_eq in IHl.
      rewrite IHl. nia.
  Qed.

The uniform distribution has total mass one._ For non-empty l, the weights of uniform_with_replacement l sum to |l| / |l| = 1.
  Lemma uniform_with_replacement_adds_to_one {A : Type} :
    ∀ (l : list A) (d : dist A) (H₁ : l ≠ [])
    (H₂ : d = uniform_with_replacement l H₁),
    sum_of_uniform_with_replacement d =p= one.
  Proof.
    unfold uniform_with_replacement,
    sum_of_uniform_with_replacement.
    intros ? ? Hl Hd.
    subst.
    rewrite fold_right_map_add.
    unfold prob_equiv, one,
    prob_eq.
    apply PeanoNat.Nat.eqb_eq.
    rewrite Nat2Pos.id; try nia.
    assert (Hw: ∃ w, length l = S w).
    destruct l.
    unfold not in Hl;
    specialize (Hl eq_refl);
    inversion Hl.
    eexists; simpl;
    eauto.
    destruct Hw as [w Hw].
    rewrite Hw.
    nia.
  Qed.

Membership in a uniformly weighted list: (x, p) occurs iff x is in the underlying list and p = 1 / plv.
  Lemma prob_list : ∀ (A : Type)
    (xf : A) (pf : prob) (plv : positive) (la : list A),
    In (xf, pf) (map
      (λ x : A, (x, {| num := 1; denum := plv |})) la) ↔
    In xf la ∧ pf = mk_prob 1 plv.
  Proof.
    intros ? ? ? ? ?.
    revert xf pf plv.
    induction la.
    + intros ? ? ?;
      split; intro Hin.
      inversion Hin.
      inversion Hin;
      inversion H.
    + intros ? ? ?;
      split;
      intro Hin.
      rewrite map_cons in Hin.
      destruct Hin eqn:Hf.
      inversion e.
      firstorder.
      pose proof (proj1 (IHla xf pf plv) i) as Hind.
      firstorder.

      ++ right; apply IHla; firstorder.
  Qed.

Generic subrelation instances: Leibniz equality of functions implies respectful Ra Rb when Ra ⊆ eq ⊆ Rb, and pointwise Rb-equality implies Leibniz equality when Rb ⊆ eq. The latter uses functional extensionality.
  Global Instance subrel_eq_respect {A B : Type}
    (Ra : relation A)
    (Rb : relation B)
    (sa : subrelation Ra eq)
    (sb : subrelation eq Rb) :
    subrelation eq (respectful Ra Rb).
  Proof.
    intros f g Hfg.
    subst.
    intros a a' Raa'.
    apply sb.
    f_equal.
    apply (sa _ _ Raa').
  Qed.

  Global Instance pointwise_eq_ext {A B : Type}
    (Rb : relation B)
    (sb : subrelation Rb eq) :
    subrelation (pointwise_relation A Rb) eq.
  Proof.
    intros f g Hfg.
    unfold pointwise_relation in Hfg.
    apply functional_extensionality.
    intros. apply sb, Hfg.
  Qed.

Product distributions and the functor structure

Independent product of two distributions combined by f: each pair of outcomes (a, b) yields f a b with weight pa · pb.
  Fixpoint join_with {A B C : Type} (f : A → B → C)
    (xs : dist A) (ys : dist B) : dist C :=
    match xs with
    | [] ⇒ []
    | (ax, px) :: tx ⇒
      List.map (fun '(ut, pt) ⇒ (f ax ut, mul_prob px pt)) ys
      ++ join_with f tx ys
    end.

Mapping a function over the outcomes, keeping the weights.
  Fixpoint fmap {A B : Type} (f : A → B) (xs : dist A) : dist B :=
    match xs with
    | [] ⇒ []
    | (ax, px) :: tx ⇒ (f ax, px) :: fmap f tx
    end.

The n-fold independent product of d: a distribution on vectors of length n whose components are drawn independently from d. Used for the randomness of parallel and composed Sigma protocols.
  Fixpoint repeat_dist_ntimes_vector {A : Type} (d : dist A)
    (n : nat) : dist (Vector.t A n) :=
  match n with
  | 0 ⇒ Ret (@Vector.nil A)
  | S n' ⇒
    Bind d (fun u ⇒
      Bind (repeat_dist_ntimes_vector d n')
      (fun v ⇒ Ret (Vector.cons _ u _ v)))
  end.

If d is non-empty, so is its n-fold product.
  Lemma repeat_dist_ntimes_nonempty_vec {A : Type} :
    ∀ (n : nat) (d : dist A),
    d ≠ [] →
    repeat_dist_ntimes_vector d n ≠ [].
  Proof.
    induction n;
    intros × Ha Hb; cbn.
    +
      cbv in Hb.
      congruence.
    +
      cbn in Hb.
      eapply IHn with d;

    List.map fst (repeat_dist_ntimes_vector d (S n)) =
    List.flat_map (fun a ⇒ List.map (fun v ⇒ Vector.cons _ a _ v)
      (List.map fst (repeat_dist_ntimes_vector d n))) (List.map fst d).
  Proof.
    cbn [repeat_dist_ntimes_vector].
    rewrite support_bind.
    apply List.flat_map_ext; intros a.
    rewrite support_bind.
    generalize (List.map fst (repeat_dist_ntimes_vector d n)) as S.
    intros S; induction S as [|v S ih]; [reflexivity | cbn; f_equal; exact ih].
  Qed.

Consing distinct heads onto a duplicate-free list of tails yields a duplicate-free list.
  Lemma NoDup_flat_map_cons {A : Type} (n : nat) (l : list A)
    (S : list (Vector.t A n)) :
    NoDup l → NoDup S →
    NoDup (List.flat_map (fun a ⇒ List.map (fun v ⇒ Vector.cons _ a _ v) S) l).
  Proof.
    intros hl hS; induction hl as [| a l hnin hl ih]; cbn; [constructor |].
    apply NoDup_app.
    + apply Injective_map_NoDup; [| exact hS].
      intros v w hvw; exact (proj2 (VectorSpec.cons_inj hvw)).
    + exact ih.
    + intros v hv hv'.
      apply List.in_map_iff in hv; destruct hv as (w & hw & _).
      apply List.in_flat_map in hv'; destruct hv' as (b & hb & hb').
      apply List.in_map_iff in hb'; destruct hb' as (w' & hw' & _).
      subst v.
      apply hnin; rewrite <-(proj1 (VectorSpec.cons_inj hw')); exact hb.
  Qed.

If the support of d is duplicate-free, so is the support of its n-fold product.
  Lemma support_repeat_nodup {A : Type} (d : dist A) :
    NoDup (List.map fst d) →
    ∀ n, NoDup (List.map fst (repeat_dist_ntimes_vector d n)).
  Proof.
    intros hd n; induction n as [| n ih].
    + cbn; constructor; [intros h; inversion h | constructor].
    + rewrite support_repeat_S; apply NoDup_flat_map_cons; assumption.
  Qed.

If the support of d covers A, the support of its n-fold product covers Vector.t A n.
  Lemma support_repeat_complete {A : Type} (d : dist A) :
    (∀ x, In x (List.map fst d)) →
    ∀ n (v : Vector.t A n),
    In v (List.map fst (repeat_dist_ntimes_vector d n)).
  Proof.
    intros hd n; induction n as [| n ih]; intros v.
    + rewrite (vector_inv_0 v); cbn; left; reflexivity.
    + rewrite support_repeat_S.
      destruct (vector_inv_S v) as (a & w & hv); subst.
      apply List.in_flat_map; ∃ a; split; [apply hd |].
      apply List.in_map; apply ih.
  Qed.

Bijections of the whole randomness vector

Distribution-level bijection lemma._ Let lf enumerate A without duplicates and let Phi be a bijection of Vector.t A n (with inverse Psi), not necessarily coordinatewise. Then relabelling the n-fold uniform product on lf by Phi permutes it. Proof: all weights are equal (uniform_probability_multidraw_prob), and the support enumerates Vector.t A n without duplicates, so enumerates_perm_map applies to it. Used for SHVZK of protocols whose simulator shifts several random values jointly (for example Bayer–Groth).
  Lemma repeat_uniform_bijection_perm {A : Type} (lf : list A) (Hlfn : lf ≠ [])
    (n : nat) (Phi Psi : Vector.t A n → Vector.t A n) :
    NoDup lf → (∀ x, In x lf) →
    (∀ v, Psi (Phi v) = v) → (∀ v, Phi (Psi v) = v) →
    Permutation
      (List.map (fun '(v, p) ⇒ (Phi v, p))
        (repeat_dist_ntimes_vector (uniform_with_replacement lf Hlfn) n))
      (repeat_dist_ntimes_vector (uniform_with_replacement lf Hlfn) n).
  Proof.
    intros hnd hall hpsi hphi.
    set (D := repeat_dist_ntimes_vector (uniform_with_replacement lf Hlfn) n).
    set (q := mk_prob 1 (Pos.of_nat (Nat.pow (List.length lf) n))).
    set (S := List.map fst D).
    assert (hD : D = List.map (fun v ⇒ (v, q)) S).
    {
      apply dist_const_prob_map; intros v p hin.
      apply (uniform_probability_multidraw_prob n lf v p Hlfn hin).
    }
    assert (hlf : List.map fst (uniform_with_replacement lf Hlfn) = lf).
    {
      rewrite uniform_with_replacement_unfold, List.map_map.
      erewrite List.map_ext; [apply List.map_id | intros; reflexivity].
    }
    assert (hS : NoDup S).
    { apply support_repeat_nodup; rewrite hlf; exact hnd. }
    assert (hC : ∀ v, In v S).
    { apply support_repeat_complete; rewrite hlf; exact hall. }
    
    rewrite hD, List.map_map.
    eapply Permutation_trans with
      (l' := List.map (fun v ⇒ (v, q)) (List.map Phi S)).
    + apply Permutation_refl'.
      change (List.map (fun v ⇒ (Phi v, q)) S =
        List.map (fun v ⇒ (v, q)) (List.map Phi S)).
      rewrite List.map_map.
      apply List.map_ext_in; intros v _; reflexivity.
    + apply Permutation_map.
      apply (enumerates_perm_map S Phi Psi hS hC hpsi hphi).
  Qed.

An event is a computable predicate on outcomes.

The complement of an event.

The sub-distribution of outcomes satisfying e.
  Definition list_of_events (e : event) (xs : dist A) : dist A :=
    List.filter (fun '(x, y) ⇒ e x) xs.

Pr[e] in xs: the sum of the weights of outcomes satisfying e.

    List.fold_right (fun '(tx, bx) ax ⇒ add_prob ax bx)

The outcomes satisfying e₁ ∨ e₂, respectively e₁ ∧ e₂.
