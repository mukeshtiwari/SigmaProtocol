Primality certificate for the ElectionGuard 2.0 subgroup order

This file proves that q = 2^256 - 189, written out in decimal as

115792089237316195423570985008687907853269984665640564039457584007913129639747
is prime. It is the 256-bit order of the subgroup of Z_p^* fixed by the ElectionGuard 2.0 specification (section 3.1.1), where p is the 4096-bit prime of primePEG.v and p - 1 = q·r. It is used by Examples/ElectionGuardIns.v.
The proof is a Pocklington certificate, generated with sympy by the helper script bench/pocklington.py of the repository and checked by reflection with Coqprime (Pocklington_refl). Each Pock_certif N a factors sqrt entry gives a witness base a and a factored part of N - 1 whose square exceeds N; the prime factors in that list, 440208…493, 14220…871, 973591, 87881, 83, 41 and 13, each get their own certificate, down to the base case prime2. The boolean checker is run with vm_compute.
