Library Crypto.OkamotoRows

Systems of multi-base equations as one Okamoto instance

Many presentation proofs of anonymous credentials prove knowledge of a single witness vector w = (w_1, ..., w_K) satisfying several linear equations in the exponent at once,

      T_j = ∏_i B_j[i]^(w_i) for j = 1, ..., m,
using one challenge and one response vector. Such a system is a single instance of the generalised Okamoto protocol of Okamoto, taken in the product group G^m of Vector_product_space: the i-th Okamoto base is the column (B_1[i], ..., B_m[i]) and the public value is (T_1, ..., T_m). This file sets up that encoding and transfers the Okamoto results to it:
  • transpose turns the m rows B_j (each of length K) into the K columns, and vexp_transpose shows the product-space multi-exponentiation of the columns is the vector of row-wise multi-exponentiations;
  • ext_reconstruct recomputes the announcement A_j = T_j^(−c) · B_j^r from the challenge and responses, as a Fiat–Shamir verifier does;
  • ext_completeness, ext_simulator_completeness, ext_special_soundness and ext_shvzk are the instances of the Okamoto theorems;
  • unit_row encodes an equation with a single base T = b^(w_p) as a row.
The file also gives the analogous reconstruction and properties for the Chaum–Pedersen protocol (equality of discrete logarithms) from ChaumPedersen, and a handful of group identities (gpow_add, pow_opp, ginv_gop, ...) shared by the credential files.
It is used by UProve (pseudonym and attribute commitments) and BBSSharp, by the Bayer–Groth shuffle files (BayerGroth, BayerGrothSound, BayerGrothZK), and by the corresponding extracted verifiers and examples.

A field F and a group G forming a vector space (Hvec), each with decidable equality. The local notations below name the group axioms that Hvec provides; gexp is the multi-exponentiation mexp of MultiExp over G.

Exponent laws, restated from the vector-space axioms: g^(r+s) = g^r · g^s, g^(r·s) = (g^r)^s, (a·b)^r = a^r · b^r, g^1 = g and g^0 = gid.
  Lemma gpow_add : ∀ (g : G) (r s : F), g ^ (add r s) = gop (g ^ r) (g ^ s).
  Proof. intros; apply gfadd. Qed.
  Lemma gpow_mul : ∀ (g : G) (r s : F), g ^ (mul r s) = (g ^ r) ^ s.
  Proof. intros; apply gfmul. Qed.
  Lemma gop_pow : ∀ (a b : G) (r : F), (gop a b) ^ r = gop (a ^ r) (b ^ r).
  Proof. intros; apply gvadd. Qed.
  Lemma gpow_one : ∀ g : G, g ^ one = g.
  Proof. intros; apply gone. Qed.
  Lemma gpow_zero : ∀ g : G, g ^ zero = gid.
  Proof. intros; apply gzero. Qed.

Uniqueness of inverses: if x · y = gid then x⁻¹ = y.
  Lemma inv_unique : ∀ x y : G, gop x y = gid → ginv x = y.
  Proof.
    intros x y h.
    rewrite <-(gid_r (ginv x)), <-h, gassoc, ginv_l, gid_l; reflexivity.
  Qed.

In the abelian group G, (a·b)⁻¹ = a⁻¹ · b⁻¹.
  Lemma ginv_gop : ∀ a b : G, ginv (gop a b) = gop (ginv a) (ginv b).
  Proof.
    intros a b; apply inv_unique.
    rewrite (gcomm (ginv a) (ginv b)), gassoc, <-(gassoc a b (ginv b)), (ginv_r b),
      (gid_r a), (ginv_r a); reflexivity.
  Qed.

The identity is its own inverse.
  Lemma ginv_gid : ginv gid = gid.
  Proof. apply inv_unique; apply gid_l. Qed.

Negating the exponent inverts: g^(−r) = (g^r)⁻¹.
  Lemma pow_opp : ∀ (g : G) (r : F), g ^ (opp r) = ginv (g ^ r).
  Proof.
    intros g r; symmetry; apply inv_unique.
    rewrite <-(gpow_add g r (opp r)).
    assert (h : add r (opp r) = zero) by field.
    rewrite h; apply gpow_zero.
  Qed.

Rearrangement: (a·b)·(c·d) = (a·c)·(b·d).
  Lemma gop4 : ∀ a b c d : G, gop (gop a b) (gop c d) = gop (gop a c) (gop b d).
  Proof.
    intros a b c d.
    rewrite <-(gassoc a b (gop c d)), (gassoc b c d), (gcomm b c), <-(gassoc c b d),
      (gassoc a c (gop b d)); reflexivity.
  Qed.

Negating all exponents inverts a multi-exponentiation: gexp gs (−xs) = (gexp gs xs)⁻¹.
  Lemma mexp_map_opp : ∀ (k : nat) (gs : Vector.t G k) (xs : Vector.t F k),
    gexp gs (Vector.map opp xs) = ginv (gexp gs xs).
  Proof.
    induction k as [| k ih]; intros gs xs.
    + rewrite (vector_inv_0 gs), (vector_inv_0 xs); cbn [Vector.map].
      rewrite !mexp_nil, ginv_gid; reflexivity.
    + destruct (vector_inv_S gs) as (g & gs' & ->).
      destruct (vector_inv_S xs) as (x & xs' & ->).
      cbn [Vector.map]; rewrite !mexp_cons, ih, pow_opp, ginv_gop; reflexivity.
  Qed.

Multi-exponentiation is multiplicative in the bases: gexp (v ⊙ w) xs = gexp v xs · gexp w xs, where ⊙ is the coordinate-wise product.
  Lemma mexp_map2_gop : ∀ (k : nat) (v w : Vector.t G k) (xs : Vector.t F k),
    gexp (Vector.map2 gop v w) xs = gop (gexp v xs) (gexp w xs).
  Proof.
    induction k as [| k ih]; intros v w xs.
    + rewrite (vector_inv_0 v), (vector_inv_0 w), (vector_inv_0 xs).
      rewrite !mexp_nil, gid_l; reflexivity.
    + destruct (vector_inv_S v) as (a & v' & ->).
      destruct (vector_inv_S w) as (b & w' & ->).
      destruct (vector_inv_S xs) as (x & xs' & ->).
      rewrite map2_cons, !mexp_cons, ih, gop_pow, gop4; reflexivity.
  Qed.

Chaum–Pedersen with a reconstructed announcement

For the statement c1 = g^y ∧ c2 = h^y, recompute the two announcement components g^ρ · c1^(−c) and h^ρ · c2^(−c) from the challenge c and response ρ. A Fiat–Shamir verifier recomputes the announcement this way and hashes it, instead of receiving it.
  Definition cp_reconstruct (g c1 h c2 : G) (c ρ : F) : Vector.t G 2 :=
    [gop (g ^ ρ) (c1 ^ (opp c)); gop (h ^ ρ) (c2 ^ (opp c))].

The Chaum–Pedersen transcript built from the reconstructed announcement.
  Definition cp_transcript (g c1 h c2 : G) (c ρ : F) : @sigma_proto F G 2 1 1 :=
    (cp_reconstruct g c1 h c2 c ρ; [c]; [ρ]).

The Chaum–Pedersen verifier of ChaumPedersen for bases g, h and public values c1, c2.
  Definition cp_verify (g c1 h c2 : G) (t : @sigma_proto F G 2 1 1) : bool :=
    generalised_cp_accepting_conversations (gop := gop) (gpow := gpow) (Gdec := Gdec) g h c1 c2 t.

A reconstructed transcript always verifies, for every c and ρ.
  Theorem cp_reconstruct_accepting : ∀ (g c1 h c2 : G) (c ρ : F),
    cp_verify g c1 h c2 (cp_transcript g c1 h c2 c ρ) = true.
  Proof.
    intros *; unfold cp_verify, cp_transcript, cp_reconstruct.
    apply generalised_cp_accepting_conversations_accept_backward;
    rewrite <-gassoc, pow_opp, ginv_l, gid_r; reflexivity.
  Qed.

Special soundness: two accepting transcripts with the same announcement and different challenges yield y with g^y = c1 and h^y = c2.
  Theorem cp_special_soundness : ∀ (g c1 h c2 : G) (a : Vector.t G 2) (ca ra cb rb : F),
    ca ≠ cb →
    cp_verify g c1 h c2 (a; [ca]; [ra]) = true →
    cp_verify g c1 h c2 (a; [cb]; [rb]) = true →
    ∃ y : F, g ^ y = c1 ∧ h ^ y = c2.
  Proof.
    intros × hc h1 h2.
    destruct (generalise_cp_sigma_soundness g h c1 c2 a ca cb ra rb h1 h2 hc) as (y & hy).
    ∃ y; split; [exact (hy Fin.F1) | exact (hy (Fin.FS Fin.F1))].
  Qed.

Special honest-verifier zero knowledge: if g^y = c1, h^y = c2 and lf enumerates the field without duplicates, the real transcript distribution is a permutation of the simulated one.
  Theorem cp_shvzk : ∀ (lf : list F) (Hlfn : lf ≠ List.nil) (g c1 h c2 : G) (y c : F),
    g ^ y = c1 → h ^ y = c2 →
    List.NoDup lf → (∀ z : F, List.In z lf) →
    Permutation
      (generalised_cp_schnorr_distribution (add := add) (mul := mul) (gpow := gpow) lf Hlfn y g h c)
      (generalised_cp_simulator_distribution (opp := opp) (gop := gop) (gpow := gpow) lf Hlfn g h c1 c2 c).
  Proof.
    intros × h1 h2 hnd hall.
    exact (generalised_cp_special_honest_verifier_zkp_enum y g h c1 c2 (conj h1 h2) lf Hlfn c hnd hall).
  Qed.

Rows of bases as Okamoto columns

VG m is the product group G^m; vexp m is multi-exponentiation in it, with coordinate-wise operations.
  Section Rows.

    Local Notation VG m := (Vector.t G m).
    Local Notation vexp m := (mexp (vid := vec_id (V := G) (vid := gid) m)
      (vadd := vec_add (vadd := gop)) (smul := vec_smul (smul := gpow))).

transpose K Bs turns m rows of length K into K columns of length m.
    Fixpoint transpose {m : nat} (K : nat) : Vector.t (VG K) m → Vector.t (VG m) K :=
      match K return Vector.t (VG K) m → Vector.t (VG m) K with
      | 0 ⇒ fun _ ⇒ []
      | S K' ⇒ fun Bs ⇒ Vector.map Vector.hd Bs :: transpose K' (Vector.map Vector.tl Bs)
      end.

Mapping a constant function gives a constant vector.
    Lemma map_fun_const : ∀ {A B : Type} (c : B) (m : nat) (v : Vector.t A m),
      Vector.map (fun _ ⇒ c) v = Vector.const c m.
    Proof.
      intros A B c m v; induction v as [| a m v ih]; [reflexivity |].
      cbn [Vector.map]; rewrite ih; reflexivity.
    Qed.

map2 f (map g v) (map h v) = map (fun a ⇒ f (g a) (h a)) v.
    Lemma map2_map : ∀ {A B C D : Type} (f : B → C → D) (g : A → B) (h : A → C) (m : nat)
      (v : Vector.t A m),
      Vector.map2 f (Vector.map g v) (Vector.map h v) = Vector.map (fun a ⇒ f (g a) (h a)) v.
    Proof.
      intros A B C D f g h m v; induction v as [| a m v ih]; [reflexivity |].
      cbn [Vector.map]; rewrite map2_cons, ih; reflexivity.
    Qed.

Multi-exponentiation of the columns in G^m by ws equals the vector of row-wise multi-exponentiations (gexp B_j ws)_j. This is the bridge between the Okamoto relation in G^m and the system of equations.
    Lemma vexp_transpose : ∀ (m K : nat) (Bs : Vector.t (VG K) m) (ws : Vector.t F K),
      vexp m (transpose K Bs) ws = Vector.map (fun row ⇒ gexp row ws) Bs.
    Proof.
      intros m K; induction K as [| K ih]; intros Bs ws.
      + rewrite (vector_inv_0 ws); cbn [transpose]; rewrite mexp_nil.
        symmetry; etransitivity.
        - apply (Vector.map_ext _ _ (fun row : Vector.t G 0 ⇒ gexp row []) (fun _ ⇒ gid)).
          intro row; apply mexp_nil.
        - apply map_fun_const.
      + destruct (vector_inv_S ws) as (w & ws' & ->).
        cbn [transpose]; rewrite mexp_cons, ih.
        unfold vec_add, vec_smul; rewrite !Vector.map_map, map2_map.
        apply Vector.map_ext; intro row.
        destruct (vector_inv_S row) as (r0 & row' & ->).
        rewrite mexp_cons; reflexivity.
    Qed.

The announcement recomputed from challenge c and responses rs, row by row: A_j = T_j^(−c) · gexp B_j rs.
    Definition ext_reconstruct {K m : nat} (c : F) (Bs : Vector.t (VG K) m) (Ts : VG m)
      (rs : Vector.t F K) : VG m :=
      Vector.map2 (fun row T ⇒ gop (T ^ (opp c)) (gexp row rs)) Bs Ts.

The reconstructed announcement satisfies the verification equation: A_j · T_j^c = gexp B_j rs for every row j.
    Lemma ext_reconstruct_eq : ∀ (K m : nat) (c : F) (Bs : Vector.t (VG K) m) (Ts : VG m)
      (rs : Vector.t F K),
      vec_add (vadd := gop) (ext_reconstruct c Bs Ts rs) (vec_smul (smul := gpow) Ts c) =
      Vector.map (fun row ⇒ gexp row rs) Bs.
    Proof.
      intros K m c; induction m as [| m ih]; intros Bs Ts rs.
      + rewrite (vector_inv_0 Bs), (vector_inv_0 Ts); reflexivity.
      + destruct (vector_inv_S Bs) as (row & Bs' & ->).
        destruct (vector_inv_S Ts) as (T & Ts' & ->).
        unfold ext_reconstruct, vec_add, vec_smul in ×.
        rewrite map2_cons; cbn [Vector.map]; rewrite map2_cons.
        f_equal; [| apply ih].
        rewrite (gcomm (T ^ (opp c)) (gexp row rs)), <-gassoc, pow_opp, ginv_l, gid_r; reflexivity.
    Qed.

The verifier for the system: the generalised Okamoto verifier in G^m with the transposed bases and public value Ts. The witness has length S (S n) ≥ 2, as the Okamoto protocol requires.
    Definition ext_verify {n m : nat} (Bs : Vector.t (VG (S (S n))) m) (Ts : VG m)
      (t : @sigma_proto F (VG m) 1 1 (S (S n))) : bool :=
      generalised_okamoto_accepting_conversation (gid := vec_id (V := G) (vid := gid) m)
        (gop := vec_add (vadd := gop)) (gpow := vec_smul (smul := gpow)) (Gdec := vec_dec Gdec)
        (n := n) (transpose (S (S n)) Bs) Ts t.

Honest transcript for witness ws, randomness us and challenge c.
    Definition ext_real {n m : nat} (ws : Vector.t F (S (S n))) (Bs : Vector.t (VG (S (S n))) m) (Ts : VG m)
      (us : Vector.t F (S (S n))) (c : F) : @sigma_proto F (VG m) 1 1 (S (S n)) :=
      generalised_okamoto_real_protocol (add := add) (mul := mul) (gid := vec_id (V := G) (vid := gid) m)
        (gop := vec_add (vadd := gop)) (gpow := vec_smul (smul := gpow)) (n := n)
        ws (transpose (S (S n)) Bs) Ts us c.

Simulated transcript for responses us and challenge c.
    Definition ext_simulator {n m : nat} (Bs : Vector.t (VG (S (S n))) m) (Ts : VG m)
      (us : Vector.t F (S (S n))) (c : F) : @sigma_proto F (VG m) 1 1 (S (S n)) :=
      generalised_okamoto_simulator_protocol (opp := opp) (gid := vec_id (V := G) (vid := gid) m)

Distribution of honest transcripts, with randomness drawn uniformly from lf.

        (gop := vec_add (vadd := gop)) (gpow := vec_smul (smul := gpow)) (n := n)

Distribution of simulated transcripts.
    Definition ext_simulator_distribution {n m : nat} (lf : list F) (Hlfn : lf ≠ List.nil)
      (Bs : Vector.t (VG (S (S n))) m) (Ts : VG m) (c : F) : dist (@sigma_proto F (VG m) 1 1 (S (S n))) :=

The transcript with the reconstructed announcement is always accepted.
    Theorem ext_reconstruct_accepting : ∀ (n m : nat) (Bs : Vector.t (VG (S (S n))) m) (Ts : VG m)
      (c : F) (rs : Vector.t F (S (S n))),
      ext_verify Bs Ts ([ext_reconstruct c Bs Ts rs]; [c]; rs) = true.
    Proof.
      intros *; unfold ext_verify.
      apply generalised_okamoto_accepting_conversation_true.
      cbv beta iota; rewrite mexp_okamoto, vexp_transpose.
      cbn [Vector.hd Vector.caseS].
      symmetry; apply ext_reconstruct_eq.
    Qed.

Completeness: if gexp B_j ws = T_j for every row j, honest transcripts are accepted.
    Theorem ext_completeness : ∀ (n m : nat) (ws : Vector.t F (S (S n))) (Bs : Vector.t (VG (S (S n))) m)
      (Ts : VG m) (us : Vector.t F (S (S n))) (c : F),
      (∀ j : Fin.t m, gexp Bs[@j] ws = Ts[@j]) →
      ext_verify Bs Ts (ext_real ws Bs Ts us c) = true.
    Proof.
      intros × hrel; unfold ext_verify, ext_real.
      apply generalised_okamoto_real_accepting_conversation.
      change (Ts = vexp m (transpose (S (S n)) Bs) ws).
      rewrite vexp_transpose.
      apply Vector.eq_nth_iff; intros j ? <-.
      rewrite (Vector.nth_map _ _ j j eq_refl); symmetry; apply hrel.
    Qed.

Simulated transcripts are always accepted.
    Theorem ext_simulator_completeness : ∀ (n m : nat) (Bs : Vector.t (VG (S (S n))) m) (Ts : VG m)
      (us : Vector.t F (S (S n))) (c : F),
      ext_verify Bs Ts (ext_simulator Bs Ts us c) = true.
    Proof. intros *; apply generalised_okamoto_simulator_accepting_conversation. Qed.

Special soundness: from two accepting transcripts with the same announcement A and challenges c1 ≠ c2, a witness ws with gexp B_j ws = T_j for all j exists (it is (rs1 − rs2)/(c1 − c2), by generalised_okamoto_real_special_soundness).
    Theorem ext_special_soundness : ∀ (n m : nat) (Bs : Vector.t (VG (S (S n))) m) (Ts A : VG m)
      (c1 c2 : F) (rs1 rs2 : Vector.t F (S (S n))),
      c1 ≠ c2 →
      ext_verify Bs Ts ([A]; [c1]; rs1) = true →
      ext_verify Bs Ts ([A]; [c2]; rs2) = true →
      ∃ ws : Vector.t F (S (S n)), ∀ j : Fin.t m, gexp Bs[@j] ws = Ts[@j].
    Proof.
      intros × hc h1 h2; unfold ext_verify in h1, h2.
      destruct (generalised_okamoto_real_special_soundness n (transpose (S (S n)) Bs) Ts A c1 c2 rs1 rs2
        hc h1 h2) as (xi & hxi & _).
      ∃ xi; intro j.
      assert (hv : Ts = vexp m (transpose (S (S n)) Bs) xi) by exact hxi.
      rewrite vexp_transpose in hv; rewrite hv.
      rewrite (Vector.nth_map _ _ j j eq_refl); reflexivity.
    Qed.

Special honest-verifier zero knowledge: if ws satisfies all the equations and lf enumerates the field without duplicates, the real transcript distribution is a permutation of the simulated one.
    Theorem ext_shvzk : ∀ (n m : nat) (lf : list F) (Hlfn : lf ≠ List.nil) (ws : Vector.t F (S (S n)))
      (Bs : Vector.t (VG (S (S n))) m) (Ts : VG m) (c : F),
      (∀ j : Fin.t m, gexp Bs[@j] ws = Ts[@j]) →
      List.NoDup lf → (∀ y : F, List.In y lf) →
      Permutation (ext_real_distribution lf Hlfn ws Bs Ts c) (ext_simulator_distribution lf Hlfn Bs Ts c).
    Proof.
      intros × hrel hnd hall; unfold ext_real_distribution, ext_simulator_distribution.
      apply generalised_okamoto_special_honest_verifier_zkp_enum; [| exact hnd | exact hall].
      change (Ts = vexp m (transpose (S (S n)) Bs) ws).
      rewrite vexp_transpose.
      apply Vector.eq_nth_iff; intros j ? <-.
      rewrite (Vector.nth_map _ _ j j eq_refl); symmetry; apply hrel.
    Qed.

unit_row p b is the row with b at position p and gid elsewhere, so that the single-base equation T = b^(w_p) fits the row format.
    Definition unit_row {K : nat} (p : Fin.t K) (b : G) : VG K :=
      Vector.replace (Vector.const gid K) p b.

Vector.replace at the first position, and at a successor position; both by computation.
    Lemma replace_F1 : ∀ {A : Type} (k : nat) (a : A) (v : Vector.t A k) (b : A),
      Vector.replace (a :: v) Fin.F1 b = b :: v.
    Proof. reflexivity. Qed.

    Lemma replace_FS : ∀ {A : Type} (k : nat) (a : A) (v : Vector.t A k) (p : Fin.t k) (b : A),
      Vector.replace (a :: v) (Fin.FS p) b = a :: Vector.replace v p b.
    Proof. reflexivity. Qed.

gexp (unit_row p b) ws = b^(ws_p).
    Lemma mexp_unit_row : ∀ (K : nat) (p : Fin.t K) (b : G) (ws : Vector.t F K),
      gexp (unit_row p b) ws = b ^ ws[@p].
    Proof.
      induction K as [| K ih]; intros p b ws; [refine (match fin_inv_0 p with end) |].
      destruct (vector_inv_S ws) as (w & ws' & ->).
      destruct (fin_inv_S _ p) as [-> | (p' & ->)]; unfold unit_row in *; rewrite const_S.
      + rewrite replace_F1, mexp_cons, mexp_const_vid, gid_r; reflexivity.
      + rewrite replace_FS, mexp_cons, ih, (smul_vid (HV := Hvec)), gid_l; reflexivity.
    Qed.
