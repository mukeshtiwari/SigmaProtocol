Library Crypto.EqSigma

Equality of Discrete Logarithms: the EQ Sigma Protocol

This file formalises the generalised Sigma protocol for equality of discrete logarithms. Given public bases gs = [g₁; …; gₖ] and public values hs = [h₁; …; hₖ] with k = 2 + n ≥ 2, the prover shows knowledge of a single witness x such that

      R(gs, hs; x) :⇔ ∀ i, gᵢ ^ x = hᵢ
i.e. all the hᵢ share the same discrete logarithm with respect to their bases. For k = 2 this is the Chaum–Pedersen protocol (Chaum and Pedersen, Crypto 1992), instantiated in ChaumPedersen; it is the core of proofs of correct decryption (see DecProof) and of correct key shares in DistElgamal.
The protocol runs k Schnorr protocols in lock-step with a single shared randomness u and a single challenge c:

      Prover → Verifier : aᵢ = gᵢ ^ u (for every i)
      Verifier → Prover : c
      Prover → Verifier : r = u + c · x
      Verifier checks : gᵢ ^ r = aᵢ · hᵢ ^ c (for every i)
Transcripts are values of type @sigma_proto F G (2 + n) 1 1 from Sigma: 2 + n announcements, one challenge and one response. The verifier generalised_eq_accepting_conversations is the conjunction of the Schnorr verification equations accepting_conversation from Sigma at every index.
Main results (all for an abstract field F and an F-vector space G with decidable equality):
  • completeness: construct_eq_conversations_schnorr_completeness;
  • special soundness: generalise_eq_sigma_soundness extracts a common witness y = (r₁ - r₂) / (c₁ - c₂) from two accepting transcripts with the same announcement and distinct challenges;
  • special honest-verifier zero-knowledge, in two forms: the weak form generalised_eq_special_honest_verifier_zkp (both distributions put the same probability 1 / |lf| on accepting transcripts), and the strong form generalised_eq_special_honest_verifier_zkp_perm / generalised_eq_special_honest_verifier_zkp_enum, which shows that the real and simulated transcript distributions are equal as multisets (a permutation of each other) whenever the randomness list lf enumerates the field.
Distributions are finite lists of (value, probability) pairs built with the dist monad of Probability.Distr; the randomness is drawn by uniform_with_replacement lf Hlfn from a non-empty list lf.

Prover, simulator, verifier and distributions

    Section Def.

The prover’s announcement map (fun g ⇒ g ^ u) gs: one Schnorr commitment per base, all with the same randomness u. Exposed separately so that Fiat–Shamir variants can hash it.
      Definition construct_eq_conversations_schnorr_commitment
        {n : nat} (gs : Vector.t G (2 + n)) (u : F) : Vector.t G (2 + n) :=
        Vector.map (fun g ⇒ gpow g u) gs.

Honest prover: construct_eq_conversations_schnorr x gs u c is the transcript (gᵢ ^ u)ᵢ; [c]; [u + c · x] for witness x, randomness u and challenge c.
      Definition construct_eq_conversations_schnorr :
        ∀ {n : nat},
        F → Vector.t G (2 + n) → F →
        F → @sigma_proto F G (2 + n) 1 1.
      Proof.
        intros n x gs u c.
        remember (construct_eq_conversations_schnorr_commitment gs u)
        as commitment.
        exact (commitment; [c]; [u + c × x]).
      Defined.

Honest-verifier simulator: given the statement gs, hs, a random response u and challenge c, it produces announcements aᵢ = gᵢ ^ u · hᵢ ^ (-c) so that every verification equation holds by construction. It does not use any witness.
      Definition construct_eq_conversations_simulator :
        ∀ {n : nat},
        Vector.t G (2 + n) → Vector.t G (2 + n) →
        F → F → @sigma_proto F G (2 + n) 1 1.
      Proof.
        intros n gs hs u c.
        remember (zip_with (fun x y ⇒ (x, y)) gs hs) as commitment.
        exact (map (fun '(g, h) ⇒ gop (gpow g u) (gpow h (opp c))) commitment;
        [c]; [u]).
      Defined.

Verifier: generalised_eq_accepting_conversations gs hs (a; c; r) returns true iff for every index i the Schnorr equation gᵢ ^ r = aᵢ · hᵢ ^ c holds (checked by accepting_conversation). Defined by recursion on n, peeling off one base at a time; the base case n = 0 handles two bases.
       Definition generalised_eq_accepting_conversations :
        ∀ {n : nat},
        Vector.t G (2 + n) → Vector.t G (2 + n) →
        @sigma_proto F G (2 + n) 1 1 → bool.
      Proof.
        refine(
          fix Fn n :=
          match n with
          | 0 ⇒ fun gs hs Ha ⇒ _
          | S n' ⇒ fun gs hs Ha ⇒ _
          end).
        +
          refine
            match Ha with
            |(a; c; r) ⇒ _
            end.
          destruct (vector_inv_S gs) as (g₁ & gs₁ & _).
          destruct (vector_inv_S gs₁) as (g₂ & _ & _).
          destruct (vector_inv_S hs) as (h₁ & hs₁ & _).
          destruct (vector_inv_S hs₁) as (h₂ & _ & _).
          destruct (vector_inv_S a) as (a₁ & a₂ & _).
          exact (@accepting_conversation F G gop gpow Gdec g₁ h₁ ([a₁]; c; r) &&
          @accepting_conversation F G gop gpow Gdec g₂ h₂ (a₂; c; r)).
        +
          destruct (vector_inv_S gs) as (g & gtl & _).
          destruct (vector_inv_S hs) as (h & htl & _).
          refine
            match Ha with
            |(a; c; r) ⇒ _
            end.
          destruct (vector_inv_S a) as (ah & atl & _).
          exact ((@accepting_conversation F G gop gpow Gdec g h ([ah]; c; r)) &&
            (Fn _ gtl htl (atl; c; r))).
      Defined.

The distribution of honest transcripts for challenge c: draw u uniformly from lf and run the honest prover.
      Definition generalised_eq_schnorr_distribution
        {n : nat} (lf : list F) (Hlfn : lf ≠ List.nil) (x : F)
        (gs : Vector.t G (2 + n)) (c : F) : dist (@sigma_proto F G (2 + n) 1 1) :=
        u <- (uniform_with_replacement lf Hlfn) ;;
        Ret (construct_eq_conversations_schnorr x gs u c).

The distribution of simulated transcripts for challenge c: draw the response uniformly from lf and run the simulator.
      Definition generalised_eq_simulator_distribution
        {n : nat} (lf : list F)
        (Hlfn : lf ≠ List.nil) (gs hs : Vector.t G (2 + n))
        (c : F) : dist (@sigma_proto F G (2 + n) 1 1) :=
        r <- uniform_with_replacement lf Hlfn ;;
        Ret (construct_eq_conversations_simulator gs hs r c).

    End Def.

Proofs

The first group of lemmas characterises the boolean verifier as the index-wise conjunction of Schnorr checks, in both the accepting and the rejecting direction. They need no algebraic assumptions.
    Section Proofs.

If the EQ verifier accepts, then every component Schnorr transcript ([aᵢ]; c; r) for (gᵢ, hᵢ) accepts. By induction on n.
        Lemma generalised_eq_accepting_conversations_correctness_forward :
          ∀ (n : nat) (gs hs : Vector.t G (2 + n))
          (s : @sigma_proto F G (2 + n) 1 1),
          generalised_eq_accepting_conversations gs hs s = true →
          (∀ f : Fin.t (2 + n),
          match s with
          | (a; c; r) ⇒
            @accepting_conversation F G gop gpow Gdec (nth gs f) (nth hs f)
              ([(nth a f)]; c; r) = true
          end).
        Proof.
          induction n as [|n IHn].
          +
            intros × Ha ?.
            cbn in f.
            refine
              (match s as s' return s = s' → _
              with
              |(a; c; r) ⇒ fun Hb ⇒ _
              end eq_refl).
            destruct (vector_inv_S gs) as (gh & gstl & Hc).
            destruct (vector_inv_S gstl) as (ggh & gstll & Hd).
            destruct (vector_inv_S hs) as (hh & hstl & He).
            destruct (vector_inv_S hstl) as (hhh & hstll & Hf).
            destruct (vector_inv_S a) as (ah & atl & Hg).
            destruct (vector_inv_S atl) as (ahh & atll & Hi).
            destruct (fin_inv_S _ f) as [hf | (hf & Hj)].
            ++
              subst; cbn.
              cbn in Ha |- ×.
              eapply andb_true_iff in Ha.
              destruct Ha as [Hal Har].
              rewrite dec_true in Hal, Har |- ×.
              exact Hal.
            ++
              destruct (fin_inv_S _ hf) as [hff | (hff & Hjj)];
              [|inversion hff].
              cbn.
              eapply dec_true. subst.
              cbn in Ha |- ×.
              eapply andb_true_iff in Ha.
              destruct Ha as [Hal Har].
              rewrite dec_true in Hal, Har.
              exact Har.

          +
            intros × Ha ?.
            refine
              (match s as s' return s = s' → _
              with
              |(a; c; r) ⇒ fun Hb ⇒ _
              end eq_refl).
            destruct (vector_inv_S gs) as (gh & gstl & Hc).
            destruct (vector_inv_S hs) as (hh & hstl & Hd).
            destruct (vector_inv_S a) as (ah & atl & He).
            destruct (fin_inv_S _ f) as [hf | (hf & Hg)].
            subst; cbn in Ha |- ×.
            eapply andb_true_iff in Ha.
            destruct Ha as [Hal Har].
            exact Hal.
            subst. cbn in Ha |- ×.
            eapply andb_true_iff in Ha;
            destruct Ha as [Hal Har].
            specialize (IHn gstl hstl _ Har hf);
            cbn in IHn.
            exact IHn.
        Qed.

Completeness: if x is a common discrete logarithm, gᵢ ^ x = hᵢ for all i, then the honest transcript construct_eq_conversations_schnorr x gs u c is accepted for every u and c. By induction on n, reducing each index to schnorr_completeness from Sigma.
        Lemma construct_eq_conversations_schnorr_completeness
          {n : nat}
          (x : F)
          (gs hs : Vector.t G (2 + n))
          (R : ∀ (f : Fin.t (2 + n)),
            (Vector.nth gs f)^x = Vector.nth hs f) :
          ∀ (u c : F),
          generalised_eq_accepting_conversations gs hs
            (construct_eq_conversations_schnorr x gs u c) = true.
        Proof.
          unfold construct_eq_conversations_schnorr.
          induction n as [|n' IHn].
          +
            intros ×.
            destruct (vector_inv_S gs) as (gh & gstl & Ha).
            destruct (vector_inv_S gstl) as (ggh & gstll & Hb).
            destruct (vector_inv_S hs) as (hh & hstl & Hc).
            destruct (vector_inv_S hstl) as (hhh & hstll & Hd).
            pose proof (R Fin.F1) as He.
            pose proof (R (Fin.FS Fin.F1)) as Hf.
            subst. cbn in He, Hf |- ×.
            subst. cbn. eapply andb_true_iff.
            split; eapply schnorr_completeness; exact eq_refl.
          +
            intros ×. cbn in × |-.
            destruct (vector_inv_S gs) as (gh & gstl & Ha).
            destruct (vector_inv_S hs) as (hh & hstl & Hb).
            rewrite Ha, Hb. cbn.
            eapply andb_true_iff. split.
            ++
              eapply schnorr_completeness.
              subst; cbn.
              specialize (R Fin.F1);
              cbn in R; subst; reflexivity.
            ++
              eapply IHn.
              rewrite Ha, Hb in R.
              intro f.
              exact (R (Fin.FS f)).
        Qed.

      Lemma eq_commitment_shift (x : F) :
        ∀ (m : nat) (gs hs : Vector.t G m) (u c : F),
        (∀ f : Fin.t m, (Vector.nth gs f) ^ x = Vector.nth hs f) →
        Vector.map (fun g ⇒ gpow g u) gs =
        Vector.map (fun '(g, h) ⇒ gop (gpow g (u + c × x)) (gpow h (opp c)))
          (zip_with (fun g h ⇒ (g, h)) gs hs).
      Proof.
        induction m as [| m ih]; intros gs hs u c R.
        + rewrite (vector_inv_0 gs), (vector_inv_0 hs); reflexivity.
        + destruct (vector_inv_S gs) as (g & gs' & hg).
          destruct (vector_inv_S hs) as (h & hs' & hh).
          subst; cbn; f_equal.
          × apply schnorr_commitment_shift.
            symmetry; exact (R Fin.F1).
          × apply ih. intros f; exact (R (Fin.FS f)).
      Qed.

Transcript shift: the honest transcript for randomness u is exactly the simulated transcript for response u + c · x.
      Lemma construct_eq_shift {n : nat} (x : F) (gs hs : Vector.t G (2 + n))
        (R : ∀ f : Fin.t (2 + n), (Vector.nth gs f) ^ x = Vector.nth hs f) :
        ∀ (u c : F),
        construct_eq_conversations_schnorr x gs u c =
        construct_eq_conversations_simulator gs hs (u + c × x) c.
      Proof.
        intros ×.
        unfold construct_eq_conversations_schnorr,
          construct_eq_conversations_simulator,
          construct_eq_conversations_schnorr_commitment; cbn.
        f_equal.
        apply eq_commitment_shift; exact R.
      Qed.

Special honest-verifier zero-knowledge, strong form: if the map u ↦ u + c · x permutes the randomness list lf, then the honest and simulated transcript distributions are permutations of each other, i.e. identical as distributions. Proof: rewrite both as Bind over the uniform distribution and apply bind_ret_perm with the shift u ↦ u + c · x, using construct_eq_shift.
      Theorem generalised_eq_special_honest_verifier_zkp_perm {n : nat} (x : F)
        (gs hs : Vector.t G (2 + n))
        (R : ∀ f : Fin.t (2 + n), (Vector.nth gs f) ^ x = Vector.nth hs f) :
        ∀ (lf : list F) (Hlfn : lf ≠ List.nil) (c : F),
        Permutation (List.map (fun u ⇒ u + c × x) lf) lf →
        Permutation
          (@generalised_eq_schnorr_distribution n lf Hlfn x gs c)
          (@generalised_eq_simulator_distribution n lf Hlfn gs hs c).
      Proof.
        intros × hp.
        change (Permutation
          (Bind (uniform_with_replacement lf Hlfn)
            (fun u ⇒ Ret (construct_eq_conversations_schnorr x gs u c)))
          (Bind (uniform_with_replacement lf Hlfn)
            (fun u ⇒ Ret (construct_eq_conversations_simulator gs hs u c)))).
        eapply bind_ret_perm with (phi := fun u ⇒ u + c × x).
        + apply uniform_perm; exact hp.
        + intros u p _. apply construct_eq_shift; exact R.
      Qed.

Special honest-verifier zero-knowledge when lf enumerates the field without duplicates: then u ↦ u + c · x is a bijection of lf (with inverse u ↦ u - c · x), so generalised_eq_special_honest_verifier_zkp_perm applies.
      Theorem generalised_eq_special_honest_verifier_zkp_enum {n : nat} (x : F)
        (gs hs : Vector.t G (2 + n))
        (R : ∀ f : Fin.t (2 + n), (Vector.nth gs f) ^ x = Vector.nth hs f) :
        ∀ (lf : list F) (Hlfn : lf ≠ List.nil) (c : F),
        List.NoDup lf → (∀ y : F, List.In y lf) →
        Permutation
          (@generalised_eq_schnorr_distribution n lf Hlfn x gs c)
          (@generalised_eq_simulator_distribution n lf Hlfn gs hs c).
      Proof.
        intros × hnd hall.
        eapply generalised_eq_special_honest_verifier_zkp_perm; [exact R |].
        eapply enumerates_perm_map with (psi := fun u ⇒ u - c × x);
        [exact hnd | exact hall | intros u; field | intros u; field].
      Qed.

    End Proofs.
  End EQ.
