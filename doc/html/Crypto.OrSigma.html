Library Crypto.OrSigma

OR-composition of Schnorr protocols over a common generator

This file formalises the Cramer–Damgård–Schoenmakers (CDS) disjunctive composition of Schnorr's Σ-protocol for k = 2 + n discrete-logarithm statements that share one generator g. The public statement is a vector hs of group elements h₀, …, h₍ₖ₋₁₎ and the prover shows that it knows the discrete logarithm of one of them, without revealing which:

      R_OR(g, hs) = { (i, x) | hs[i] = g ^ x }
The protocol lets the prover answer all k branches, but only one of them honestly. The verifier sends a single challenge c and the prover may split it into branch challenges c₀, …, c₍ₖ₋₁₎ subject to the linear constraint c = c₀ + … + c₍ₖ₋₁₎. This one degree of freedom is enough to run the Schnorr simulator on every branch whose witness is unknown. For a prover that knows x with hs[i] = g ^ x the protocol is:
  • Commitment. For every j ≠ i pick uⱼ and cⱼ at random and set aⱼ = g ^ uⱼ · hⱼ ^ (opp cⱼ), which is a simulated Schnorr commitment. For the real branch pick u and set aᵢ = g ^ u.
  • Challenge. The verifier sends c.
  • Response. Set cᵢ = c - Σ_{j≠i} cⱼ and rᵢ = u + cᵢ · x, with rⱼ = uⱼ for j ≠ i. Send all cⱼ and all rⱼ.
  • Verification. Accept iff c = Σⱼ cⱼ and g ^ rⱼ = aⱼ · hⱼ ^ cⱼ for every branch j.
A transcript has type sigma_proto F G k (1 + k) k: k commitments, a challenge vector of length 1 + k whose head is the verifier's challenge c and whose tail is the split c₀ … c₍ₖ₋₁₎, and k responses. The prover's randomness is one vector uscs of length k + (k - 1), written (2 + n) + (1 + n): the first k entries are the per-branch values uⱼ and the last k - 1 entries are the simulated challenges of the fake branches.
The main results, all for an arbitrary number 2 + n of branches, are:
  • completeness generalised_construct_or_conversations_schnorr_completeness: if hs[rindex] = g ^ x then the transcript built by the prover is accepted for every choice of randomness and challenge;
  • special soundness generalised_or_sigma_soundness_main: two accepting transcripts with the same commitment and different top-level challenges yield an index f and an exponent y with g ^ y = hs[f];
  • special honest-verifier zero knowledge: the simulator generalised_construct_or_conversations_simulator produces accepting transcripts without the witness (generalised_construct_or_conversations_simulator_completeness); the real and simulated distributions give every transcript the same weight and the same verification result (generalised_or_special_honest_verifier_zkp); and, when the sampling list enumerates the field without duplicates, the two distributions are permutations of each other, so they are equal (generalised_or_special_honest_verifier_zkp_perm).
The protocol only proves knowledge of one witness out of k. The k-out-of-n threshold variant of Cramer, Damgård and Schoenmakers, built from secret sharing, is not formalised.
The file depends on Sigma (the record sigma_proto, the Schnorr verifier accepting_conversation, Schnorr special soundness special_soundness_berry and the commitment identity schnorr_commitment_shift) and on the distribution monad of Probability.Distr. The file OrSigmaGen is the same construction with a separate generator per branch; the tally verifiers use that version. This file is instantiated in Examples.OrSigmaIns and extracted to OCaml through Extraction/OrSigmalib.
Reference: R. Cramer, I. Damgård, B. Schoenmakers, Proofs of Partial Knowledge and Simplified Design of Witness Hiding Protocols, CRYPTO 1994 (https://www.win.tue.nl/~berry/papers/crypto94.pdf).

Everything is parametric in a field F of scalars (exponents and challenges) and a group G written multiplicatively, with exponentiation gpow by scalars. Definitions

    Section Defs.

Commitment vector of the prover, for the case where the real branch sits at position m of a statement of length m + (1 + n).
The randomness uscs is split as us ++ cs, with us = usl ++ [u] ++ usr (one value per branch) and cs = csl ++ csr (one simulated challenge per fake branch, so m + n in total). The result is commitl ++ [g ^ u] ++ commitr where each fake branch j gets the simulated commitment g ^ uⱼ · hⱼ ^ (opp cⱼ). The entry of hs at position m is not used: the real commitment does not depend on the statement.
        Definition construct_or_conversations_schnorr_commitment {m n : nat}
         (g : G) (hs : Vector.t G (m + (1 + n)))
         (uscs : Vector.t F ((m + (1 + n)) + (m + n))) :
         Vector.t G ((m + (1 + n))).
        Proof.
          destruct (splitat (m + (1 + n)) uscs) as (us & cs).
          destruct (splitat m us) as (usl & usrh).
          destruct (vector_inv_S usrh) as (u & usr & _).
          destruct (splitat m cs) as (csl & csr).
          destruct (splitat m hs) as (hsl & hsrh).
          destruct (vector_inv_S hsrh) as (_ & hsr & _).
          set (coml := zip_with (fun ui ci ⇒ (ui, ci)) usl csl).
          set (commitl := zip_with (fun hi '(ui, ci) ⇒ gop (g^ui) (hi^(opp ci))) hsl coml).
          set (com := g^u).
          set (comr := zip_with (fun ui ci ⇒ (ui, ci)) usr csr).
          set (commitr := zip_with (fun hi '(ui, ci) ⇒ gop (g^ui) (hi^(opp ci))) hsr comr).
          exact ((commitl ++ [com] ++ commitr)).
        Defined.

Full prover transcript when the witness x is for branch m, that is hs[m] = g ^ x.
The commitment comes from construct_or_conversations_schnorr_commitment. The real branch challenge is cb = c - Σ (csl ++ csr), so that all branch challenges add up to c, and its response is u + cb · x. The challenge vector is c :: csl ++ [cb] ++ csr and the response vector is usl ++ [u + cb · x] ++ usr: fake branches reuse their sampled uⱼ as responses. This version fixes the real index through the type m + (1 + n); generalised_construct_or_conversations_schnorr takes the index as a Fin.t instead.
        #[local]
        Definition construct_or_conversations_schnorr {m n : nat}
          (x : F) (g : G) (hs : Vector.t G (m + (1 + n)))
          (uscs : Vector.t F ((m + (1 + n)) + (m + n))) (c : F) :
          @sigma_proto F G (m + (1 + n)) (1 + (m + (1 + n))) (m + (1 + n)).
        Proof.
          set (comm := @construct_or_conversations_schnorr_commitment m n g hs
            uscs).
          destruct (splitat (m + (1 + n)) uscs) as (us & cs).
          destruct (splitat m us) as (usl & usrh).
          destruct (vector_inv_S usrh) as (u & usr & _).
          destruct (splitat m cs) as (csl & csr).
          remember (c - (Vector.fold_right add (csl ++ csr) zero)) as cb.
          remember (u + cb × x) as res.
          refine(comm; c :: csl ++ [cb] ++ csr ; usl ++ [res] ++ usr).
        Defined.

Prover for 2 + n branches with the real branch given by rindex : Fin.t (2 + n).
vector_fin_app_pred computes m₁ and m₂ with 2 + n = m₁ + (1 + m₂), where m₁ is the numeric value of rindex, together with matching splits of the randomness. The statement and the randomness are transported along these equalities and construct_or_conversations_schnorr is called with m = m₁. The result is transported back to length 2 + n. Arguments: rindex is the branch whose witness is known, x is the witness, g hs is the statement, uscs is the randomness of length (2 + n) + (1 + n) and c is the verifier's challenge.
        Definition generalised_construct_or_conversations_schnorr {n : nat}
          (rindex : Fin.t (2 + n)) (x : F) (g : G) (hs : Vector.t G (2 + n))
          (uscs : Vector.t F ((2 + n) + (1 + n))) (c : F) :
          @sigma_proto F G (2 + n) (1 + (2 + n)) (2 + n).
        Proof.
          destruct (splitat (2 + n) uscs) as (us & cs).
          destruct (@vector_fin_app_pred F (1 + n) rindex us cs) as
          (m₁ & m₂ & v₁ & v₃ & vm & v₂ & v₄ & pfaa & pfbb & _).
          inversion pfaa as [pfa].
          inversion pfbb as [pfb].
          pose proof (@construct_or_conversations_schnorr m₁ m₂ x g
          (rew pfa in hs) ((rew pfa in us) ++ (rew pfb in cs)) c) as hd.
          rewrite <-pfa in hd.
          exact hd.
        Defined.

Special honest-verifier simulator. It needs no witness and no index.
It splits uscs into us (length 2 + n) and cs (length 1 + n), sets the branch challenges to cm = (c - Σ cs) :: cs, so they add up to c, and runs the Schnorr simulator on every branch: commitment aⱼ = g ^ usⱼ · hsⱼ ^ (opp cmⱼ) and response usⱼ. The transcript is (a; c :: cm; us). Here the first branch takes the dependent challenge, whereas the prover gives it to branch rindex. or_shift bridges this difference in the zero-knowledge proof.
        Definition generalised_construct_or_conversations_simulator {n : nat}
          (g : G) (hs : Vector.t G (2 + n)) (uscs : Vector.t F ((2 + n) + (1 + n)))
          (c : F) : @sigma_proto F G (2 + n) (1 + (2 + n)) (2 + n).
        Proof.
          destruct (splitat (2 + n) uscs) as (us & cs).
          set (cm := (c - (Vector.fold_right add cs zero) :: cs)).
          set (comm := zip_with (fun ui ci ⇒ (ui, ci)) us cm).
          set(commitment := zip_with (fun hi '(ui, ci) ⇒
            gop (g^ui) (hi^(opp ci))) hs comm).
          refine(commitment; c :: cm; us).
        Defined.

Branch-wise verifier, defined by recursion on the number of branches: it checks the Schnorr equation g ^ rⱼ = aⱼ · hⱼ ^ cⱼ for each branch with the single-branch verifier accepting_conversation from Sigma, and returns the conjunction. Here the challenge vector has one entry per branch and no leading top-level challenge.
        #[local]
        Definition or_accepting_conversations_supplement :
          ∀ {n : nat}, G → Vector.t G n → @sigma_proto F G n n n → bool.
        Proof.
          refine
            (fix Fn n :=
            match n with
            | 0 ⇒ fun g hs Ha ⇒ true
            | S n' ⇒ fun g hs Ha ⇒
              match Ha with
              | (a₁; c₁; r₁) ⇒ _
              end
            end).
          destruct (vector_inv_S hs) as (h & hsr & _).
          destruct (vector_inv_S a₁) as (a & asr & _).
          destruct (vector_inv_S c₁) as (c & csr & _).
          destruct (vector_inv_S r₁) as (r & rsr & _).
          exact ((@accepting_conversation F G gop gpow Gdec g h ([a]; [c]; [r])) &&
            (Fn _ g hsr (asr; csr; rsr))).
        Defined.

Verifier of the OR protocol. For a transcript (a; c :: cs; r) it accepts iff c = Σ cs (tested with Fdec) and every branch passes its Schnorr check, as computed by or_accepting_conversations_supplement on (a; cs; r). The statement is g hs; the number of branches n is arbitrary here, including 0 and 1.
        Definition generalised_or_accepting_conversations {n : nat}
          (g : G) (hs : Vector.t G n)
          (pf : @sigma_proto F G n (1 + n) n) : bool.
        Proof.
          refine
            match pf with
            |(a; css; r) ⇒ _
            end.
          destruct (vector_inv_S css) as (c & cs & _).
          refine
            match Fdec c (Vector.fold_right add cs zero) with
            | left _ ⇒
                or_accepting_conversations_supplement g hs (a; cs; r)
            | right _ ⇒ false
            end.
        Defined.

Distribution of real transcripts for a fixed challenge c: draw uscs uniformly (with replacement) from the non-empty list lf, independently in each of the (2 + n) + (1 + n) coordinates, and run the prover generalised_construct_or_conversations_schnorr. When lf lists the whole field this is the honest prover's distribution.
        Definition generalised_or_schnorr_distribution
          {n : nat} (lf : list F) (Hlfn : lf ≠ List.nil)
          (rindex : Fin.t (2 + n)) (x : F) (g : G) (hs : Vector.t G (2 + n)) (c : F) :
          dist (@sigma_proto F G (2 + n) (1 + (2 + n)) (2 + n)) :=
          uscs <- repeat_dist_ntimes_vector
            (uniform_with_replacement lf Hlfn) ((2 + n) + (1 + n)) ;;
          Ret (generalised_construct_or_conversations_schnorr rindex x g hs uscs c).

Distribution of simulated transcripts for a fixed challenge c: draw the same amount of randomness as the prover and run generalised_construct_or_conversations_simulator.
        Definition generalised_or_simulator_distribution
          {n : nat} (lf : list F) (Hlfn : lf ≠ List.nil)
          (g : G) (hs : Vector.t G (2 + n)) (c : F) :
          dist (@sigma_proto F G (2 + n) (1 + (2 + n)) (2 + n)) :=
          usrs <- repeat_dist_ntimes_vector
            (uniform_with_replacement lf Hlfn) ((2 + n) + (1 + n)) ;;
          Ret (generalised_construct_or_conversations_simulator g hs usrs c).

    End Defs.

Proofs

The first group of lemmas characterises the boolean verifiers by propositional statements over all branches. Then come completeness for the prover and the simulator, special soundness, and special honest-verifier zero knowledge.
    Section Proofs.

If the branch-wise verifier accepts (a; c; r), then for every branch f the single Schnorr conversation formed by the f-th components of a, c and r is accepting for the statement (g, hs[f]).
        Lemma or_accepting_conversations_correctness_supplement_forward :
          ∀ {n : nat} (g : G) (hs : Vector.t G n)
          (s : @sigma_proto F G n n n),
          or_accepting_conversations_supplement g hs s = true →
          (match s with
          | (a; c; r) ⇒
            ∀ f : Fin.t n,
            @accepting_conversation F G gop gpow Gdec g (nth hs f)
              ([(nth a f)]; [nth c f]; [(nth r f)]) = true
          end).
        Proof.
          induction n as [|n IHn].
          +
            intros × Ha.
            refine
              (match s as s' return s = s' → _
              with
              | (a₁; c₁; r₁) ⇒ fun Hb ⇒ _
              end eq_refl).
            intros f;
            inversion f.
          +
            intros × Ha.
            refine
              (match s as s' return s = s' → _
              with
              | (a₁; c₁; r₁) ⇒ fun Hb ⇒ _
              end eq_refl); intro f.
            destruct (vector_inv_S hs) as (hsh & hstl & Hd).
            destruct (vector_inv_S a₁) as (ah₁ & atl₁ & He).
            destruct (vector_inv_S c₁) as (ch₁ & ctl₁ & Hf).
            destruct (vector_inv_S r₁) as (rh₁ & rtl₁ & Hg).
            destruct (fin_inv_S _ f) as [Hi | (fs & Hi)];
            subst; simpl.
            ++
              cbn in Ha.
              eapply andb_true_iff in Ha.
              destruct Ha as [Hal Har].
              exact Hal.
            ++
              simpl in Ha;
              eapply andb_true_iff in Ha.
              destruct Ha as [Hal Har].
              exact (IHn _ _ _ Har fs).
        Qed.

If the branch-wise verifier rejects, some branch f has a rejecting single-branch Schnorr conversation.
        Lemma or_accepting_conversations_correctness_supplement_forward_reject :
          ∀ {n : nat} (g : G) (hs : Vector.t G n)
          (s : @sigma_proto F G n n n),
          or_accepting_conversations_supplement g hs s = false →
          (match s with
          | (a; c; r) ⇒
            ∃ f : Fin.t n,
            @accepting_conversation F G gop gpow Gdec g (nth hs f)
              ([(nth a f)]; [nth c f]; [(nth r f)]) = false
          end).
        Proof.
          induction n as [|n ihn].
          +
            intros × ha.
            cbn in ha; congruence.
          +
            intros × ha.
            refine
              (match s as s' return s = s' → _
              with
              | (a₁; c₁; r₁) ⇒ fun hb ⇒ _
              end eq_refl).
            rewrite hb in ha.
            destruct (vector_inv_S hs) as (hsh & hstl & Hd).
            destruct (vector_inv_S a₁) as (ah₁ & atl₁ & He).
            destruct (vector_inv_S c₁) as (ch₁ & ctl₁ & Hf).
            destruct (vector_inv_S r₁) as (rh₁ & rtl₁ & Hg).
            subst. cbn in ha.
            destruct (Gdec (g ^ rh₁) (gop ah₁ (hsh ^ ch₁))) as [hb | hb].
            ++
              destruct (ihn g hstl (atl₁; ctl₁; rtl₁) ha) as (f & hc).
              ∃ (Fin.FS f); cbn. exact hc.
            ++
              ∃ Fin.F1; cbn.
              eapply dec_false.
              exact hb.
        Qed.

Converse of or_accepting_conversations_correctness_supplement_forward: if every branch has an accepting Schnorr conversation, the branch-wise verifier accepts.
        Lemma or_accepting_conversations_correctness_supplement_backward :
          ∀ {n : nat} (g : G) (hs : Vector.t G n)
          (s : @sigma_proto F G n n n),
          (match s with
          | (a; c; r) ⇒
            ∀ f : Fin.t n,
            @accepting_conversation F G gop gpow Gdec g (nth hs f)
              ([(nth a f)]; [nth c f]; [(nth r f)]) = true
          end) → or_accepting_conversations_supplement g hs s = true.
        Proof.
          induction n as [|n IHn].
          +
            intros × Ha.
            rewrite (vector_inv_0 hs);
            cbn; reflexivity.
          +
            intros × Ha.
            refine
              (match s as s' return s = s' → _
              with
              | (a₁; c₁; r₁) ⇒ fun Hb ⇒ _
              end eq_refl).
            destruct (vector_inv_S hs) as (hsh & hstl & Hd).
            destruct (vector_inv_S a₁) as (ah₁ & atl₁ & He).
            destruct (vector_inv_S c₁) as (ch₁ & ctl₁ & Hf).
            destruct (vector_inv_S r₁) as (rh₁ & rtl₁ & Hg).
            subst; cbn.
            eapply andb_true_iff.
            split.
            ++
              pose proof (Ha Fin.F1) as Hi.
              cbn in Hi.
              exact Hi.
            ++
              specialize (IHn g hstl (atl₁; ctl₁; rtl₁)).
              assert (Hb : (∀ f : Fin.t n,
              match (atl₁; ctl₁; rtl₁) with
              | (a; c; r) ⇒
                  @accepting_conversation F G gop gpow Gdec g hstl[@f]
                    ([a[@f]]; [c[@f]]; [r[@f]]) = true
              end)).
              intros *; exact (Ha (Fin.FS f)).
              exact (IHn Hb).
        Qed.

              with
              | (a₁; c₁; r₁) ⇒ fun hb ⇒ _
              end eq_refl).

        Qed.

The branch-wise verifier accepts iff every branch has an accepting Schnorr conversation.
        Lemma or_accepting_conversations_correctness_supplement :
          ∀ {n : nat} (g : G) (hs : Vector.t G n)
          (s : @sigma_proto F G n n n),

Equality of the real and simulated distributions

The simulator gives the dependent challenge to branch 0, while the prover gives it to branch rindex and adds cb · x to that branch's response. or_shift rindex x c maps prover randomness to the simulator randomness that yields the same transcript. With uscs = us ++ cs and cb = c - Σ cs, it replaces us[rindex] by us[rindex] + cb · x and inserts cb into cs at position rindex. The head of the result is dropped, because the simulator recomputes it from the sum. The map is a bijection, with inverse or_unshift, so it preserves the uniform distribution.
        Definition or_shift {n : nat} (rindex : Fin.t (2 + n)) (x c : F)
          (uscs : Vector.t F ((2 + n) + (1 + n))) : Vector.t F ((2 + n) + (1 + n)) :=
          let (us, cs) := splitat (2 + n) uscs in
          let cb := c - Vector.fold_right add cs zero in
          Vector.append (replace us rindex (us[@rindex] + cb × x))
            (tl (insert_at (1 + n) cs rindex cb)).

Special honest-verifier zero knowledge as equality of distributions. Assume hs[rindex] = g ^ x, and that the sampling list lf has no duplicates and contains every field element, so that it is the uniform distribution on F. Then for every challenge c the real transcript distribution is a permutation of the simulated one: they give every transcript the same probability. The simulator does not use x or rindex.
Proof idea: by construct_or_shift the prover equals the simulator composed with or_shift. Since or_shift is a bijection on randomness vectors (or_unshift_shift, or_shift_unshift), it permutes the uniform product distribution (repeat_uniform_bijection_perm); bind_ret_perm combines the two facts.
        Theorem generalised_or_special_honest_verifier_zkp_perm {n : nat} (x : F)
          (g : G) (hs : Vector.t G (2 + n)) (rindex : Fin.t (2 + n))
          (R : hs[@rindex] = g ^ x) :
          ∀ (lf : list F) (Hlfn : lf ≠ List.nil) (c : F),
          List.NoDup lf → (∀ y : F, List.In y lf) →
          Permutation
            (generalised_or_schnorr_distribution lf Hlfn rindex x g hs c)
            (generalised_or_simulator_distribution lf Hlfn g hs c).
        Proof.
          intros × hnd hall.
          change (Permutation
            (Bind (repeat_dist_ntimes_vector (uniform_with_replacement lf Hlfn)
                ((2 + n) + (1 + n)))
              (fun uscs ⇒ Ret (generalised_construct_or_conversations_schnorr
                rindex x g hs uscs c)))
            (Bind (repeat_dist_ntimes_vector (uniform_with_replacement lf Hlfn)
                ((2 + n) + (1 + n)))
              (fun uscs ⇒ Ret (generalised_construct_or_conversations_simulator
                g hs uscs c)))).
          eapply bind_ret_perm with (phi := or_shift rindex x c).
          + apply (repeat_uniform_bijection_perm lf Hlfn _ _
              (or_unshift rindex x c) hnd hall);
            [apply or_unshift_shift | apply or_shift_unshift].
          + intros uscs p _. apply construct_or_shift; exact R.
        Qed.
