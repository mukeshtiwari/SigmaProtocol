Library Frontend.Schulze

Receipt-free Schulze ballots, version 1: pairwise bits with position consistency

This file formalises the voter side of a receipt-free encrypted preferential ballot for the Schulze method (Schulze 2011). The tally side, in which trustees certify the Schulze winner on the encrypted pairwise margins without decrypting them, is in Backend/SchulzeTally.v. Because individual ballots and the margins are never decrypted, a voter cannot be identified through a pattern of preferences (the so-called Italian attack), which is what receipt-free refers to here.
Ballot encoding._ For m candidates the voter chooses a position s_i ∈ {0, …, m} for every candidate i; smaller positions are preferred, equal positions are ties (a weak ranking), and position m can be used for unranked candidates. The ballot contains:
  • for every candidate i, the ciphertext Enc(s_i) and a membership proof that s_i ∈ {0, …, m};
  • for every ordered pair (i, j) (including i = j), the ciphertext Enc(b_ij) of the preference bit b_ij = 1 iff s_i < s_j, a bit proof b_ij ∈ {0, 1}, and a membership proof for the homomorphic combination
            Enc(b_ij) ^ K · Enc(δ_ij) = Enc(K · b_ij + δ_ij), K = 2m + 1,
    in the set {-m, …, 0} ∪ {K+1, …, K+m}, where Enc(δ_ij) = Enc(s_j) · Enc(s_i)⁻¹ is computed by the verifier from the position ciphertexts (it is not part of the ballot; the voter knows its randomness r_j - r_i).
Here Enc is exponential ElGamal, Enc(v; r) = (g ^ r, g ^ v · h ^ r).
Why the shift by K._ The statement to prove for a pair is the disjunction of conjunctions
      (b_ij = 1 ∧ δ_ij ∈ {1, …, m}) ∨ (b_ij = 0 ∧ δ_ij ∈ {-m, …, 0}).
The generic OR/AND combinators of Crypto/OrSigmaGen.v and Crypto/AndSigmaGen.v only compose Schnorr statements over a single group, so this cannot be built from them directly. Instead, given b_ij ∈ {0, 1} (bit proof) and δ_ij ∈ [-m, m] (both positions are in 0, m), the value K · b_ij + δ_ij lies in {-m, …, 0} exactly when the second disjunct holds and in {K+1, …, K+m} exactly when the first holds, because K = 2m + 1 separates the two ranges. The disjunction is therefore one set-membership proof, and every proof of the ballot is an instance of the CDS-style disjunctive encryption proof of Crypto/EncProof.v (the bit proof is literally the approval-vote proof of Frontend/Approval.v).
Results._
  • Completeness: ballot_valid (interactive) and nizk_ballot_valid (Fiat–Shamir with one hashed challenge per ballot).
  • Special soundness: ballot_sound extracts, from two accepting ballots with equal ciphertexts and announcements and different challenges in every proof, positions s ∈ [0, m]^m such that every pairwise ciphertext decrypts to g ^ [s_i < s_j] . Hypotheses: exponentiation in base g is injective (exp_injective) and the field has characteristic above 4m + 2 (natF_injective); both hold for a prime-order group with q > 4m + 2.
  • Aggregation: aggregate_margins_enc and cdec_aggregate show that the product of the bit ciphertexts of all ballots encrypts the pairwise margin matrix D_ij = number of ballots with s_i < s_j.
  • Special honest-verifier zero knowledge: ballot_zk shows that the proofs of an honest ballot are distributed (as a list-based distribution, up to permutation) exactly as the output of a simulator that sees only the ciphertexts and the challenges.
The batched variant Frontend/SchulzeBatched.v (version 2) and the simplified variant Frontend/SchulzeSimple.v (version 3) replace the m² membership proofs by Pedersen-committed linear and zero arguments and are much smaller; they reuse the ciphertext algebra and some lemmas of this file.

Definitions

Ciphertext algebra

ElGamal ciphertexts are pairs in G × G; the group operations are lifted componentwise.
  Section Definitions.

cmul a b is the componentwise product (homomorphic addition of plaintexts).
    Definition cmul (a b : G × G) : G × G :=
      (gop (fst a) (fst b), gop (snd a) (snd b)).
cinv a is the componentwise inverse (negation of the plaintext).
    Definition cinv (a : G × G) : G × G := (ginv (fst a), ginv (snd a)).
cpow a k raises both components to k (scales the plaintext by k).
    Definition cpow (a : G × G) (k : F) : G × G := (fst a ^ k, snd a ^ k).
cid is the trivial ciphertext (1, 1), the encryption of 0 with randomness 0.
    Definition cid : G × G := (gid, gid).
ceqb a b decides equality of ciphertexts.
    Definition ceqb (a b : G × G) : bool :=
      match Gdec (fst a) (fst b), Gdec (snd a) (snd b) with
      | left _, left _ ⇒ true
      | _, _ ⇒ false
      end.
cdec x a decrypts a = (a₁, a₂) with secret key x: it returns a₂ · (a₁ ^ x)⁻¹, which is g ^ v for an encryption of v (cdec_enc).
    Definition cdec (x : F) (a : G × G) : G := gop (snd a) (ginv (fst a ^ x)).

Set membership of an ElGamal plaintext

The disjunctive encryption proof of Crypto/EncProof.v over a list ms of n group elements: cp encrypts one of ms, that is, ∃ r k, cp = (g ^ r, ms_k · h ^ r).
A membership proof over n messages is a Sigma transcript with n announcements, 1 + n challenges (the main challenge followed by the branch challenges) and n responses.
    Definition membership_proof (n : nat) : Type :=
      @sigma_proto F (G × G) n (S n) n.

Verifier of the membership proof: all n Chaum–Pedersen branches accept and the branch challenges add up to the main challenge.
    Definition verify_membership {n : nat} (g h : G) (ms : Vector.t G n)
      (cp : G × G) (pf : membership_proof n) : bool :=
      @generalised_accepting_encryption_proof_elgamal F zero add Fdec
        G ginv gop gpow Gdec n ms g h cp pf.

Honest prover: cp encrypts ms[rindex] with randomness r. The prover randomness uscs holds 2 + n commitment exponents and 1 + n simulated challenges.
    Definition prove_membership {n : nat} (g h : G) (ms : Vector.t G (2 + n))
      (rindex : Fin.t (2 + n)) (r : F) (uscs : Vector.t F ((2 + n) + (1 + n)))
      (cp : G × G) (c : F) : membership_proof (2 + n) :=
      @generalised_construct_encryption_proof_elgamal_real F zero add mul sub
        opp G ginv gop gpow n rindex r uscs ms g h cp c.

The announcement of the honest membership proof, computed before the challenge is known (with dummy witness and challenge zero, which do not affect it: prove_membership_announcement).
    Definition membership_commitment {n : nat} (g h : G) (ms : Vector.t G (2 + n))
      (rindex : Fin.t (2 + n)) (uscs : Vector.t F ((2 + n) + (1 + n)))
      (cp : G × G) : Vector.t (G × G) (2 + n) :=
      Sigma.announcement (prove_membership g h ms rindex zero uscs cp zero).

Ballots for m candidates

The data layout of a ballot and its verifier. Everything here is parametric in the number of candidates m, the generator g and the election public key h.
    Section Ballot.
      Context {m : nat} (g h : G).

The admissible position messages [g ^ 0; g ^ 1; …; g ^ m] .
      Definition msgs_pos : Vector.t G (S m) :=
        Vector.map (fun k ⇒ g ^ natF (fin_idx k)) (fin_enum (S m)).

The separating shift K = 2m + 1.
      Definition pair_shift : nat := S (m + m).

The admissible messages of the combined pair value K · b + δ:
          g ^ 0, g ^ -1, …, g ^ -m, g ^ (K+1), …, g ^ (K+m)
The first m + 1 entries are the case b = 0 (δ ∈ {-m, …, 0}, at index -δ), the last m entries the case b = 1 (δ ∈ {1, …, m}, at index m + δ).
      Definition msgs_pair : Vector.t G (S m + m) :=
        Vector.map (fun k ⇒ ginv (g ^ natF (fin_idx k))) (fin_enum (S m)) ++
        Vector.map (fun k ⇒ g ^ natF (pair_shift + S (fin_idx k))) (fin_enum m).

A position cell: Enc(s_i) and the proof s_i ∈ {0, …, m}.
      Definition pos_cell : Type := G × G × membership_proof (S m).

A pair cell: Enc(b_ij), the bit proof b_ij ∈ {0, 1}, and the membership proof K · b_ij + δ_ij ∈ {-m, …, 0} ∪ {K+1, …, K+m}.
      Definition pair_cell : Type :=
        (G × G) × @sigma_proto F (G × G) 2 3 2 × membership_proof (S m + m).

A ballot: m position cells and an m × m matrix of pair cells.
      Definition ballot : Type :=
        Vector.t pos_cell m × Vector.t (Vector.t pair_cell m) m.

Projections out of position and pair cells.
      Definition pos_cipher (pc : pos_cell) : G × G := fst pc.
      Definition pair_bit (pc : pair_cell) : G × G := fst (fst pc).
      Definition pair_bit_proof (pc : pair_cell) : @sigma_proto F (G × G) 2 3 2 :=
        snd (fst pc).
      Definition pair_mem_proof (pc : pair_cell) : membership_proof (S m + m) :=
        snd pc.

pair_combined cd pc is Enc(b_ij) ^ K · cd, the ciphertext on which the pair membership proof is checked; cd is Enc(δ_ij) as computed by the verifier.
      Definition pair_combined (cd : G × G) (pc : pair_cell) : G × G :=
        cmul (cpow (pair_bit pc) (natF pair_shift)) cd.

A position cell is valid iff its membership proof over msgs_pos accepts.
      Definition verify_pos_cell (pc : pos_cell) : bool :=
        verify_membership g h msgs_pos (pos_cipher pc) (snd pc).

A pair cell is valid with respect to cd = Enc(δ_ij) iff its bit proof (the approval-vote verifier) and its combined membership proof over msgs_pair accept.
      Definition verify_pair_cell (cd : G × G) (pc : pair_cell) : bool :=
        (@verify_encryption_vote_proof F zero one add Fdec G ginv gop gpow Gdec
          g h (pair_bit pc, pair_bit_proof pc) &&
         verify_membership g h msgs_pair (pair_combined cd pc) (pair_mem_proof pc))%bool.

All position cells are valid.
      Definition verify_positions (b : ballot) : bool :=
        forall_fin m (fun i ⇒ verify_pos_cell (Vector.nth (fst b) i)).

All pair cells are valid, with Enc(δ_ij) computed as Enc(s_j) · Enc(s_i)⁻¹ from the position ciphertexts.
      Definition verify_pairs (b : ballot) : bool :=
        forall_fin m (fun i ⇒ forall_fin m (fun j ⇒
          verify_pair_cell
            (cmul (pos_cipher (Vector.nth (fst b) j)) (cinv (pos_cipher (Vector.nth (fst b) i))))
            (Vector.nth (Vector.nth (snd b) i) j))).

The interactive ballot verifier.
      Definition verify_ballot (b : ballot) : bool :=
        (verify_positions b && verify_pairs b)%bool.

The m × m matrix of encrypted preference bits of a ballot.
      Definition ballot_bits (b : ballot) : Vector.t (Vector.t (G × G) m) m :=
        Vector.map (Vector.map pair_bit) (snd b).

aggregate_margins bs multiplies the bit matrices of all ballots entrywise, giving Enc(D_ij) with D_ij = Σ_ballots b_ij (aggregate_margins_enc).
      Definition aggregate_margins {N : nat} (bs : Vector.t ballot N) :
        Vector.t (Vector.t (G × G) m) m :=
        Vector.fold_right (fun b acc ⇒ Vector.map2 (Vector.map2 cmul) (ballot_bits b) acc)
          bs (Vector.const (Vector.const cid m) m).

The decrypted bit b_ij of a ballot under the secret key x, as a group element; for a valid ballot it is g ^ 0 or g ^ 1.
      Definition plaintext_bit (x : F) (b : ballot) (i j : Fin.t m) : G :=
        cdec x (pair_bit (Vector.nth (Vector.nth (snd b) i) j)).

    End Ballot.

The honest voter

The voter for m = n + 1 candidates (at least one, so that the EncProof index types 2 + k are inhabited). All randomness, including the challenges in the interactive form, is supplied explicitly in records.
    Section Prover.
      Context {n : nat} (g h : G).
      Local Notation m := (S n).

Randomness for one position cell: encryption randomness ps_r, membership-proof randomness ps_uscs and challenge ps_c.
      Record pos_rand : Type := mk_pos_rand {
        ps_r : F;
        ps_uscs : Vector.t F ((2 + n) + (1 + n));
        ps_c : F
      }.

Randomness for one pair cell: encryption randomness pr_rb of the bit, bit-proof randomness pr_uscs_b and challenge pr_c_b, membership-proof randomness pr_uscs_m and challenge pr_c_m.
      Record pair_rand : Type := mk_pair_rand {
        pr_rb : F;
        pr_uscs_b : Vector.t F 3;
        pr_c_b : F;
        pr_uscs_m : Vector.t F ((2 + (n + S n)) + (1 + (n + S n)));
        pr_c_m : F
      }.

Randomness for a whole ballot.
      Record ballot_rand : Type := mk_ballot_rand {
        br_pos : Vector.t pos_rand m;
        br_pair : Vector.t (Vector.t pair_rand m) m
      }.

encrypt_pos s rd encrypts the position s and proves membership at index s of msgs_pos.
      Definition encrypt_pos (s : nat) (rd : pos_rand) : @pos_cell m :=
        let cp := @enc F G gop gpow g h (natF s) (ps_r rd) in
        (cp, prove_membership g h (msgs_pos (m := m) g) (fin_of_nat_default s m)
          (ps_r rd) (ps_uscs rd) cp (ps_c rd)).

pair_index si sj is the index of g ^ (K b + δ) in msgs_pair: m + (sj - si) if si < sj (b = 1), and si - sj otherwise (b = 0).
      Definition pair_index (si sj : nat) : Fin.t (S m + m) :=
        if Nat.ltb si sj
        then fin_of_nat_default (m + (sj - si)) (m + m)
        else fin_of_nat_default (si - sj) (m + m).

encrypt_pair si sj ri rj rd builds the pair cell for positions si, sj whose ciphertexts used randomness ri, rj: it encrypts b = [si < sj] , proves b ∈ {0, 1} with generate_enc_proof of Frontend/Approval.v, and proves that the combination Enc(b) ^ K · Enc(δ) (randomness K · rb + (rj - ri)) encrypts the message at pair_index si sj. The local cd is exactly the verifier's Enc(s_j) · Enc(s_i)⁻¹ because rdelta = rj - ri.
      Definition encrypt_pair (si sj : nat) (ri rj : F) (rd : pair_rand) :
        @pair_cell m :=
        let b : F := if Nat.ltb si sj then one else zero in
        let cb := @enc F G gop gpow g h b (pr_rb rd) in
        let pfb := @generate_enc_proof F zero one add mul sub opp Fdec G ginv gop gpow
          g h (pr_rb rd) b (pr_uscs_b rd) cb (pr_c_b rd) in
        let rdelta := sub rj ri in
        let cd := @enc F G gop gpow g h (sub (natF sj) (natF si)) rdelta in
        let rc := (natF (@pair_shift m) × pr_rb rd) + rdelta in
        let cc := cmul (cpow cb (natF (@pair_shift m))) cd in
        (cb, pfb, prove_membership g h (msgs_pair (m := m) g) (pair_index si sj)
          rc (pr_uscs_m rd) cc (pr_c_m rd)).

encrypt_ballot s rd builds the full ballot for the position vector s.
      Definition encrypt_ballot (s : Vector.t nat m) (rd : ballot_rand) : @ballot m :=
        (Vector.map (fun i ⇒ encrypt_pos (Vector.nth s i) (Vector.nth (br_pos rd) i))
          (fin_enum m),
         Vector.map (fun i ⇒ Vector.map (fun j ⇒
            encrypt_pair (Vector.nth s i) (Vector.nth s j)
              (ps_r (Vector.nth (br_pos rd) i)) (ps_r (Vector.nth (br_pos rd) j))
              (Vector.nth (Vector.nth (br_pair rd) i) j)) (fin_enum m)) (fin_enum m)).

    End Prover.

Non-interactive ballots (Fiat–Shamir)

All proofs of a ballot share one challenge, H applied to the ballot transcript: the position ciphertexts with their announcements, then for every pair the bit ciphertext with the announcements of the bit proof and of the membership proof. H is an abstract function; random-oracle soundness of the transformation is not formalised. The public key (g, h) is not hashed.
    Section NIZK.
      Context {n : nat} (g h : G) (H : list (G × G) → F).
      Local Notation m := (S n).

The list of group-element pairs fed to the hash.
      Definition ballot_transcript (b : @ballot m) : list (G × G) :=
        (List.concat (Vector.to_list (Vector.map (fun i ⇒
          pos_cipher (fst b)[@i] :: Vector.to_list (Sigma.announcement (snd (fst b)[@i])))
          (fin_enum m))) ++
         List.concat (Vector.to_list (Vector.map (fun i ⇒
          List.concat (Vector.to_list (Vector.map (fun j ⇒
            let pc := (snd b)[@i][@j] in
            pair_bit pc ::
            (Vector.to_list (Sigma.announcement (pair_bit_proof pc)) ++
             Vector.to_list (Sigma.announcement (pair_mem_proof pc)))) (fin_enum m))))
          (fin_enum m))))%list.

The Fiat–Shamir challenge of a ballot.
      Definition ballot_challenge (b : @ballot m) : F := H (ballot_transcript b).

is_chal c pf tests whether the main challenge of pf is c.
      Definition is_chal (c : F) {k l r : nat} (pf : @sigma_proto F (G × G) k (S l) r) : bool :=
        if Fdec (Vector.hd (Sigma.challenge pf)) c then true else false.

challenges_are c b holds iff every proof of b uses main challenge c.
      Definition challenges_are (c : F) (b : @ballot m) : bool :=
        (forall_fin m (fun i ⇒ is_chal c (snd (fst b)[@i])) &&
         forall_fin m (fun i ⇒ forall_fin m (fun j ⇒
           (is_chal c (pair_bit_proof (snd b)[@i][@j]) &&
            is_chal c (pair_mem_proof (snd b)[@i][@j]))%bool)))%bool.

The non-interactive verifier: all main challenges equal the hash of the transcript and the interactive verifier accepts.
      Definition nizk_verify_ballot (b : @ballot m) : bool :=
        (challenges_are (ballot_challenge b) b && verify_ballot g h b)%bool.

set_challenges rd c replaces every challenge field of rd by c.
      Definition set_challenges (rd : ballot_rand (n := n)) (c : F) : ballot_rand (n := n) :=
        mk_ballot_rand
          (Vector.map (fun r ⇒ mk_pos_rand (ps_r r) (ps_uscs r) c) (br_pos rd))
          (Vector.map (Vector.map (fun r ⇒
            mk_pair_rand (pr_rb r) (pr_uscs_b r) c (pr_uscs_m r) c)) (br_pair rd)).

The non-interactive honest voter in two passes: compute the ballot once with arbitrary challenges, hash its transcript (which does not depend on the challenges: ballot_transcript_set_challenges) and recompute it with the hashed challenge.
      Definition nizk_encrypt_ballot (s : Vector.t nat m) (rd : ballot_rand (n := n)) :
        @ballot m :=
        encrypt_ballot g h s (set_challenges rd (ballot_challenge (encrypt_ballot g h s rd))).
    End NIZK.
  End Definitions.
