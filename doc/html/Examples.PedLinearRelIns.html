Library Examples.PedLinearRelIns

Linear relation between Pedersen-committed values, toy instance

A concrete instance of Crypto/PedLinearRel.v: for Pedersen commitments Cᵢ = g^vᵢ·h^rᵢ (i = 1..3), a proof of knowledge of all the openings (vᵢ, rᵢ) such that the committed values satisfy the public linear relation Σᵢ αᵢ·vᵢ = z. The prover commits to g^uᵢ·h^wᵢ for every i and to g^(Σ αᵢ·uᵢ), receives c and answers uᵢ + c·vᵢ and wᵢ + c·rᵢ. The verifier checks g^(vᵢ')·h^(rᵢ') = Aᵢ·Cᵢ^c for every i and g^(Σ αᵢ·vᵢ') = A·g^(c·z). The file is extracted to OCaml by src/Extraction/PedLinearRellib.
The group is the order-q subgroup of Z_p^* for the toy safe prime p = 2q + 1 = 5927 with q = 2963 (from Utility/Zpstar.v: Zp q is the scalar field and Schnorr_group p q the group of quadratic residues mod p). The parameters are far too small to be secure; they are chosen so that primality can be proved by trial division (Examples/Prime.v) and the extracted code runs instantly.
The instance uses αs = (1, -1, -1) and z = 0, that is v₁ = v₂ + v₃. A typical application is a confidential transaction: the committed old balance equals the committed amount sent plus the committed new balance, so no value is created, while all three amounts stay hidden. For the binding property of the commitments the discrete logarithm of h to the base g must be unknown; here g = 4 and h = 7 are simply fixed small elements, not generated verifiably.

The generator g = 4 = 2²: a quadratic residue, hence of order q; membership (4^q mod p = 1) is checked by vm_compute.

    Ha := conj eq_refl eq_refl : (0 < 4 < p)%Z;
    Hb := _ |}.
    vm_cast_no_check (eq_refl (Zpow_facts.Zpow_mod 4 q p)).

The four commitments: g^uᵢ·h^wᵢ for i = 1..3 and g^(Σ αᵢ·uᵢ), from the six random scalars usws = us ++ ws.

The non-interactive proof: c is fn applied to [p; q; g; h], the four announcements and the three commitments Cᵢ; fn is a hash function supplied by the OCaml caller (strong Fiat–Shamir).
   Definition nizk_construct_pedersen_linear_relation_generalised_real_proof_ins
    (fn : ∀ {m : nat}, Vector.t (Z + (@Schnorr_group p q)) m → (@Zp q))
    (vs rs : Vector.t (@Zp q) 3) (usws : Vector.t (@Zp q) 6) :
    @sigma_proto (@Zp q) (@Schnorr_group p q) 4 1 6.
  Proof.
    set (comm₁ := construct_pedersen_linear_relation_commitment_ins usws).
    set (comm₂ := pedersen_commitment_vector_ins vs rs).
    set (c := fn _ ([inl p; inl q; inr g; inr h] ++
    Vector.map inr (comm₁ ++ comm₂))).
    refine(construct_pedersen_linear_relation_generalised_real_proof_ins
    vs rs usws c).
  Defined.

The verifier for commitments cs: checks the three opening equations and the linear-relation equation, with αs and z above.
  Definition verify_pedersen_linear_relation_generalised_proof_ins
